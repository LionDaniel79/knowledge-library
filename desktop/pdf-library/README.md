# Windows PDF 서재

전자도서관 전체 PDF를 Windows에서 등록·검색·OCR 처리하는 독립 앱이다. WPF 화면과 Python 작업기는 표준 입출력으로 통신하며 HTTP 서버를 열지 않는다. 기존 PDF 서버, 웹 로그인, 기존 SQLite 없이 시작할 수 있다. 기존 색인을 지정하면 읽기 전용으로 재사용한다.

## 처음 설치

Windows x64, .NET Framework 4.x WPF, Python 3.12 이상이 필요하다. Windows 설정의 언어 기능에 사용할 OCR 언어(한국어/영어)를 설치한다. 저장소의 이 폴더에서 다음을 실행한다.

```powershell
.\Setup-PdfLibrary.ps1 -Python $python -Root $pdfRoot -PreparePython
```

`$python`은 설치된 Python 실행 파일, `$pdfRoot`는 전자도서관 전체 폴더다. 이미 PDF/OCR 의존성이 준비된 Python이면 `-PreparePython`을 생략한다. 기존 색인을 재사용할 때만 `-Index $index`를 추가한다. 새 사용자는 색인을 만들거나 옛 사이드카를 복사할 필요가 없다.

설치 위치는 기본 `%LOCALAPPDATA%\KnowledgeLibrary\PdfLibrary`이며 현재 Windows 사용자만 접근할 수 있도록 제한한다. 앱과 필요한 OCR 모듈을 버전별 `releases` 폴더에 복사하고 `state`에 새 관리 데이터를 저장한다. PDF 폴더·기존 설치·기존 색인·옛 사이드카는 수정하지 않는다. `-InstallRoot`로 전용 새 위치를 지정할 수 있다. 다른 파일이 있는 폴더는 설치 대상으로 받지 않는다. 실패한 설치는 같은 전용 위치에서 다시 실행할 수 있다.

바탕 화면의 **전자도서관 PDF 서재** 바로가기를 연다. 설치 폴더에도 `PdfLibrary.lnk`가 있다. `-StartWithWindows`는 시작프로그램 바로가기를 추가하고, `-Start`는 설치 직후 실행한다. 지정하지 않으면 자동 실행 설정을 만들지 않는다. 소스에서 로컬 빌드하는 실행 파일이며 코드 서명 인증서는 포함하지 않는다. 설치 확인 파일은 배포 파일의 SHA-256을 기록한다.

## 사용

- 처음 실행하면 전체 폴더를 확인한다. **전체 PDF 확인 / 추가 등록**은 전체를 다시 확인하고 바뀐 파일만 내용 지문을 계산한다. 논문·간행물도 Windows 관리 범위다. 폴더 감지는 짧은 시간에 발생한 변경을 모아 다시 확인한다. 감지 오류·저장 장치 재연결 뒤에는 전체 확인 버튼으로 보완한다.
- OCR은 한 쪽씩 저장하며 PDF 자체 텍스트를 먼저 사용한다. 대기·처리·오류 쪽수, 현재 파일/쪽, 완료한 쪽수, 연결된 사본을 표시한다. **OCR 일시정지 / 계속**, **오류 다시 시도**를 사용할 수 있다. 일부 파일 오류는 다른 파일의 처리를 막지 않는다. 목록은 첫 100개를 표시하며 집계와 검색은 전체 자료를 대상으로 한다.
- 검색은 모든 단어가 포함된 쪽을 찾는다. 큰따옴표로 어구를 지정하고 자료 종류·문서 ID로 좁힐 수 있다. 결과를 더블클릭하거나 **쪽 열기**를 누르면 PDF 쪽을 창에 맞춰 표시한다. **검색 취소**는 검색/쪽 열기만 중단한다.
- 창을 닫으면 알림 영역에 남아 처리한다. 알림 영역 아이콘을 더블클릭하면 다시 연다. 앱의 **종료** 또는 알림 영역 메뉴의 **종료**는 현재 작업 프로세스까지 중단한다. 이미 저장한 쪽은 보존되고 중단된 쪽은 다음 실행에서 이어간다.
- **위치 일괄 확인**은 전체 사본의 실제 PC 경로, 상태, 웹 보관함 키·상대경로, 마지막 확인 시각을 표로 보여 준다. 집계의 사본 수는 마지막 스캔에서 확인된 연결 저장소 기준이며 이 표는 실제 파일을 다시 검사한다. 외장하드 분리는 삭제 승인으로 처리하지 않는다. 이동/이름 변경은 내용 지문으로 다시 연결하며 여러 사본을 유지한다.

## 웹 서지 등록

**웹 연결 설정**에 HTTPS 웹 주소와 웹에서 발급한 이 PC의 등록 권한 기기 키를 입력한다. 같은 주소의 기존 Windows DPAPI 기기 키(`DeviceKeys` 또는 `TestDeviceKeys`)가 있으면 키를 비워 재사용할 수 있다. 새 키는 현재 사용자에게만 풀리는 DPAPI 형식으로 저장한다. 키는 명령행·로그·일반 설정 파일에 저장하지 않는다.

**웹 서지 일괄 등록**을 누르면 현재 처리를 마친 뒤 대기 목록을 전송한다. 최초 전체 등록과 이후 변경분에 같은 절차를 사용한다. **새 PDF 서지 자동 등록**을 켜면 새 스캔과 OCR로 확인한 서지 변경분을 자동 전송하고 실패 시 간격을 두고 재시도한다. 꺼져 있어도 오프라인 대기 목록은 보존된다.

전송은 outbound HTTPS만 사용한다. 도서 변경분은 `/api/desktop/library`, 완료된 위치 검사의 시각·보관함별 건수는 `/api/desktop/library/scans`에 보낸다. 완료 시각은 실제 검사가 끝난 때이며, 외장하드를 분리하거나 검사가 중단되어도 새 완료 기록을 만들지 않는다. 기독도서·일반도서와 하위 폴더의 서지·승인된 상대 위치만 전송한다. PDF/OCR 본문, 로컬 절대경로, 파일 해시를 보내지 않는다. 기존 문서는 소유자 범위의 최신 버전을 먼저 확인한다. 같은 내용의 파일이 서로 다른 기존 도서에 속하면 원래 문서 ID와 도서 연결을 각각 유지하고 OCR만 공유한다. 실제 파일 경로·이름·크기·시각 또는 이전에 검증한 파일 식별 정보로 도서를 구분하며, 구분되지 않는 사본은 임의로 배정하지 않고 보류한다. 한 도서의 여러 사본은 한 도서 연결 안에 유지한다. 확인되지 않는 옛 문서 ID는 개별 보류하고 다른 자료의 등록을 계속한다. 기존 제외·삭제·충돌은 임의로 복원하거나 병합하지 않는다. 전송 도중 종료해도 같은 요청 ID로 재시도한다. 인증서 검증은 유지하고 리디렉션은 따라가지 않는다.

명령으로 연결할 수도 있다. 키는 숨김 입력으로 받는다.

```powershell
.\Connect-PdfLibrary.ps1 -Configuration $config -Origin $httpsOrigin
# 기존 Windows 사용자 DPAPI 키 재사용
.\Connect-PdfLibrary.ps1 -Configuration $config -Origin $httpsOrigin -ReuseExisting
```

이 명령은 연결 정보만 저장한다. 앱을 다시 열고 등록 버튼을 누른다. 기기 등록/키 발급, 실제 웹 전송, 운영 설치 교체·옛 서버 철거는 이 시험에서 실행하지 않았다.

## 기존 실행 방식과 데이터

직접 빌드하거나 기존 5개 인수 바로가기를 계속 사용할 수 있다. 기존 색인이 없으면 세 번째 인수에 `-`를 사용한다.

```powershell
.\Build.ps1 -Output $exe
& $exe $python (Resolve-Path .\worker.py).Path $index $pdfRoot $privateState
# 설치된 설정 파일 실행
& $exe --config $config
```

`$privateState`는 PDF 폴더 밖의 사용자 전용 폴더다. 새 관리 DB `management-v1.sqlite`와 대기 목록만 이곳에 저장한다. 원본 색인은 읽기 전용 스냅샷이며 변경 중인 WAL/journal 색인은 조회를 중단한다. 백업은 앱의 **종료** 후 전용 상태 폴더를 비공개 저장소에 복사한다. DPAPI 키는 같은 Windows 사용자에서만 해독할 수 있으므로 다른 PC에서는 새 기기 연결을 설정한다.

옛 `registry.py`, `reader.py`, manifest v2와 검수용 작업기 명령은 호환성을 위해 남아 있다. 앱에는 검수용 모의 전송/OCR 버튼을 노출하지 않는다. 새 관리 API와 보존 규칙은 [MANAGEMENT.md](./MANAGEMENT.md)에 있다.

## 격리 시험

```powershell
& $python -B -m unittest discover -v
.\Build.ps1 -Smoke -Output $smokeExe
& $python -B smoke.py $smokeExe $newPng
& $python -B smoke.py $smokeExe $anotherNewPng --standalone
.\Test-Setup.ps1 -Python $python -SmokeExecutable $smokeExe
```

발명한 PDF/임시 SQLite만 사용한다. 기존 색인 재사용과 색인 없는 새 설치, OCR 한 쪽 저장, 검색·강조·쪽 열기, 위치 표, 검색 취소와 배경 작업 분리, 새 파일 감지, 트레이, 명시적 종료 후 자식 프로세스 정리를 검증한다. 설치 시험은 임시 전용 폴더와 가짜 DPAPI 키를 사용하고 바탕 화면/시작프로그램을 변경하거나 웹으로 전송하지 않는다. PNG는 기존 파일과 겹치지 않는 새 이름을 지정한다.
