# Windows PDF 서재 (3단계 검수판)

WPF가 Python 자식 작업기와 표준 입출력으로 통신한다. 로컬 검색, PDFium 페이지 열기, 폴더 검산, 격리 OCR, API v2 모의 등록을 제공한다. 로그인이나 HTTP 리스너는 필요 없다.

## 실행

Windows x64, .NET Framework 4.x WPF와 C# 컴파일러, Python 3.12 이상 및 저장소의 PDF/OCR 의존성이 설치된 인터프리터를 사용한다. 이 PC에서는 기존 OCR 가상환경으로 검수했다. worker.py와 scripts의 상대 위치를 유지한다.

~~~powershell
.\Build.ps1 -Output $exe
& $exe $python (Resolve-Path .\worker.py).Path $index $pdfRoot $privateState
~~~

$exe는 새 검수 실행 파일, $index는 기존 페이지 색인, $pdfRoot는 외장하드의 도서관 루트다. $privateState는 사용자 전용 로컬 디스크의 별도 폴더로 지정한다. PDF 원본 폴더와 별도로 두고 다른 사용자의 사이드카와 공유하지 않는다.

- 단어를 띄어 쓰면 페이지 단위 AND, 큰따옴표는 공백을 포함한 어구다. 문서 ID 지정 검색은 문서 안에서 먼저 찾는다. 결과의 쪽을 더블클릭하거나 쪽번호를 입력해 연다. 결과에 자료 유형·인식 방식·파일 가용 상태가 나온다. ID는 결과의 도구 설명에서 확인한다.
- 폴더 검산은 두 선택 루트의 가용성을 확인하고 경로를 두 번 순회한다. 중단 후 다시 시작하면 완료한 파일의 검산을 재사용한다. 변경된 파일과 중단 당시 처리 중이던 파일은 다시 확인한다. 경로명·크기·시각만으로 이동을 확정하지 않는다. 동일 해시를 가진 별개 도서 연결을 유지한다.
- 검색 시간제한은 작업기 기본 10초, 화면의 강제 종료는 15초다. 취소·창 닫기는 해당 요청의 Windows Job Object를 닫아 OCR 손자 프로세스까지 정리한다. 현재 운영 색인은 안정된 읽기 전용 스냅샷으로 사용한다. WAL/journal이나 색인 변경이 감지되면 조회를 중단한다. 외장하드에 색인도 있다면 드라이브 분리 중에는 그 색인을 조회할 수 없다.
- 문서 ID를 입력하거나 결과를 선택한 뒤 **사본 OCR 한 쪽 검수**를 누른다. 문서별 미완료 페이지 최대 5개를 ocr-inspection.sqlite에 복사하고 호출당 한 쪽만 처리한다. PDFium 문자 추출을 먼저 시도하고 필요하면 한·영 Windows OCR을 사용한다. 화면의 pending/review/error는 남은 쪽·검수 후보·오류다. 재실행은 미완료 쪽부터, 이어서 오류 쪽을 재시도한다. 취소하면 직전 완료 페이지까지 보존한다. 이전 OCR 후보와 검수용 출력은 별개다.
- **선택 목록 모의 검증**은 기독도서와 일반도서의 하위 PDF만 포함한다. 물리 사본 수와 옛 문서 ID 집합을 별도로 집계하고, 200건씩 모의 서버에서 start → put → seal → preview → apply-selection을 거친다. 서버 집합과의 삭제 차이는 5단계 처리 사항이다. 현재는 dry-run DTO만 있다. 미확인 신규 판본이나 여러 도서 ID 중 어느 책인지 확정할 수 없는 선택 파일은 검토가 끝날 때까지 전체 manifest 생성을 차단한다.
- 선택 문서의 기존 bookId·서지·버전은 명시적으로 지정한 단일 소유자 백업을 manifest.attach_catalog(backup, directory)로 불러온다. 서버 통신은 없다. 운영 전환 시 서버가 소유자, 최신 버전, 사용자 삭제 여부를 독립적으로 확인해야 한다.

## 데이터와 복구

원본 SQLite는 mode=ro로만 연다. 사본·별칭·선택 목록·전송 대기열은 전용 사이드카에 저장한다. 한 스캔이 완료된 이후에도 모의 등록 직전 현재 파일 집합과 수정 시각을 재확인한다. 루트 단절, 읽기 실패, 경로 이탈, 중단 또는 집합 불일치이면 seal하지 않는다. 모의 등록은 같은 내용 재시도 시 동일 요청을 사용한다.

작업기를 닫은 상태에서 전용 상태 폴더를 비공개 위치에 복사하면 사이드카·검수 후보·outbox를 보존할 수 있다. 복구 시 이 폴더의 사본을 새 위치에 두고 $privateState를 그 위치로 지정한다. 새 빈 폴더에서 시작하면 다시 검산한다. 예전의 경로 기반 스캐너·초기화 명령을 실행할 필요가 없다.

## 시험

~~~powershell
& $python -B -m unittest -v test_desktop
.\Build.ps1 -Smoke -Output $smokeExe
& $python -B smoke.py $smokeExe $newPng
~~~

GUI 검사는 가상 도서의 검색, 강조, 원문 쪽 열기, 취소를 거쳐 기존 파일과 중복되지 않는 PNG에 화면을 기록한다. 비식별 출력 예: 'paper / 2 hits; quoted / 1 hit', '모의 선택 2개 / 물리 파일 2개'. 실제 로그와 manifest는 사용자 전용 폴더에서 관리한다.
