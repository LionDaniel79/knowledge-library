## 포함 범위

도서와 가져온 원자료, 독서 이력, 메모, 책장, 연간 통계 보정값, PDF 위치와 처리 범위, 수정 이력, 수동 연결, 설교·논문 자료 모음, 주제·생각 변화·확인 이력, 수집 출처와 보조 정리 정보가 포함된다. 날짜만 있는 독서일은 그대로 보존하며, 시각은 UTC로 직렬화해 다른 시간대의 PC에서도 동일하게 비교한다.

로그인 계정, 인증키, 기기 토큰, 실행 대기열, AI 지출 정책은 복원하지 않는다. 복원만으로 분석이나 외부 전송을 시작하지 않는다. 과거 실행·지출 감사 자료가 필요하면 기존 전체 내보내기와 운영용 별도 DB 백업도 보관한다.

PDF 원본 파일, PDF SQLite 색인, iReadItNow에서 추출한 표지 이미지 파일은 JSON에 들어 있지 않다. 이 파일들을 별도로 백업해야 원문·표지를 다시 열 수 있다. 복원한 PC의 파일 경로와 앱 설정도 맞춰야 한다.

## 제한과 검수

현재 로컬 웹앱은 127 MiB 이하 파일을 검사·복원한다(HTTP 요청 한도 128 MiB). 실제 자료의 수정 이력과 가져온 원자료를 모두 보존하므로 백업이 크다. 서버리스 배포의 별도 업로드 제한을 우회하는 기능은 이번 구현에 포함하지 않았으므로 대용량 복원은 로컬 앱에서 수행한다.

백업과 앱의 DB 구조가 같아야 한다. 구조가 다르면 기존 자료를 변경하지 않고 중단한다. 동일 식별자가 이미 다른 소유자로 저장된 같은 DB에 복사 복원하면 충돌로 거부된다. 재해 복구는 동일 앱 버전의 새 DB와 확인된 소유자 계정에서 수행한다.

변조 확인용 SHA-256은 파일 손상을 검출하며 암호화·전자서명이 아니다. 개인 기록이 들어 있으므로 개인 보관 위치에 저장한다. 복원할 때 사용자 계정은 현재 로그인된 소유자로 지정하고, 파일에 임의로 삽입한 소유자 필드는 거부한다.

검사는 체크섬뿐 아니라 앱이 읽는 내부 자료 구조도 확인한다. 가져온 기록의 원자료, 주제 배열, 연구에 보관한 메모, 생각 변화의 두 기록·근거·맥락 등이 잘못되면 저장 전에 거부한다. 반면 원본 앱의 임의 필드와 과거 수정 이력은 제거하거나 재작성하지 않는다.
