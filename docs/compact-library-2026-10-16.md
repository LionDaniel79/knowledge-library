# 간결한 서재 화면과 도서 등록

2026-10-16. 이 문서는 이전 Zotero 운영 안내보다 우선한다.

- 통계·독서 달력의 표시 단위를 ‘권’으로 통일하고 기존 앱 독서량 카드를 숨겼다. 집계 원본은 유지한다.
- 날짜와 메뉴 제목을 한 줄에 놓고 반복 설명을 제거했다. 메모 목록은 제목·본문 미리보기·태그·연결 도서·날짜를 작은 카드에 배치한다. 전체 내용은 클릭해서 읽는다.
- 태그 필터의 ⊖로 삭제한다. 확인한 태그는 휴지통을 포함한 본인 기록에서 제거되며 본문과 수정 이력은 보존한다. 새 기록에 입력한 태그는 목록에 나타난다.
- 도서 목록 오른쪽 위: 파랑 완독, 초록 읽는 중, 노랑 책 대기열. 상태가 겹치면 함께 표시한다.
- 책 상세는 목록의 정보를 즉시 표시하고 최신 정보를 다시 읽는다. 동시 수정은 버전으로 확인한다.
- 표지는 파일 선택 또는 HTTPS 주소를 사용한다. 파일은 JPG·PNG·WebP, 8MB 이하이며 작은 WebP로 변환한다. 업로드한 표지는 로그인한 본인만 읽을 수 있고 복원용 백업에 포함된다.
- 책 추가에서 제목/ISBN 검색 또는 바코드 카메라·사진을 이용한다. 검색 후보를 선택한 뒤 판본과 내용을 확인하고 저장한다. 바코드 권한이 없으면 번호를 직접 입력한다. 카메라는 HTTPS 또는 localhost에서 동작한다.
- 예스24를 우선 사용하고, 실패·미발견 시 PC의 정보나루와 Google Books/Open Library로 보완한다. Open Library 제목 검색은 판본을 특정하지 않으므로 ISBN·출판사를 임의로 채우지 않는다. 검색은 AI 호출이 아니다.
- 예스24 출처는 간단히 표시하고 책 상세에 상품 링크를 제공한다. Basic 한도는 공식 문서 기준 하루 20,000건, 초당 10건이다. 알라딘 API는 종료 예정이므로 사용하지 않는다.
- Zotero 화면, API, 전송 코드·스크립트·환경설정을 제거했다. 이미 전송한 원격 도서는 삭제하지 않았다. 과거 외부 연결 데이터는 백업 호환 목적으로만 남긴다. 연구용 표준 JSON/RIS 내보내기는 유지한다.
- AI 요청 오류는 읽기 전용 뷰를 잠그려던 쿼리에서 발생했다. 소유자와 휴지통 제외 조건을 유지하면서 실제 메모 테이블을 잠그도록 고쳤다. 제한 DB 계정으로 요청 등록을 시험한 뒤 롤백했다. 유료 AI 호출은 하지 않았다.

PDF 원문 검색·열람과 PC 연결 기능은 웹앱에서 제거되었다. PDF 서지·기존 메모·인용·쪽수는 유지되며, 원본 열기와 OCR은 별도 Windows PDF 서재에서 수행한다.

개발 검수: 태그 소유권·충돌·이력, 이미지 형식·크기·소유권·백업 복원, 공개 서지 응답 파싱, AI 제한 계정 요청, 390/1440px 화면, 바코드 사진 인식과 서지 선택을 검사한다. 실제 휴대폰 카메라 하드웨어 검수는 브라우저 사진 인식 시험과 구분한다.

공식 API: [예스24](https://developers.yes24.com/docs), [이용 정책](https://developers.yes24.com/), [Google Books](https://developers.google.com/books/docs/v1/using), [Open Library](https://openlibrary.org/developers/api).

최종 검토 보완: 업로드 중 표지 선택을 잠그고, 태그 삭제 응답이 끊겼을 때 같은 요청으로 재시도한다. 기존 자료와 업로드 표지를 함께 복원할 수 있도록 로컬 백업 한도를 511 MiB로 늘렸다. 대용량 복원은 PC 앱에서 수행한다.

검수 결과: 단위·서버 테스트 247개, 브라우저 테스트 49개 통과. 타입 검사와 배포 빌드 통과. 예스24 실제 제목 검색은 후보 10개·표지 10개·소개 9개, 오류 0건을 확인했다. 임시 인증키 입력 파일은 삭제했고 서버 비밀 설정만 사용한다. 실제 유료 AI 호출은 실행하지 않았다.
