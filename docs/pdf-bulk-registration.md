# PDF 일괄 등록

## 최초 설치

이 기능은 각자 코드를 설치하고 본인 DB·Google 로그인·PC 서버를 구성한 뒤 사용합니다. 공유 서비스의 다른 계정 등록 기능은 아닙니다. 기존 소유자 인증은 그대로 적용됩니다.

1. `.env.example`을 참고하여 DB·로그인·소유자 설정과 마이그레이션을 완료합니다.
2. PC 서버에 `LIBRARY_PDF_ROOT`(원본 폴더), `LIBRARY_PDF_INDEX`(새 SQLite 색인의 절대 경로), `LIBRARY_PYTHON`(Python 실행 파일 절대 경로)를 설정합니다. 색인 파일은 없어도 자동 생성합니다. 색인과 작업 현황·캐시는 외장하드 등 충분한 공간이 있는 위치를 권합니다.
3. Python 3.11 이상에 `python -m pip install -r scripts/requirements-pdf.txt`로 PDF 도구를 설치합니다. 기존 OCR 도구 설치 환경도 사용할 수 있습니다.
4. `npm install` 후 Webpack으로 빌드하고 전체 소스와 함께 PC 서버를 실행합니다. `scripts/pdf-import-worker.ts`, `scripts/pdf_bulk.py`와 `tsx`가 PC 설치에 필요합니다. Vercel 단독에서는 로컬 파일을 읽을 수 없습니다.

## 사용

PDF 원문 검색 → PDF 보관 폴더 설정에서 폴더를 입력합니다. 기존 외장하드 위치가 바뀌었다면 연결 검사 → 이 위치로 저장을 먼저 실행합니다.

**PDF 일괄 등록**으로 폴더와 하위 폴더의 조사 결과를 확인한 뒤 **등록 시작**을 누릅니다. 첫 실행은 전체 신규 도서를, 이후 실행은 추가분을 등록합니다. 파일 내용이 같은 PDF는 중복 등록하지 않습니다. 논문·간행물은 제외하고 모호한 분류·기존 원본 변경은 보류합니다. 원본을 이동하거나 삭제하지 않습니다.

기본 목록 등록 후 앞 12쪽·뒤 8쪽의 ISBN과 제목을 확인해 서지를 보완하고, 문자형 본문을 색인합니다. ISBN 검산·정확한 제목·단일 판본 근거가 모두 맞을 때만 자동 보완합니다. 제목 검색과 불확실한 ISBN은 검토 목록에 보존합니다. 사용자가 수정한 책 정보는 자동 교체하지 않습니다. 표지는 검증된 다운로드 경로로 DB에 보관하고 목차는 제공자 자료가 있을 때만 보완합니다.

서지 키는 선택 사항입니다. `YES24_API_KEY`, `DATA4LIBRARY_KEY`, `GOOGLE_BOOKS_API_KEY`가 없으면 기본 목록·문자형 본문 색인까지만 가능합니다. API 한도는 기존 공용 호출 예약 파일을 사용합니다. 제공자 인증/한도/연결 오류는 기본 등록을 취소하지 않으며 **오류 재시도**로 이어갑니다. 유료 AI는 호출하지 않습니다.

창을 닫아도 PC에서 작업을 계속합니다. **일시 중지**는 현재 처리 중인 파일/페이지 묶음 후 멈춥니다. PC를 재시작했다면 같은 설정창의 **이어서 진행**으로 복구합니다. 작업 현황은 `LIBRARY_PDF_INDEX + .imports.sqlite`에 저장되므로 색인과 함께 보존합니다. PC가 꺼져 있거나 외장하드가 분리되어 있으면 진행하지 못합니다.

스캔 본문 전체 OCR은 기존 OCR 작업을 사용하며 일괄 등록이 무관한 전체 작업을 새로 시작하지 않습니다. 스캔 페이지는 문자 인식 대기로 표시합니다. 모든 도서에 서지·표지·목차를 확보했다는 의미로 ‘완료’를 사용하지 않습니다. 각각의 실제 처리 건수와 검토·오류를 확인하세요.

등록 도서와 보완 정보는 기존 변경분 동기화로 내려받습니다. 다른 기기의 동기화 버튼으로도 즉시 반영할 수 있습니다. 외장하드 원본은 동기화하지 않습니다.

다음 일괄 등록을 실행한 뒤에도 ‘등록 작업’ 선택에서 이전 작업의 검토 후보·오류를 다시 볼 수 있습니다.
