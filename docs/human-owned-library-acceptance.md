## 사용할 수 있는 기능

- 저장·수정·검색·수동 연결로 AI 요청이 생기지 않는다. Google 로그인, 책 정보 수정·책장·정렬·분야 필터, 독서 달력, 기록 검색·태그, 설교/논문 자료 모음을 유지한다.
- 통합 검색은 내 기록, 원자료, 검색용 보조 정보를 구분한다. 원문의 정확한 일치를 보조 태그보다 먼저 보여 준다. 출처는 ‘근거 보기’를 열 때 보인다.
- 보조 정보는 수정·숨김·복구할 수 있으며 개인 글을 덮어쓰지 않는다. JSON/Markdown에 작성 출처와 판단·수정 이력을 따로 보관한다.
- 명시적 AI 도움은 선택 기록의 태그 제안과 발췌 설명이다. 전송 내용과 비용 상한을 보고 실행한다. 키는 PC에만 둔다. 두 기록 비교는 실자료 성능 검수 전 비활성 상태다.
- PC가 꺼지면 AI 요청은 대기한다. 온라인 메모 저장과 검색은 계속 가능하다. 외부 호출 응답을 잃으면 자동 재호출하지 않고 비용 확인을 기다린다.
