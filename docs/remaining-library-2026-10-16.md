# 지식서재 후속 구현

사용자 요청으로 PDF 원본 백업과 손상 파일 7개 정비는 제외한다. Windows 자동 실행·휴대폰 PWA/카메라/외부 접속 검수는 사용자가 담당한다.

## 정상 PDF 검색 확인

현재 실제 자료에서 도서 검색 6종·원문 검색 5종을 재검사했다. 저장된 페이지와 인용 20건의 구절·파일 버전이 일치했다. 이는 OCR 텍스트가 사진의 글자를 완벽히 인식했다는 판정이 아니며, 기존 OCR 확인 전 표시는 유지한다. 손상 PDF를 수정하거나 다시 처리하지 않았다.

## 서버에서 요청형 GPT 실행

기존 선택 원문 미리보기·요청당 $0.01·월 $5 한도·동시 임대·사용량 정산을 재사용한다. 운영 서버에 실행 설정과 기존 API 키를 Secret으로 저장했고, 웹앱은 PC 없이 요청을 처리한다. 평소 저장/검색에서는 AI를 실행하지 않는다. 서버 실행을 설정한 PC의 옛 API 작업기는 시작하지 않는다.

2026-10-16 실제 운영 서버에서 임시 시험 문장만 사용해 요청 → GPT 호출 → 근거 검증 → 결과 저장 → 비용 정산을 확인했다. 성공한 요청은 $0.000072900이며 기존 메모 157건의 내용은 바뀌지 않았다. 두 차례 실패 검증도 사용량에 남겨 총 연결 시험 비용 $0.000234900을 기록했다. 이전 키 확인 $0.000035를 합쳐도 승인된 $0.01 이내다.

서버는 응답을 받은 뒤 결과 영수증을 DB에 먼저 기록한다. 결과 저장만 실패했으면 저장을 재시도하며 외부 API를 다시 호출하지 않는다. 송신 뒤 결과 자체를 잃었으면 비용 확인을 기다린다. 처리 대기열은 브라우저를 닫아도 제한된 서버 실행과 인증된 후속 요청으로 이어간다. 플랫폼 장애 시 대기 요청은 화면 재접속으로도 재개할 수 있으며 불확실한 송신은 자동 재전송하지 않는다.

## ChatGPT 읽기 연결

`/api/mcp`는 HTTPS의 읽기 전용 MCP다. 기존 Google 로그인 후 별도 동의 화면에서 도서·기록 읽기를 허용한다. 정확히 등록된 ChatGPT 클라이언트/콜백, S256 PKCE, resource 바인딩, 한 번 쓰는 5분 코드, 1시간 접근 토큰과 갱신 회전, 영구 연결 해제를 검증한다. 토큰 평문은 DB에 저장하지 않는다. 외부 도구는 전용 읽기 DB 계정으로 동작하며 파일 경로·SQL·쓰기 도구를 제공하지 않는다.

연결 주소는 운영 앱의 ‘필요할 때 AI 도움 → AI 사용·비용 설정 → ChatGPT 연결’에 있다. ChatGPT 계정에서 사용자 지정 연결을 만들고 읽기 동의는 본인이 수행한다. 계정에 해당 설정이 있는지는 실제 계정에서 확인한다. 연결을 해제하면 이후 읽기와 갱신을 거절한다.

공식 확인: [OpenAI MCP 인증](https://developers.openai.com/plugins/build/auth), [공식 ChatGPT 클라이언트 메타데이터](https://chatgpt.com/oauth/client.json). 플러그인 목록에 공개 게시하는 작업은 포함하지 않는다.

## 생각 변화 비교

수동 타임라인·주제·변화 이유·사용자 확정은 구현돼 있다. 현재 실제 자료는 메모 157건, 생각 시점/발화 주체를 확인한 사건 기록 0건이다. 비교할 본인 기록이 아직 없다는 사용자 답변에 따라 실제 품질 평가는 대기한다. 합성 테스트를 실제 사용자 품질 통과로 표시하지 않는다. 데이터와 검증 기준이 충족되기 전 GPT 비교를 임의 활성화하지 않는다.

## 데이터 보완

예스24 5,749권 수집은 별도 실행 중이다. 상태 파일 교체가 Windows 일시 잠금으로 실패해 1,033권에서 멈춘 원인을 확인했고, 잠금 해제 재시도와 체크포인트 복구로 재개했다. 판본 미확정 후보는 확인 전 적용하지 않는다. 사용자 글과 독서기록은 보존하며 원본 PDF는 읽기 전용으로 유지한다. 최종 완료 수치는 수집기 종료 후 별도로 확인한다.

## 구현 검증

- 단위·통합 테스트 81개 파일 / 273건, 관련 브라우저 검사 12건 통과. 서버 전환 시 PC 작업기 종료 검사도 포함한다.
- 별도 소스 사본의 배포 빌드 및 TypeScript 검사 통과. 배포 추적 602항목 중 개인 자료/비밀 파일 0개.
- 실제 DB에 추가 테이블과 최소 권한을 반영했다. MCP 계정은 읽기 전용이며 도서 수정과 인증 토큰 테이블 조회 권한이 없음을 확인했다.
- 최종 코드 검토에서 발견한 연결 해제/갱신 경쟁과 브라우저 종료 후 작업 대기 문제를 재현 테스트로 수정했다. Google 로그인 복귀 시 MCP 요청의 state/PKCE 정보가 유지되는 것도 SDK와 실제 라우트 매칭으로 검증했다.
- 비공개 PC 접속 서버에도 검수된 최신 빌드와 서버 실행 설정을 반영했다. 로컬·Tailscale·운영 웹의 화면 응답과 미인증 AI 접근 거부를 확인했다. 실제 휴대폰 확인은 사용자가 담당한다.
