# 새 기록·태그 관리·통합 검색 복원 (2026-10-25)

- 모든 화면의 상단에 ‘새 기록’을 표시한다. 휴대폰에서도 버튼 글자를 보이며 기존 기록 입력 창을 바로 연다. 상단 전역 검색은 복구하지 않는다.
- 메모 검색의 태그 목록에서 검색과 ⊖ 삭제를 함께 제공한다. 기존 확인 화면/지문 검사/요청 중복 방지/전체 기록의 태그 제거 명령을 재사용한다. 메모 내용은 유지한다. 선택 중인 태그를 삭제하면 필터가 전체로 돌아가고 검색 결과를 갱신한다.
- 통합 검색은 예전 상단 검색과 같은 /api/books?q 및 /api/notes?q 직접 검색을 입력 중 수행한다. 기존 책 표지 카드·메모 카드와 상세/편집 동작을 재사용한다. 책·메모는 별도로 건수와 페이지/표시 개수를 사용한다. 처음에 받지 않은 메모와 책에 연결하지 않은 생각도 검색한다. 전체 자료가 메모리에 있을 때는 같은 직접 필터로 조회한다. 별도 검색용 정리 정보 인덱스로 대체하지 않는다.
- 사유의 지도 탭 옆 새로고침과 중복 지도 새로고침을 제거했다. 자료/기록 변경에 따른 기존 자동 갱신은 유지하고 오류가 있을 때만 다시 불러오기를 제공한다.

원인: 새 기록 버튼을 숨기는 휴대폰용 CSS가 남아 있었고, 이전 상단 검색을 다른 검색 API와 결과 모양으로 교체했다. 검색용 태그 선택기를 새로 만들 때 기존 삭제 기능도 빠졌다. 이번 변경은 기존 동작 복원이며 새 DB나 AI 기능을 추가하지 않는다.

판단: 태그 관리는 기존 공유 선택기를 확장해 삭제 명령을 복제하지 않았다. 검색 결과 카드는 부모의 기존 렌더러를 전달해 같은 책/메모 동작을 보존한다. 제목·저자·독립 메모 등 직접 검색 범위는 예전 상단 검색을 따른다.

모의 PC/휴대폰 및 고립 DB로 확인한다. 개인 자료를 작성/삭제하지 않았고, 실제 기기 간 동기화와 iPhone 키보드는11/1검수 목록에 유지한다. 원본 PDF·PC 서버·OCR·API 키·유료 AI 호출은 변경하지 않는다.
