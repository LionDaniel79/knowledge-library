# 글감 엮기 통합 및 기능 재평가 — 2026-10-26

## 변경 범위

- 사유의 지도의 독립 메뉴 ‘설교·논문 자료’와 ‘메모 상자 → 글감 엮기’는 동일한 `WritingWorkbench`, API, 저장 자료를 사용했다. 독립 메뉴만 제거하고 글감 엮기로 통합한다. 기존 설교·논문 묶음과 자료·배치·수정 이력은 삭제하거나 옮기지 않는다.
- 글감 엮기를 열면 생성 양식이 바로 보인다. 생성 양식의 접기/펼치기와 ‘새 글감 묶음 만들기’ 제목을 없앴다. 제목·용도·탐구할 질문·목차 입력 및 생성 버튼은 유지한다.
- 제목을 생략한 기록은 목록과 카드에서 내용 앞부분을 표시한다. 저장된 ‘미분류 메모’ 제목과 원래 기록은 바꾸지 않는다.
- TXT에도 자료 역할(주장·근거·반론 등)과 PDF 식별자·원본 서명을 포함한다. 기존 Markdown과 같은 수준으로 출처를 추적한다.
- 백업 자료 이름을 ‘글감 묶음’으로 통일하고, 사용법에 진입 위치와 목차·배치의 관계를 명시한다.

## 사용자 의도와 현재 기능

목표는 독서 중 만든 자기 기록을 다시 읽고, 분류·연결하며, 목차와 해석을 붙여 글쓰기 재료로 만드는 것이다. 직접 판단하고 쓰는 작업을 중심에 둔다.

| 단계             | 현재 기능과 평가                                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 생각을 포착      | 기록의 제목은 생략할 수 있다. 글감 선택에서는 내용을 보고 구분한다.                                                                                  |
| 분류·연결·재검토 | 내 기록의 주제·태그·분야·도서 분류, 화이트보드 연결, 메모 상자의 연결 이유와 관련 기록을 사용한다.                                                   |
| 집필 질문과 목차 | 글감 묶음별로 제목·용도·질문·목차를 저장·수정한다. 이전 설교와 논문 묶음도 같은 선택 목록에서 연다.                                                  |
| 자료 선별        | 활성 메모 전체의 제목·내용을 검색해 담는다. 이미 담은 메모는 중복 추가하지 않는다.                                                                   |
| 논의 구성        | 각 자료에 질문·주장·근거·반론·배경 역할, 장·절, 배치 순서, 내 해석을 붙인다. 원래 메모와 해석은 별개로 보관한다.                                     |
| 출처 보존        | 담은 시점의 메모·서지·쪽수·버전을 보존한다. 나중에 원래 기록을 고쳐도 담아 둔 문장은 바뀌지 않는다. 현재 기록과 비교해 열 수 있다.                   |
| 제외·복원        | 묶음에서 자료를 빼도 원래 기록은 남는다. ‘묶음에서 뺀 자료도 보기’에서 다시 포함한다. 제외된 자료는 내보내지 않는다.                                 |
| 활용             | 정한 순서대로 Markdown/TXT를 내보낸다. 내 해석과 출처·메모 버전을 포함하며 PDF 자료는 식별자와 원본 서명도 포함한다. 서지 JSON/RIS도 내보낼 수 있다. |

기본 구조는 승인된 ‘목차를 만들고 메모를 순서대로 모아 글감으로 내보내기’에 부합한다. 자동으로 글을 대신 쓰는 기능을 추가하지 않는다.

## 실제 사용 예

1. ‘공감에 관한 글’ 묶음을 만들고 ‘첫 생각 / 새롭게 읽은 근거 / 현재 결론’ 목차를 적는다.
2. 과거 생각, 책의 근거를 옮긴 기록, 최근 자기 생각을 검색해 담는다.
3. 각각 장·절과 역할을 정하고, 자기 해석을 덧붙인다.
4. ↑·↓ 또는 배치 순서로 읽힐 순서를 정한다.
5. TXT/Markdown을 내려받아 글을 쓴다. 불필요한 자료는 묶음에서만 뺀다.

## 현재의 범위와 제한

- 목차는 한 줄당 한 항목인 목록이다. 질문과 목차를 합쳐 2,000자까지 저장한다.
- 장·절 이름을 붙이는 것만으로 자료 순서가 바뀌지는 않는다. 배치 순서가 화면과 내보내기 순서를 정한다. 목차의 순서를 바꾸면 자료도 자동 재배열되는 계층형 편집기는 현재 범위가 아니다.
- 글감 자료를 정리·내보내는 작업대다. 완성 원고의 문단을 직접 편집하거나 조판하는 원고 편집기는 아니다.
- 묶음에서 자료 제외·복원은 지원한다. 묶음 자체의 보관/삭제 기능은 이번 변경에 추가하지 않는다.
- AI 호출 없이 사용하는 기능이다. 개인 기록을 외부 AI로 보내지 않는다.

## 검수 방법

고립 PGlite DB와 Chromium/WebKit 모의 화면을 사용한다. 개인 온라인 서재에 테스트 기록을 만들거나 실제 메모를 변경하지 않는다. 전 기기 동기화 및 iPhone의 실제 파일 저장 검수는 기존 별도 검수 항목으로 유지한다.

검수 항목: 진입점 통합, 양식 즉시 표시, 기존 글감 열기, 제목 없는 메모 선택, 목차 수정, 역할·장절·해석 저장, 순서 변경 중 초안 보존, 묶음에서 제외·복원, TXT 다운로드, 원문 불변, 중복 방지, 다른 계정 접근 차단, 버전 충돌 처리. 검수 결과 및 배포 식별값은 별도 운영 기록에 남긴다.
