# 메모·연결·생각묶음의 문맥별 AI 도움

- 내 기록 목록: 종합검토·메모 연결 제안. 제목·생각묶음 생성 제안은 숨긴다.
- 메모 상세: 해당 메모 하나의 제목 추천. 선택한 원문만 보내며 적용은 제목 입력칸을 채운다.
- 연결 상세: 메모 본문을 한 번씩 표시한 뒤 전체 연결과 개별 연결 편집을 구분한다. 저장은 한 트랜잭션이며 버전 충돌 시 입력을 유지한다.
- 연결 AI: 선택한 묶음의 모든 메모를 근거로 제목·이유를 반환한다. 추가 연결 추천은 선택한 묶음 안의 한 메모와 바깥 한 메모 사이만 허용한다.
- 생각묶음 AI: 제목과 설명을 기존 입력칸에 채운다. 최종 저장은 기존 원본 저장 동작을 사용한다.

## 연결 계층과 동기화

기존 연결 행과 library_whiteboards.data.memoGroups를 함께 사용한다. 새 테이블·마이그레이션은 없다. memoGroups에는 연결 ID 집합, 전체 제목·이유, 바로 아래 자식 연결 집합을 저장한다. 상위 결합 해제는 자식 연결을 거절하지 않는다. 단일 쌍을 해제할 때만 그 연결 상태를 rejected로 바꾼다. 각 단계의 자식 묶음과 공유 메모를 보존한다.

editMemoGroup은 기존 knowledge 트랜잭션·요청 중복 방지·수정 이력·동기화 저널을 사용한다. 기기 큐에서도 동일한 순수 변경 계획을 사용한다. 일반 보드 배치 저장·되돌리기는 연결 계층 정보를 덮어쓰지 않는다. 그룹 정보 변경은 전용 경로로만 반영한다.

## 검증과 한계

관련 단위·격리 DB 시험: 34건. 브라우저 모의 시험: 6건(390px·1280px 포함). 실제 API 호출 없이 제목과 이유 입력 반영, 단일 메모 전송, 대상 구분, 계층 해제·재시도·실패 시 원자성, 기존 메모 보존, 오프라인 변경 계획을 확인했다. 실제 유료 AI 응답과 물리적 다른 기기 간 동기화는 이번 검증에 포함하지 않았다.
