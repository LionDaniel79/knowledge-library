# PDF·로고스 수집의 전체 진행 현황

두 수집 탭에서 현재 웹 서재의 수집 대상 도서를 도서 ID별로 집계합니다. PDF는 기존 Local PDF 등록 자료, 로고스는 Logos 가져오기 출처 자료가 대상이며 삭제·제외된 도서는 집계하지 않습니다.

- **전체 대상**: 현재 수집 대상 도서 수.
- **누적 조사**: 자동 보완 이력 또는 기존 조사·체크포인트가 있는 도서 수. 같은 책의 반복 실행을 중복 합산하지 않습니다.
- **자동 보완 이력**: 자동 보완 적용 기록이 있는 도서 수. 모든 서지 항목의 완성을 뜻하지 않으며 사용자가 나중에 수정·복원한 경우에도 적용 이력은 남습니다.
- **남은 미적용**: 전체 대상 중 자동 보완 적용 이력이 없는 도서 수. 미조사와 적용 보류를 포함합니다.
- **적용 보류**: 조사 기록은 있지만 자동 보완 이력이 없는 도서 수. 검토 대기, 후보 없음, 파일·범위 확인, 오류·재시도, 기타로 구분합니다. 보류는 영구 처리 불가 판정이 아닙니다.

전체 현황은 시작 시, 배치 종료 후, 대기 중 15분마다 읽기 전용으로 확인합니다. 화면에는 마지막 확인 시각을 표시하며 실제 배치의 진행 상태는 기존 오늘 처리량·실시간 배치 결과에 표시됩니다. 화면의 ‘현황 새로고침’은 저장된 집계를 다시 표시하며 대량 재수집을 실행하지 않습니다.

조회 실패 시 마지막 집계는 보존하고 실패 안내를 표시합니다. 집계가 아직 없을 때는 확인되지 않은 권수를 0으로 표시하지 않습니다. 원본 PDF·OCR·색인·API 호출 원장·수집 체크포인트·웹 도서 및 개인 기록은 수정하지 않습니다. 집계 파일에는 도서 ID, 개인 경로, 인증 정보나 도서 내용이 포함되지 않습니다.
