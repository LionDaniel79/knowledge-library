# 지식서재 5단계 — 모바일 실기기 동기화·PDF 복원 검수

작성: 2026-11-04 KST · PR #8 `feat/stage5-windows-https-v2` · 운영·Neon QA 기존 자료 불변 원칙

## 1. 범위와 명확한 제약

- 사용 중인 iPhone Safari 또는 홈 화면에 설치한 웹앱에서 **읽기 전용**으로 관찰할 수 있는 동작만 확인한다. 도서·메모·독서 기록 생성, 수정, 삭제 및 실제 PDF 보관/복원을 시험하지 않는다.
- PR #8의 새 코드는 아직 병합되지 않았고, 기존 QA Preview 배포는 이전 커밋일 수 있다. **QA Preview가 최신 PR #8 커밋인지 배포 SHA를 먼저 확인**해야 실기기 결과를 PR #8의 검증으로 인정한다.
- 기존 QA Preview가 Vercel SSO로 보호된 경우 정상적인 인가 절차를 이용한다. 보호를 제거하지 않는다. 원문 인증키·우회키·DB 접속 문자열을 이 대화나 GitHub에 보내지 않는다.
- 실제 도서의 `pdf_archive` 복원을 휴대폰에서 확인하려면 이후 **별도의 격리 QA 소유자·테스트 도서와 명시적으로 승인된 쓰기 환경**이 필요하다. 운영/기존 QA 소유자를 변경하지 않는다. 본 검수에서 복원 전후 UI는 PGlite 가상 기기 자동시험으로 검증하며, *실기기 복원 표시*는 **미검증** 상태로 기록한다.
- 기존 실제 PDF·OCR·Windows 검색 DB는 수정하지 않는다. 모바일에서 로컬 데이터를 삭제하거나 저장공간을 초기화하지 않는다. 동기화 대기열이 비어 있음을 확인하기 전에는 로그아웃·브라우저 데이터 지우기를 하지 않는다.

## 2. 사전 조건

1. [ ] 보호된 QA URL과 실제 배포 SHA를 확인한다. PR #8 검수 대상으로 사용할 때는 최신 커밋과 일치해야 한다. 그렇지 않으면 '기존 배포 읽기 기능만 검수'로 표시한다.
2. [ ] QA 환경에 `LIBRARY_STAGE5_WRITE_ENABLED=false`이고 실제 `applied_at` 설정 manifest가 0건임을 서버에서 **조회 전용**으로 확인한다.
3. [ ] 휴대폰이 정상 온라인일 때 서재를 한 번 완전히 동기화하고, '완료/대기 0/오류 0' 상태를 확인한다. 실제 UI 명칭은 배포판에 따라 다를 수 있다.
4. [ ] 기존에 읽을 수 있는 PDF 도서 한 권과 해당 메모/독서 기록(있다면)을 선택하고 제목·ID(앱이 제공할 때만)·현재 진행 쪽수·메모 수를 **개인 정보 없는 형태**로 검수표에 기입한다.
5. [ ] 작업 전 기기 오프라인 미전송 변경이 없다면 그대로 유지한다. 미전송 데이터가 있다면 저장 상태 확인 전 인터넷이나 저장공간을 초기화하지 않는다.

## 4. 격리 자동시험 (실제 운영/QA 쓰기 없음)

PR #8 `tests/pdf-retention-mobile-stage5.test.ts`는 가상 PDF 6권(기존 수동 제외·논문 제외·기존 pdf_archive·정상·미선택 연구·합본 원본), 메모 2건, 독서 기록, 도서 관계를 PGlite에서 생성한다. 가상 휴대폰과 태블릿으로 다음을 검증한다.

- 복원 전 제외된 자료는 두 기기의 도서 목록에 없고, 원래 읽고 있던 도서·메모는 보존된다.
- 복원 시 `library_book_exclusions` 변경과 `library_books.version` 변경이 모바일 동기화로 전달돼 기존 도서 ID가 다시 표시되며 이전 독서 기록이 연결된다.
- 오프라인 메모 1건은 중단/재접속을 거쳐 동일 요청 ID로 한 번만 반영된다.
- 이미 제외된 다른 자료는 여전히 제외되고, 미선택 2건과 기존 PDF 등록 상태도 사용자 승인 없이 바뀌지 않는다.
- 같은 manifest를 다시 적용해도 중복 복원·문서 등록·메모가 발생하지 않는다.
- 이 시험은 브라우저의 서비스워커·실제 네트워크·Safari UI까지 테스트하지 못하므로 실기기 M01–M09가 별도로 필요하다.

자동시험 워크플로 `.github/workflows/stage5-retention-safety.yml`:
`npx vitest run tests/pdf-retention-stage4.test.ts tests/pdf-retention-stage5-safety.test.ts tests/pdf-retention-mobile-stage5.test.ts tests/desktop-catalog-integration.test.ts tests/desktop-http-manifest-stage5.test.ts tests/sync-retention.test.ts tests/replica-archive.test.ts tests/replica-pull.test.ts tests/multi-device-memo-sync.test.ts --maxWorkers=1`
