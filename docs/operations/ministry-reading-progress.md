## 연동 계약

기존 `POST /api/integrations/ministry`의 정확한 출처·검증된 Google 소유자·Firebase 토큰 검증을 유지한다.

- `reading`의 책 목록: 기존 `cycleId`, `currentPage`에 정수 `cycleVersion` 추가.
- 새 명령: `{action:"update-progress",requestId,progress:{id,expectedVersion,currentPage}}`.
- `id`는 책 ID가 아니라 독서 회차 UUID다. `requestId`도 UUID다.
- 값은 절대 도달 쪽수인 정수 0~100000이며 책의 전체 쪽수 이하여야 한다. 쪽수 정정은 허용한다. 마지막 쪽을 기록해도 완독 처리하지 않는다.
- 성공: `{id,version}`. 입력 버전의 다음 버전을 반환한다. 같은 요청 번호와 내용 재시도는 이전 결과를 돌려준다.
- 오래된 버전은 409, 다른 소유자의 회차는 404, 읽는 중이 아니거나 쪽수가 범위 밖이면 400. 허용하지 않은 필드는 거절한다.
- 기존 `updateProgress` 변경 경로를 사용하므로 수정 이력과 기기 동기화 변경도 함께 발생한다. 스키마·권한·인증키 추가는 없다.

목회 앱은 서버 성공 후 카드만 갱신하고 전체 서재를 다시 다운로드하지 않는다. 실패한 입력과 재시도 요청 번호는 메모리에 보관하며, 연결 해제·계정 변경 시 폐기한다. 버전 충돌은 자동 덮어쓰기 없이 최신 기록을 보여준 뒤 사용자가 다시 저장한다. 구버전 서버가 버전을 제공하지 않으면 저장 버튼을 비활성화한다.
