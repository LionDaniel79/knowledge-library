# 글감 삭제·백그라운드 동기화

- 글감 목록의 제목 오른쪽에서 삭제한다. 확인 창은 대상 제목을 보여준다. 삭제 대상은 해당 글감의 목차·배치·모아 둔 사본이며 원래 메모·도서·연결은 유지한다.
- 제목·질문과 보드 버전을 확인한다. 다른 기기가 목차나 배치를 바꾸었다면 삭제를 거절한다. 검토 후 명시적으로 선택한 삭제는 새 기준으로 다시 전송한다.
- 삭제 이력에 당시 프로젝트·보드·글감 사본을 남기고 기기에는 즉시 반영한 뒤 변경분으로 동기화한다. 삭제한 프로젝트는 늦게 도착한 보드 저장으로 다시 만들어지지 않는다.
- DB030은 특정 프로젝트의 사본·배치만 제거하는 전용 함수다. 웹 실행 계정에 테이블 전체 DELETE 권한을 주지 않는다. 별도 검증 분기와 제한 계정으로 검사했다.
- 보드와 글감은 같은 ID를 사용하지만 충돌 검토는 실제 자료 종류를 구분한다. 보드 저장 검토가 뒤에 대기하는 글감 삭제를 잃지 않도록 회귀 검사를 추가했다.
- 최근 실제 저장54건 중33건이 화면 위치·배율만 바뀐 저장이었다. 화면 이동과 확대·축소는 기기에 보관하고, 자료·목차 변경 또는 명시 저장 시 최신 화면 위치를 함께 전송한다.
- 기존 홈 동기화는 메뉴 이동 후에도 계속 실행되고 있었다. 설정에서 시작할 때 창을 바로 닫아 메뉴를 사용할 수 있게 했고, 모든 메뉴에서 진행 건수·남은 건수·완료를 표시한다.
- 진행 상태만 바뀌면 서재 전체를 다시 읽던 경로를 분리했다. 공용 동기화 실행기와 중복 실행 방지·타임아웃은 유지한다.

검수는 실제 개인 자료를 삭제하거나 유료 AI를 호출하지 않고, 격리 DB·기기 저장소·지연 네트워크로 수행했다. PC와390px 모바일 화면의 Chromium/WebKit에서 메뉴 이동·완료·오류 표시를 확인했다.
