# 메모 검색·글감 보드 적용 기록

## 사용자 흐름

- 메모 상자 → 내 기록: 종류·분야·도서·주제·태그는 왼쪽 체크박스로 복수 선택한다. 같은 항목 안에서는 OR, 항목 사이에서는 AND로 찾는다. 검색 버튼 또는 검색 칸의 Enter가 결과와 AI 범위를 확정한다.
- AI 전송 메모 수: 6/12/24개 또는 전체를 선택한다. 전체는 모든 검색 페이지를 확인하며, 1,000개·문맥·전송량 제한을 넘으면 범위를 좁히도록 안내하고 조용히 생략하지 않는다. 전체 옵션은 본문 전체를 사용한다. 비용 미리보기·사용자 확인·월 상한을 유지한다.
- 연결된 주제: 목록에서 한 쌍을 선택하고 오른쪽에서 상세 정보·관련 메모·주제 설명을 확인한다. 실제 주제 연결, 메모에서 나온 연결, 보드 연결을 구분하여 끊는다. 메모는 삭제하지 않는다.
- 화이트보드 연결 관리에도 연결된 주제가 나타난다.
- 글감엮기: 메모 상자 오른쪽의 별도 탭이다. 기존 WhiteboardPanel/Canvas를 재사용하며 글감별 boardId로 배치를 분리한다. 목차 상자에 개별 메모·메모 묶음·주제 관련 메모를 넣고 목차와 자료의 번호순으로 TXT/MD를 출력한다.
- 목차 안 메모와 위치는 검색 조건에 영향을 받지 않는다. 같은 상자 안에서 카드를 움직여도 번호는 바뀌지 않는다. 배율 옆의 저장은 현재 카메라까지 즉시 저장하며, 자동 저장도 유지한다.
- 글감 목록에서 이전 배치를 복원한다. 원래 연구 자료·목차·스냅샷은 보존하고 처음 열 때 새 보드로 표현한다. 기존 메모가 있으면 최신 본문을, 원본이 없으면 당시 스냅샷을 사용한다.
- 글감 AI 도움은 현재 보드와 목차를 기준으로 아이디어·상자 제목·추가할 메모를 제안한다. 이미 목차에 넣은 메모를 제외한 기존 기록에서 최대24개 후보를 선정한다. 제안 적용은 현재 글감에서만 가능하며 자동 적용하지 않는다.

## 동기화 확인 수정

자연키가 같은 주제 분류의 기기별 ID 차이, 연구 제목·질문 사전 조건, 메모의 중첩 주제 버전, 배치·도서 소개·판본 관계 버전, 연속 메모 수정과 그 사이의 분류 작업을 현재 자료에 맞춰 재생한다. 기존 원본 요청과 선택 이력은 보존한다. 검토 목록을 숨기거나 실제 사용자 충돌을 임의 선택하지 않는다.
