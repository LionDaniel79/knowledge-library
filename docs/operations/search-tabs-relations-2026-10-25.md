# 검색 화면과 소장본 연결 변경 (2026-10-25)

## 화면
- 통합검색 메뉴는 도서 검색/메모 검색/통합 검색 탭이다. 처음에는 도서 검색을 열고 이후 같은 기기·계정의 마지막 탭을 연다.
- 도서 검색은 제목·저자·출판사·ISBN·분야·독서 상태를 조합한다. 메모 검색은 종류·분야·주제·태그·연결된 책 제목·메모 내용을 조합한다. 사용자의 답변에 따라 ‘제목’은 메모 제목이 아닌 연결된 책 제목만 뜻한다.
- 주제·태그는 검색 가능한 선택 목록, 책 제목은 입력 중 제목 제안을 제공한다. 책 제목의 일부만 입력해 검색해도 된다. 같은 제목의 여러 판본은 모두 일치할 수 있다.
- 통합 검색 탭의 단일 검색은 책·저자·기록과 보관된 검색 정보를 함께 찾는다. 상단 전역 입력과 종전 자료검색어/검색대상 컨트롤은 제거했다.
- 소장도서에는 분야·책장 다음에 검색을 둔다. 제목·저자·출판사·ISBN 등을 검색하며 기존 필터·정렬·페이지를 유지한다. 책 상세 제목은 본문과 함께 스크롤된다.

## 연결
다른 소장본·판본 연결 → 도서를 직접 찾아 비교를 연다. 현재 책은 결과에서 제외하고 첫 유효한 결과가 선택된다. 다른 책을 고른 뒤 관계와 확인한 근거를 입력하고 ‘연결’을 누른다. 검색 결과 개수·페이지는 접지 않고 표시한다. 메모 편집의 ‘책과 연결하지 않은 생각’ 선택은 그대로다.

이전 문제는 현재 책이 후보에 포함되고 검색을 바꾸어도 이전 선택이 유지될 수 있는 구조였다. 현재 책 제외를 서버/기기의 전체 질의에 적용하고, 새 검색·다른 원본 책을 열 때 선택을 갱신한다. 실제 연결 저장·버전/소유권 검사·해제는 기존 기능을 사용한다. 두 책을 합치거나 원본 PDF를 변경하지 않는다.

## 판단과 검수 범위
- 마지막 탭은 기기·계정별 선택이며 교차 기기 동기화 대상은 아니다.
- 책의 주제는 관련 메모에서도 찾고 메모에서 명시적으로 거절한 주제는 제외한다. 세부 KDC 번호도 상위 분야로 검색한다. ‘내 기록’과 같은 기준으로 맞춘 것이다.
- 단위/고립 DB 40개와 모의 PC·모바일 화면11개, 타입 검사가 통과했다. 실제 개인 DB/기기 동기화는 실행하지 않았으며11/1검수 목록에 추가했다.
- PC 서버·OCR·외장 PDF·API 키·유료 AI 호출은 변경하지 않았다. 최종 빌드는 Vercel에서 확인한다.
