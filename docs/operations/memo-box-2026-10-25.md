# 메모 상자와 글감 엮기

## 사용하는 흐름

1. 기록을 작성할 때 태그 위의 **주제**에서 하나 이상 선택한다. 제목은 선택 사항이다. 주제를 지정하지 않은 기록은 미분류로 찾는다.
2. **주제별 자료**에서 자료 종류·분야·주제·정렬을 고르고 표시 개수 왼쪽의 검색으로 제목·내용을 좁힌다.
3. **화이트보드**에서 메모와 주제 묶음을 연결한다.
4. 화이트보드 오른쪽의 **메모 상자 → 연결된 메모**에서 기록을 선택한다. 원래 기록을 수정·분류하거나 연결의 관계와 이유를 고친다. **관련 기록 남기기**는 기존 기록을 보존하고 새 기록을 연결한다.
5. **연결된 주제**에서는 직접 확인한 주제 연결, 화이트보드의 주제 연결, 서로 다른 주제의 실제 메모 연결을 구분해 본다. 관련 주제의 메모를 살펴보고 주제 설명을 수정하거나 두 주제에 속하는 새 기록을 남긴다.
6. **글감 엮기**에서 글감 묶음과 목차를 만든다. 메모를 담고 ↑·↓로 순서를 조정한다. 각 자료의 **역할·순서·내 해석 수정**에서 장·절과 나의 해석을 입력한다. 목차의 항목은 장·절 입력 후보로 표시된다.
7. **글감 내려받기 (.md/.txt)**로 문서를 저장한다. 당시 메모, 나의 해석, 책·쪽수·메모 버전이 함께 담긴다. 이후 원본 메모를 수정해도 담을 당시의 인용 스냅샷은 유지된다.

설교·논문 자료 메뉴도 같은 글감 저장 구조를 사용한다. 기존 독립 메뉴인 생각의 흐름·검토할 후보·사유의 연결 UI는 제거했고 원자료와 과거 판단·이력은 삭제하지 않았다. AI 호출은 이 기능을 사용하는 데 필요하지 않다.

## 저장과 충돌

- 새 테이블을 만들지 않고 기존 주제·연결·연구 자료·배치 구조를 사용한다. 일반 집필은 기존 내부 연구 유형 `thesis`를 사용하며 화면은 **집필·논문**으로 표시한다.
- 목차는 연구 질문 뒤의 읽을 수 있는 Markdown 목록으로 저장한다. 예전 질문만 있는 자료도 그대로 읽는다. 질문과 목차는 합쳐 2,000자까지 저장한다.
- 메모와 선택 주제·관련 메모 연결은 한 명령/한 트랜잭션으로 저장한다. 기존 화면이 주제 필드를 보내지 않으면 원래 분류를 유지한다. 하위 행 ID는 요청 ID와 순서로 정해 재시도와 임시 참조 치환을 지원한다.
- 제목·목차 수정은 열었을 당시의 제목·질문과 비교해 충돌을 막는다. 순서 이동은 묶음 내 활성 자료의 순서를 한 번에 저장한다. 과거에 배치 순서가 없던 자료도 함께 정렬되며 각 항목의 장·절과 해석은 유지한다. 순서 이동 한 번은 최대 2,000개 항목을 처리한다.
- 분야·주제 직접 거절·삭제 주제·휴지통 기록을 존중한다. 주제 묶음 연결만 있는 것을 메모 사이의 근거 관계로 표시하지 않는다.

## 확인 범위

개인 온라인 DB에 시험 자료를 쓰거나 기기 간 동기화 검사를 실행하지 않는다. 고립 PGlite DB와 모의 브라우저에서 저장·권한·충돌·검색·반응형 화면·내보내기를 검수한다. 실제 기기 왕복과 iPhone 파일 저장은 `sync-acceptance-2026-11-01.md`에 추가했다.

기존 PC PDF 서버와 실행 중인 OCR 작업은 유지한다. 이번 공개 웹 화면 변경으로 PC 서버를 교체하지 않는다.

## 검토 후 보완과 제한

- 질문이 빈 목차도 실제 저장 후 다시 인식하도록 보완했다.
- 글감 순서를 바꿔도 다른 카드에 입력 중인 해석·역할·장절을 보존한다. 순서만 바뀐 경우 최신 배치를 기준으로 저장하고, 본문 해석이 다른 곳에서 바뀐 경우 기존 버전 검사를 유지하며 비교·확인할 수 있다.
- 주제·연결 이유 편집 중 새 자료가 들어와도 초안과 원래 편집 버전을 보존한다.
- TXT는 서지·쪽수·메모 버전을 포함하지만 PDF 내부 식별자와 원본 서명은 현재 Markdown에만 포함한다. 파일 수준의 원본 식별값이 필요한 글감은 .md로 내보낸다. 두 형식의 식별 정보 통일은 후속 개선 항목이다.

검증: TypeScript 검사 통과. 관련 고립 DB·단위 검사 52개, 모의 PC/휴대폰 화면 검사 17개와 기존 초안 충돌 화면 검사 1개 통과. 실제 기기 동기화 검수는 11월 1일로 보류했다.
