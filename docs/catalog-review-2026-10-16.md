# 도서정보 검토와 실제 검색 검수

2026-10-16 오후 후속 작업. 운영 보고서와 개인 검토표는 외장하드의 비공개 작업 폴더에 보관한다. 이 문서에는 원문, 개인 기록, 인증키를 포함하지 않는다.

## 도서정보와 Zotero

저장된 공식 서지의 분류 보류 원인은 제목 차이 990건, 분류번호 없음 156건, 기타 19건이었다. ISBN·저자·출판사가 같고 부제 또는 병렬 제목만 다른 경우에 한해 공식 분류를 채택하도록 보완했다. 공저자·권차·개정판·해설판 차이와 사용자 수정은 계속 보류한다. PDF의 ISBN/판본 확정 기준은 완화하지 않았다.

미리보기 229건을 재검증해 209권의 공식 분류를 반영하고 20건은 보류했다. 원래 제목·저자·출판사·ISBN은 바꾸지 않았다. 연결된 Zotero 1,608권 중 192권의 관리 컬렉션을 갱신했다. 현재 확정 분류 600권, 후보 855권, 분야 미확인 153권이다. 신규 항목은 0개이며 기존 서지·사용자 컬렉션·태그·메모를 유지했다.

전송 보류 77권 중 38권은 저장된 공식 서지와 대조했고, 38권은 추가 조사가 필요하다. ISBN 없는 1권과 동명 기록은 서로 다른 소장본이라는 사용자 확인을 받았다. 두 도서의 확인 이력을 저장했으며 ISBN·판본 관계는 추정하지 않았다. 이번에 보류 도서를 Zotero로 새로 보내지는 않았다.

PDF 파일명에서 제목·저자 경계를 보완해 333권을 추가 조회했다. 233권에서 서지 후보를 찾았다. 신규 요청 457회, 캐시 활용 648회이며 후보만 비공개 파일에 저장했다. 후보 발견은 동일 판본 확정이나 도서정보 반영 완료를 뜻하지 않는다. 조회 직전에 현재 소유자·도서 버전·문서 서명·일반 도서 처리 범위를 다시 확인한다. 논문·간행물은 제외한다. 유료 AI 호출은 없었다.

## 검색·인용과 OCR

실제 도서·저자 검색 6개를 확인했다. PDF 검색은 5개 용어 중 4개에서 결과를 얻었고, ‘정서중심’은 결과가 없었다. 이 용어가 실제 자료에 있다고 확인된 것은 아니므로 검색 실패로 단정하지 않는다. 반환된 결과 중 20개는 본인 소유 문서·파일 서명·PDF 페이지·저장 구절과 일치했다. 전체 검색 재현율이나 원문 문자 정확도를 검증한 것은 아니다.

FTS 검색의 불필요한 전체 정렬을 제거했다. 정렬 순위로 40개를 읽는 실행 계획을 회귀 검사로 확인했다. 별도 실제 용어 비교에서 새 경로 7.4초, 기존 경로 15초 초과로 중단된 사례를 확인했다. 이후 실제 검색의 캐시가 준비된 상태에서는 약 0.04~2.05초였다. 캐시와 용어에 따라 달라지므로 이를 모든 검색의 속도로 보장하지 않는다.

원본 이미지 3쪽을 실제 대조했다. OCR 오탈자와 인쇄 쪽수 오인식이 남아 있었고, 기존 텍스트 층에도 과거 OCR 오류가 있었다. `text` 방식은 원문 정확도 인증이 아니다. 인용 위치는 PDF 페이지를 기준으로 하며, 직접 인용 전 원본 대조가 필요하다. 손상 PDF 7개는 다른 PDF 파서에서도 열리지 않았다. 그중 384바이트 파일은 PDF 대신 다운로드 안내 HTML이었다. 원본을 수정·삭제하지 않았다.

## 개인 기록과 운영

메모 157개와 독서 이력 419개는 작업 전후 해시가 일치했다. 사용자는 아직 비교할 개인 생각 기록이 없다고 확인했다. 실제 생각 변화 평가와 비교 AI 활성화는 기록·사용자 정답이 준비된 뒤 진행한다. 현재 사유의 지도 기능 검사를 개인 생각 변화의 품질 검증으로 표현하지 않는다.

360/390px 화면, 드래그, 편집 충돌, 기록 휴지통, 도움말 등 브라우저 검사 16개와 오프라인·AI 보조 관련 검사 21개를 통과했다. PC 실행기에서 웹앱과 요청 작업자를 확인했다. 재부팅 후 기존 실행 파일로 시작하며 자동 로그인 실행은 설치하지 않았다. 본인 휴대폰의 실제 재접속과 비공개 PDF 연결 검수는 남아 있다.

변경 후 25개 테이블을 다시 백업하고 새 임시 DB에 복원해 차이 0건을 확인했다. 완료 시점 PDF 색인과 이미지 독립 백업도 확인했다. 원본 PDF 전체 약 362GB는 복사하지 않았으며 여유 공간 400GB 이상의 별도 저장장치가 필요하다.

## 검수와 남은 일

- TypeScript 검사 통과. Windows 전체 단위·통합 검사 77파일 260개 통과.
- 독립 검토에서 발견한 판본 접미사, 공저자, 잘못된 필드 형식, 재조회 범위, PDF 검색 소유자 범위 문제를 재현 후 수정했다. 검색 정렬 개선은 이후 별도 실패→성공 검사와 실제 데이터로 확인했다.
- 추가 검색 결과 233권과 나머지 불확실한 판본·서지 대조는 남아 있다. 일괄 추정 반영하지 않는다.
- 별도 사용자 확인표에는 손상 PDF 7개의 위치와, 이후 필요한 휴대폰 연결·원본 백업 준비만 담았다. 이미 답변한 소장본과 아직 없는 생각 기록은 재요청하지 않는다.
- 대규모 보조 조회 도구는 시작 시 기존 캐시 전체를 읽는다. 이를 스트리밍으로 바꾸는 경미한 성능 개선은 추후 작업이며, 조회 범위 검증과 반영 안전성에는 영향을 주지 않는다.
