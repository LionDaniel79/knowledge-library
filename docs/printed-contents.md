# PDF 인쇄 목차

책 상세의 **추가 도서 정보 → 목차 → 인쇄 목차 펼치기**에서 확인한다. 내장 목차가 없는 일반 도서의 앞 40쪽·뒤 10쪽을 이미 생성된 색인으로 조사하며, 논문·간행물은 제외한다. 단순한 ‘차례’ 언급만으로 채택하지 않고 독립된 목차 제목과 여러 항목형 행을 함께 요구한다.

## 읽고 수정하기

- 보관한 내용은 **목차 후보**다. PDF 추출문에도 기존 OCR 오류가 있을 수 있어 확인 전 표시를 유지한다.
- 원문 링크는 **목차가 있는 PDF 쪽**을 새 탭에서 열어 책 상세 화면을 유지한다. 목차에 인쇄된 장의 시작 쪽을 PDF 쪽수로 환산하지 않는다.
- 최대 4쪽·8,000자까지만 발췌한다. 여러 쪽 목차의 계속되는 페이지가 조건에 맞지 않으면 그 앞에서 멈추므로 전체 목차를 보장하지 않는다.
- **수정**은 직접 정리한 문장을 별도로 저장한다. 당시 발췌문, 파일 버전과 원문 쪽은 보존하며 숨기기·복원·수정 이력을 지원한다.
- PDF가 교체되거나 기본정보 전용으로 바뀌면 현재 검색에서 제외하고 옛 원문 링크를 중지한다. 당시 자료는 이력으로 남는다.
- 검색의 보조 자료에서는 직접 정리한 목차가 있으면 그 문장, 없으면 당시 발췌문을 검색·표시한다.

## 운영

`scripts/collect-printed-toc.ts`는 기본 조사 전용이다. `--apply`를 명시한 개발용 실행만 온라인 보조 자료를 저장한다. 책·메모·독서 이력과 PDF를 변경하지 않는다. `--document`로 표본 하나를 조사할 수 있고 `--limit`은 이번에 확인할 도서 수다.

설정된 E:의 `CATALOG_CACHE_DIR/printed-toc`에 상태·후보·조사 결과를 원자적으로 기록한다. `--output`은 별도 검수 폴더 지정용이다. 작업을 다시 실행하면 변경된 OCR을 재조사하고, 동일 근거·책 버전은 재저장하지 않는다. 사람이 수정하거나 숨긴 목차는 보존한다. 서지·분류·내장 목차 갱신 작업이 끝난 후 실행한다.

결과는 내장 목차 사용, 인쇄 목차 후보, OCR 대기, 조사한 쪽에서 미발견, 원문 확인 필요로 나눈다. 앱의 **자료 준비·오류 확인**에서도 건수를 볼 수 있다. 완료 상태는 이번 조사 완료이며 모든 책의 목차 확보를 뜻하지 않는다.

원문 파일과 쪽별 텍스트를 저장 직전에 다시 확인한다. 원본 연결이 바뀌면 해당 후보를 건너뛴다. 새 OCR 결과나 원본 교체 후 다시 조사할 수 있고, 중단된 작업의 기존 결과는 유지한다. 이 기능은 새 OCR 작업이나 외부 AI/API 호출을 하지 않는다.

## 검수

순수 추출·UI·저장·백업·검색 검사에서 본문 오탐, 논문/간행물 제외, 쪽 범위, 길이 제한, 원문과 수정문 분리, 소유자/책/파일 버전, 실패 시 되돌림, 수정·숨김 보존을 확인했다. 실제 표본 13개 추출문을 읽고 그중 한국어·영어·여러 쪽 목차의 원문 3쪽을 화면으로 대조했다. 본문을 목차로 채택한 표본은 없었으나 기존 OCR의 글자 누락·깨짐은 있었다. 자동으로 교정하지 않고 후보 상태로 보관한다.

2026-10-15 실제 앱에서 『고재수 십계명 강해』의 저장된 목차를 펼치고 원문 링크를 눌러 PDF 8쪽(인쇄 9쪽)을 확인했다. 새 탭에 정확한 파일·쪽수·버전을 유지하고 원래 도서 상세 창이 남는 동작을 검수했다. 사용자의 메모나 목차 수정문은 시험용으로 저장하지 않았다.
