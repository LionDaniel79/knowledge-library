# PDF 검색·열람 안정화

요청: 월별 막대의 바닥선을 통일하고, 원문 검색 선택 시 같은 창에서 비공개 PC 검색으로 자동 연결한다. PDF 관리 메뉴는 제거하고 원본 보관 폴더 지정만 남긴다.

확인한 원인: Tailscale Serve는 정상이나 3001 포트의 프로그램이 종료돼 있었다. 기존 예약 작업의 Triggers가 비어 있어 재로그인·재부팅 뒤 자동 시작이 보장되지 않았다. 유휴 Postgres 연결의 FATAL 08P01 오류가 처리되지 않은 기록도 있었다. 월 이름은 좁은 칸에서 10~12월이 줄바꿈돼 막대 하단 위치가 달라진다.

1. 검색어·문서 범위가 로그인 이후에도 보존되는 허용 경로와 회귀 검사를 작성한다. 비공개 Tailscale 범위·사용자 인증은 유지하고 외부 프록시를 만들지 않는다.
2. 원문 검색 API가 색인 없는 웹 환경에서 PC 검색 경로를 안내하면 같은 창에서 자동 이동한다. PC에서는 검색어를 이어 받아 즉시 검색한다.
3. 관리 메뉴와 별도 검색 이동 버튼을 제거한다. ‘PDF 보관 폴더 설정’은 기존 원본 대조 절차를 재사용하고 웹에서 선택하면 같은 창의 PC 설정으로 연결한다.
4. 유휴 DB 오류 처리, 자동 시작·주기적 재개 설정을 적용한다. 실제 종료 후 자동 복구와 원문 페이지 표시를 확인한다.
5. 그래프 월 이름은 고정된 한 줄 영역에 배치하고 모든 막대의 하단을 정렬한다. 좁은 화면에서도 기하 좌표를 검사한다.
6. 관련 검사·전체 회귀 검사·빌드·배포 후 실제 연결을 검증한다. 다른 작업의 미완료 변경과 원본 PDF는 수정하지 않는다.
