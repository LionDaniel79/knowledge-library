# 요청형 GPT 보조

2026-10-15 추가: **AI 정리 · 태그와 주제**를 구현했다. 저장한 기록 하나에서 최대 5개의 태그·주제를 제안하며 항목마다 원문의 정확한 근거를 검증한다. 전송 미리보기와 기존 비용 한도를 거치며 결과를 개별 채택해야 검색용 보조 정보에 반영된다. 사유의 지도의 주제 연결이나 생각 변화 판단을 자동 확정하지 않는다. 이미 같은 제안이 숨겨져 있어도 명시적으로 다시 채택하면 사용자 확인 이력을 남기고 복원한다. 기록 삭제 후에는 이전 AI 제안을 채택할 수 없다.

기본 화면의 설명은 짧게 줄였다. **필요할 때 AI 도움 → 사용법**에 기록 선택·결과 활용·비용·PC 연결·키·생각 비교의 현재 범위를 모았다. ‘자료 구축 때 AI로 정리’는 과거 정비 출처이며 개발 대기 표시가 아니다.

평소 기록·검색·직접 연결은 AI 호출 없이 동작한다. 보조 기능을 켠 뒤 사용자가 선택 범위를 확인하고 실행한 요청만 등록 PC에서 처리한다. API 키는 PC 환경에만 있으며 앱의 Google 로그인이나 ChatGPT 구독과 별개다. 2026-10-15 사용자 승인에 따라 월 $5·요청당 $0.01 한도를 저장했다. 사용자가 직접 입력한 기존 API 키로 모델 접근과 짧은 시험 문장의 실제 Responses 호출을 확인했다. 개인 기록은 전송하지 않았으며 시험 비용 $0.000035를 월 사용액에 정산했다. 연결 시험의 승인 총상한은 $0.01이다. 개발 정비 예산은 미설정 상태로 유지한다. 이 시험은 연결 검수이며 생각 비교의 성능 평가를 대체하지 않는다.

기능은 기록 1개의 태그 제안(최대 5개), 선택 구절 최대 3개의 설명, 직접 고른 기록 2개의 비교다. 입력 합계 12,000자·출력 2,000토큰 이내이며 넘으면 범위를 줄이도록 한다. API는 선택 원문을 외부로 전송하므로 실행 전 그 내용을 보여 준다. 결과는 별도 제안으로 남고 내 글을 자동 수정하지 않는다. 비교 보조는 실제 평가 통과 전 비활성 상태다.

2026-10-13 확인한 모델은 `gpt-6-luna`, Standard 단가(100만 토큰당 입력 $0.10 / 캐시 입력 $0.01 / 캐시 쓰기 $0.125 / 출력 $0.50)다. 요금표 ID와 모델을 고정하며 다른 모델로 자동 전환하지 않는다. [공식 모델 정보](https://developers.openai.com/api/docs/models/gpt-6-luna), [캐시 사용량 계산](https://developers.openai.com/api/docs/guides/prompt-caching)을 기준으로 한다. 요금 변경 시 코드의 요금표 버전을 갱신해야 한다.

전체 요청의 UTF-8 바이트와 여유분으로 보수적인 토큰 상한을 계산한다. 모든 입력이 비싼 캐시 쓰기인 경우와 최대 출력을 예약한다. 실제 비용은 입력의 캐시 읽기/쓰기 부분을 나눠 계산하며, 추론 토큰은 출력에 이미 포함되어 있으므로 다시 더하지 않는다. 금액은 십진 문자열과 정수 단위로 계산한다.

사용자별 정책 행을 잠근 트랜잭션에서 요청당·월별·개발 정비 한도를 검사한다. 송신 전후가 불명확한 요청은 예약을 유지하며 이전 달의 미확정 예약도 반영한다. 예약·송신·정산/불명/미송신을 구분하고 동일 작업 번호를 재사용한다. 미확정 외부 호출을 자동 재전송하지 않는다. HTTP 전송의 엄밀한 exactly-once는 보장하지 않는다.

Responses API는 `store:false`, 도구 없음, 엄격한 JSON을 사용한다. 이는 응답 저장 옵션이며 모든 제공자 보존 정책을 없애는 의미가 아니다. 거절·불완전 출력·잘못된 근거는 제안으로 반영하지 않지만 발생한 사용량은 기록한다. 인용은 UTF-16 원문 범위와 정확히 비교하고, 생각 비교에는 날짜와 발화 주체 검증도 적용한다. [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Responses 전환 안내](https://developers.openai.com/api/docs/guides/migrate-to-responses).

## PC 연결과 실행

1. 기록의 ‘필요할 때 AI 도움’ → ‘AI 사용 설정’에서 요청당·월별 한도를 직접 정하고 보조 기능을 켠다. 기본 한도는 없다.
2. 같은 화면의 PC 연결에서 연결 파일을 발급받아 비공개 위치에 보관한다. 파일에는 기기 인증 토큰이 있으므로 공유하거나 Git에 올리지 않는다.
3. PC의 `.env.local`에 `LIBRARY_WORKER_CONFIG`(연결 파일 경로), `OPENAI_API_KEY`를 설정한다. API 키는 연결 파일이나 온라인 앱에 입력하지 않는다.
4. `npm run assist:worker`를 실행한다. 웹앱이 온라인에 있어도 이 PC 프로세스가 실행되어 있어야 새 AI 요청이 처리된다. PC가 꺼지거나 키가 없으면 대기한다.
5. 기록 선택 → 전송 내용 미리보기 → 비용 상한과 실제 원문 확인 → 요청 순서로 사용한다. 요청 전에 원문이 바뀌면 다시 미리보기한다.

2026-10-14부터 로컬 언어모델 실행을 폐지했다. 로컬 모델 등록·실행 진입점은 즉시 종료되고 예전 작업기 요청은 인증·DB 접근 없이 410으로 거부한다. 사유의 지도에서도 로컬 분석 설정을 제거했다. 기존 대기 작업을 API로 자동 전환하지 않으며 과거 결과와 판단 이력은 보존한다.

현재 작업기는 `assist:worker` 하나다. PC는 요청 전달과 비용·결과 저장만 맡고 언어모델 연산은 OpenAI API에서 수행한다. 따라서 로컬 모델·GPU·임베딩 모델 다운로드가 필요 없다. PC 연결 의존성을 없애는 서버 실행은 향후 배포 단계에서 별도로 구현한다. 현재 UI는 발췌 한 개를 선택하며 API 스키마는 최대 세 개를 지원한다. 두 기록 비교는 실자료 평가 전 비활성 상태다.

작업기는 전송 전 상태와 수신한 결과를 `private-data/assist/`에 먼저 보관한다. 결과 저장 응답이 유실되면 저장만 다시 시도한다. 전송 후 응답을 잃었으면 ‘비용 확인 필요’로 두고 새 호출도 보류한다. API 사용 내역을 직접 확인한 뒤 해당 카드에 실제 금액을 기록하면 보류가 풀린다. 이전 요청은 다시 보내지 않는다. 기기 연결을 해제하면 해당 PC의 요청 처리가 막히며, 기기를 다시 등록할 때 기존 미확정 비용을 먼저 확인한다.

이 PC용 실행 파일은 `E:/지식서재 작업/private-data/config/start-api-worker.ps1`에 준비했다. 저장소의 로컬 설정을 읽되 작업 디렉터리를 외장하드로 지정하여 작업 기록과 로그도 `E:/지식서재 작업/private-data/assist/`에 보관한다. PC 연결 파일 역시 외장하드의 비공개 설정 폴더에 둔다. 2026-10-15 작업기를 시작했고 앱에 키 준비 완료 상태를 전달하는 것을 확인했다. 운영체제 자동 시작은 등록하지 않았으므로 재부팅 뒤에는 다시 실행해야 한다. 이 앱의 한도는 이 앱에서 예약한 요청을 통제하며 같은 OpenAI 키를 다른 프로그램에서 사용한 비용까지 통제하지는 않는다.

JSON/Markdown 내보내기에는 요청 범위·결과·작성 출처·채택·비용 기록이 포함되고 기기 인증 토큰은 제외된다. 채택한 태그도 검색용 보조 정보로 남으며 원래 메모 본문과 직접 작성한 태그를 덮어쓰지 않는다.
