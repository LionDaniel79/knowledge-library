# 지식서재 구현 현황과 다음 단계

2026-10-16 현재. 과거 실행 기록은 날짜별 검수 문서와 개발 계획에 남긴다.

## 이번에 완료한 일

- **PDF OCR 재개:** Windows 자원 부족(WinError 1450)이 진행 상태 경로를 해석할 때 발생했다. 오류 상태 기록도 실패해 running 표시가 남았다. 반복 경로 해석과 상태 쓰기를 줄이고, 한 작업씩 실행하며 OCR 실행기는 250쪽마다 교체한다. 이미 처리한 책을 다시 훑는 비용을 줄였다. 자원 부족은 PDF 손상으로 기록하지 않는다. 원본·기존 본문·처리한 페이지를 보존한다.
- **Zotero 분류 완료:** 기존 1,608권을 `지식서재` 컬렉션 아래 분야별로 정리했다. 확정 408권, 분류 후보 1,013권, 분야 미확인 187권이다. 후보·미확인은 `분류 검토` 하위에서 구분한다. 도서를 새로 만들지 않았고, 기존 서지·컬렉션·태그·메모를 유지했다. 후속 서지 동기화도 분류 관리 이력을 보존한다.
- **독립 백업:** 최신 25개 테이블을 새 시험 DB에 복원해 차이 0건 확인했다. 도서 10,994건, 기록 157건, 독서 이력 419건, Zotero 연결 1,608건을 포함한다. E:와 물리적으로 다른 D: 사본의 SHA-256도 일치한다. SQLite 색인 약 13.2GB를 일관된 시점으로 복사해 quick_check를 통과했고, 가져온 이미지 1,676개(약 180MB)의 해시도 검증했다. 진행 중 OCR 이후의 페이지는 이번 시점 백업에 포함되지 않는다.
- **배포 준비:** 개인 자료·비밀 설정을 제외한 417개 코드 파일로 전용 비공개 GitHub 저장소 `LionDaniel79/knowledge-library`를 만들었다. 배포 빌드와 비밀 파일 제외 검사를 통과했다. 실제 DB에 제한 계정 `library_web_runtime`을 만들고 읽기·저장 성공, 삭제·이력 변경·스키마 생성·인증 자료 접근 불가를 확인했다. 접속 정보는 이 PC 계정으로만 풀 수 있게 암호화했다.

## 지금 실제로 진행 중인 일

일반 도서 PDF의 남은 OCR과 ISBN/제목·저자 보완 수집이 실행 중이다. 대상은 `E:/전자도서관`의 일반 도서 4,064개다. 논문 2,609개와 간행물 2,636개는 기본정보만 유지한다. 2026-10-16 13:42 KST 집계에서 일반 도서 1,475,338쪽 중 미처리 1,668쪽, 처리율 약 99.89%였다. OCR 결과는 검증 전 문자 인식이며 정확한 본문이나 서지 확인이 모두 끝났다는 뜻은 아니다.

수집기는 앞뒤 페이지의 준비된 근거를 먼저 활용한다. OCR 완료 뒤 최종 판본 조사, 공식 분류, 내장·인쇄 목차 갱신, 원본 기록 보존 검사를 자동으로 이어간다. 모호한 판본이나 찾지 못한 정보는 생성해서 채우지 않는다. 유료 AI 호출은 이 과정에서 하지 않는다.

## 남은 순서와 조건

| 순서 | 다음 작업 | 남은 조건 |
|---|---|---|
| 1 | 남은 OCR 및 후속 서지·목차 수집 완료 확인 | PC·E: 연결 유지. 실행 상태/오류는 외장하드 운영 로그에 저장 |
| 2 | 불확실한 판본·분류 검토 | Zotero 전송을 보류한 77권, 분류 후보·미확인, 손상 PDF 7개. 원본 교체나 소장 판본 확인이 필요한 경우 사용자 판단 |
| 3 | 사유의 지도 검색·생각 변화 평가 | 기능 검사는 통과. 실제 생각 변화 기록과 사용자 정답 판단이 필요. AI가 임의로 개인의 입장 변화 정답을 만들지 않음 |
| 4 | 외부 웹 배포·Google 로그인 검수 | Vercel 연결 도구가 해당 팀 권한을 거부했고 PC 도구는 로그인 정보가 없어 기기 인증 대기. 인증 후 전용 프로젝트/환경변수/허용 도메인/접속 검수 |
| 5 | 휴대폰에서 원문 접근 | 본인 PC·휴대폰의 Tailscale 연결 필요. 비공개 Serve만 사용. 원본 PDF를 웹 서버로 올리거나 공개 포트를 열지 않음 |
| 6 | 전체 PDF 원본 독립 백업 | 원본 합계 약 362GB. D: 여유 공간에 들어가지 않아 별도 충분한 저장 매체 필요. 현재 독립 백업은 색인·이미지·온라인 자료이며 원본 PDF 복사 완료가 아님 |
| 7 | 선택적 MCP 연결 | 읽기 전용 도구는 구현됨. 사용할 클라이언트와 자료 접근 범위 확인 후 활성화. 현재 기본 비활성 |
