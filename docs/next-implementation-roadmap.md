| 독립 백업 | E: 검수 사본과 실제 복원 시험은 완료. 다른 물리 매체에 보관할 백업 필요 |
| 손상·미발견 자료 | 손상 PDF 7개 원본 교체, 모호한 판본 검토, 미발견 소개·표지·목차의 추가 근거 필요 |

## 검수

오전 추가 구현의 최종 결과: 단위·통합 **225개**, 브라우저 **14개**, 수집 실행기 **4개**, 타입·변경 내용 검사 통과. 독립 검토의 중요 문제 1개(소개 이중 변환)도 회귀 검사로 수정했다. 아래 항목은 그 이전 자료 정비·빌드 검수의 기록이다.

- 전체 63개 파일의 **213개 단위·통합 검사**, 타입 검사·배포 빌드 통과. 이후 원문 새 탭 이동 조정의 관련 9개 검사·타입·빌드 통과.
- 배포 추적 6,222개 중 비밀 설정·PDF·색인·개인 자료 포함 **0개**.
- 인쇄 목차 반영 후 메모 **157개**, 독서 이력 **419개**가 기존 백업과 동일했다.
- 새 인쇄 목차까지 담은 실제 **24개 테이블** 백업을 별도 빈 시험 DB에 복원해 불일치 **0건**, 온라인 DB 쓰기 **0회**를 확인했다. 새 백업은 116.7MiB로 로컬 127MiB 파일 한도 이내다.
- 혼합 판본 30건 표본과 후속 검수, 추가 판권면 3개를 합쳐 고신뢰 후보 PDF 36개/서로 다른 ISBN 30개를 대조했다. 중복 소장본을 별도 판본으로 세지 않았다. 다른 권차·OCR 대기·모호한 후보는 검토 상태로 보존했다. 모든 서지 필드가 완전하다는 보증은 아니다.
- 인쇄 목차 추출문 13개·원문 이미지 3쪽을 대조했다. 실제 앱에서 『고재수 십계명 강해』 목차를 펼치고 PDF 8쪽(인쇄 9쪽)을 새 탭으로 열었다. 사용자의 수정문이나 메모를 시험용으로 저장하지 않았다.
- 독립 검토의 중요 문제 4개(오래된 목차·검수 소유자·관계 근거 변경·당시 서지 유실)를 수정하고 회귀 검증했다.
- 실제 제목 띄어쓰기 검색, 공식 분류의 분야 표시, 원문 이동을 브라우저에서 확인했다. 사용자 정의 정답 자료의 검색 유용성 점수는 아직 산출하지 않았다.

전체 OCR이나 외부 운영 연결까지 완료됐다는 뜻은 아니다. 이번 사용법·유지보수에서는 유료 API를 호출하지 않았다. 앞선 GPT 연결 시험은 $0.000035였으며 별도 기록했다. 원본 파일은 보존한다. 등록 서버 IP 조건에 맞춘 공통 API 한도는 앱 설정이며, 과거의 450회 제한을 공식 한도로 설명하지 않는다.
