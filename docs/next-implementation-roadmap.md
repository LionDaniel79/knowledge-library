# 지식서재 구현 현황과 다음 단계

2026-10-16 현재. 과거 실행 기록은 날짜별 검수 문서와 개발 계획에 남긴다.

## 이번에 완료한 일

- **PDF OCR 완료:** Windows 자원 부족(WinError 1450) 복구 후 14:00 KST에 대기 페이지 0쪽으로 완료했다. 마지막 실행에서 4,821쪽을 추가 처리했고 새 오류는 0건이었다. 반복 경로 해석과 상태 쓰기를 줄이고, 한 작업씩 실행하며 OCR 실행기는 250쪽마다 교체한다. 기존 결과와 원본을 보존한다.
- **Zotero 분류 완료:** 기존 1,608권을 `지식서재` 컬렉션 아래 분야별로 정리했다. 확정 408권, 분류 후보 1,013권, 분야 미확인 187권이다. 후보·미확인은 `분류 검토` 하위에서 구분한다. 도서를 새로 만들지 않았고, 기존 서지·컬렉션·태그·메모를 유지했다. 후속 서지 동기화도 분류 관리 이력을 보존한다.
- **독립 백업:** 최신 25개 테이블을 새 시험 DB에 복원해 차이 0건 확인했다. 도서 10,994건, 기록 157건, 독서 이력 419건, Zotero 연결 1,608건을 포함한다. E:와 물리적으로 다른 D: 사본의 SHA-256도 일치한다. SQLite 색인 약 13.2GB를 일관된 시점으로 복사해 quick_check를 통과했고, 가져온 이미지 1,676개(약 180MB)의 해시도 검증했다. 진행 중 OCR 이후의 페이지는 이번 시점 백업에 포함되지 않는다.
- **웹 배포:** https://knowledge-library-inky.vercel.app 에 Next.js 웹앱 배포 완료. 전용 비공개 GitHub 저장소 `LionDaniel79/knowledge-library`도 Vercel에 연결했다. 제한 계정 `library_web_runtime`과 필요한 로그인 설정만 production Secret으로 저장했다. PDF·색인·정보나루/OpenAI/Zotero 키는 배포하지 않았다. 로그인 화면, 비인증 접근 차단, 잘못된 Origin 저장 차단, Google 계정 선택으로 이어지는 실제 인증 흐름을 확인했다. 사용자가 Google 로그인 후 소장 도서 목록이 보인다고 확인했다.

## 데이터 처리 완료 범위

대상은 `E:/전자도서관`의 일반 도서 4,064개다. 논문 2,609개와 간행물 2,636개는 기본정보만 유지한다. 14:37 KST 최종 검사에서 일반 도서 1,475,338쪽은 기존 텍스트 1,129,345쪽, 검증 전 OCR 330,604쪽, 인식된 글자가 없는 15,389쪽이며 미처리 0쪽이다. 처리율은 문자 인식 정확도를 뜻하지 않는다. 손상 PDF 7개는 별도 검토가 필요하다.

ISBN/제목·저자 조회, 판본 조사, 공식 분류 적용, 내장·인쇄 목차 갱신, 원본 기록 보존 검사까지 완료했다. 최종 목차 회차에서 61개를 추가 반영했다. 내장 목차 1,069개와 인쇄 목차 후보 815개가 있으며, 목차 미발견 2,173개와 손상 7개는 채워 넣지 않았다. 메모 157개와 독서 이력 419개는 이전 해시와 같다. 모호한 판본과 미확인 서지 검토는 남아 있다. 유료 AI 호출은 하지 않았다.
