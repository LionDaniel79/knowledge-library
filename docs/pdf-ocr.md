# 로컬 스캔 PDF 문자 인식

## ISBN 페이지 우선 처리

2026-10-15부터 현재 수집 작업은 `--priority identity-first`를 사용한다. 모든 일반 도서의 미처리 앞 12쪽·뒤 8쪽을 먼저 처리하고, 그 뒤 남은 본문으로 돌아간다. 20쪽 이하의 자료는 같은 페이지를 중복 처리하지 않는다. 기본 `book` 순서는 기존 호출과 호환되며 운영 작업은 우선순위를 명시한다.

OCR 작성 프로세스는 하나이며 엔진 두 개가 인식한 결과를 순서대로 저장한다. 순서를 바꿀 때 기존 작업에 `--stop`을 요청해 진행 중 페이지 저장과 종료를 확인한 뒤 재개한다. 원문 문자층과 완료한 OCR은 다시 처리하지 않는다. 진행 파일의 `front_back`·`body`는 이번 실행에서 처리한 페이지 수이며 전체 누적 진척률이 아니다.

`scripts/continue-priority-catalog.ps1`은 앞뒤 페이지가 준비된 책을 본문 OCR과 병행해서 조회한다. OCR 오류·원본 변경·미확인 판본은 자동 확정하지 않는다. 재개할 때 기존 감독 작업이 종료됐는지 확인하고, 동일 출력 폴더의 잠금으로 중복 감독 실행을 막는다.

Windows의 설치된 한국어 OCR을 사용한다. 원본 PDF는 읽기만 하며, 빈 페이지의 문자 인식 결과와 엔진·언어·파일 버전·이미지/텍스트 해시를 로컬 색인에 저장한다. 논문·간행물·범위 확인 대기 자료는 처리하지 않는다. 기존 텍스트는 덮어쓰지 않는다.

설치: `python -m pip install --target .local-python -r scripts/requirements-ocr.txt`

기본 추출 작업이 종료된 뒤 `python -X utf8 scripts/pdf_ocr.py --index <로컬색인> --limit 20`으로 소량 점검한다. `--limit`을 생략하면 남은 페이지를 계속 처리한다. 이미 처리한 페이지는 재시작 때 건너뛴다. 빈 결과·오류 재시도는 `--retry-failed`로 명시해야 한다. 기본 디스크 여유 하한은 8 GiB다. 키·외부 API·유료 모델은 사용하지 않는다.

검색 결과는 `ocr_unverified`다. 인용 저장은 사용자가 실제 PDF 페이지와 대조했다는 확인 후 가능하다. 원시 OCR을 자동 사유 분석이나 ISBN 확정의 근거로 사용하지 않는다. 인식 품질은 스캔·서체·언어에 따라 달라지며 영문 l/I 같은 오독도 가능하다. `ocr_review`는 처리 완료이지 정확성 검수 완료가 아니다.

검증: 합성 이미지 PDF의 한국어/영어 인식, FTS 검색, 원본 해시 보존을 실제 Windows 엔진에서 확인했다. 합성 자동 시험은 재개·제외 범위·빈 결과·디스크 부족·처리 중 원본 변경과 인용 전 확인을 검사한다. 전체 소장 자료의 정확성 검수를 의미하지 않는다.
