# 지식서재 AI 시험 결과와 다음 작업

> **2026-10-14 운영 변경:** 사용자의 최신 결정에 따라 평소 기록·검색·수동 지도는 AI 없이 동작한다. 이전 자동 로컬 비교 작업은 비활성 상태이며, 명시적 GPT 요청만 PC의 새 작업기로 처리한다. [현재 사용 안내](gpt-assistance.md)와 [전체 검수 결과](human-owned-library-acceptance.md)가 아래 과거 시험·계획보다 우선한다.

> **후속 방향:** 아래 시험 결과는 그대로 유효한 과거 기록이다. 이후 사용자가 ‘개발 중 AI 자료 정비, 일상은 직접 작성·판단, 요청할 때만 GPT API’를 선택했으므로 다음 구현은 [새 계획](superpowers/plans/2026-10-13-human-owned-library.md)을 따른다. 로컬 생성 모델 성능 개선을 일상 기록 기능의 선행 조건으로 두지 않는다.

2026-10-13. 승인된 계획을 이어서 이 PC에서 실제 모델을 시험했다. **설치와 실행은 가능하지만, 현재 소형 모델을 생각 변화 자동 분석에 활성화할 수준은 아니다.** 주제 정리, 기록 검색, 수동 생각의 흐름 기능은 별도로 사용할 수 있다.

## 실제 모델 시험

개인 기록 대신 직접 만든 짧은 한국어 기록쌍을 사용했다. 유지·확장·수정·입장 전환뿐 아니라 관계없는 기록, 책 인용, 부정 표현을 포함했다. 아래 결과는 이 앱의 프롬프트·출력 형식·PC에서의 작은 적합성 시험이며 모델의 일반 성능 점수가 아니다.

| 구성 | 결과 | 완료된 비교의 소요 시간 |
|---|---|---|
| Gemma4 E2B 원본, 보조 생성 모델 비활성 | 한 쌍 성공 후 반복 시험에서 메모리 보호 중단 | 성공한 한 쌍 약 23초 |
| 같은 Gemma 주 가중치의 텍스트 전용 파생 모델, 초기 프롬프트 | 6쌍 응답 완료. 인용·발화 주체 검사를 통과하고 기대 관계까지 맞춘 것은 2/6 | 중앙값 21.7초, 상위 95% 지점 23.8초 |
| 텍스트 전용 Gemma, 관계 정의를 명시한 프롬프트 | 두 응답 후 세 번째에서 메모리 보호 중단. 품질 개선 확인 못함 | 완료 응답 약 22~24초 |
| Qwen3.5 2B, 관계 정의를 명시한 프롬프트 | 6쌍 응답 완료. 유효하고 올바른 관계는 1/6 | 중앙값 29.4초, 상위 95% 지점 30.7초 |
| 같은 Qwen의 추가 추론 모드 | 한 쌍에서 180초 제한까지 최종 응답 없음 | 시간 초과 |
| 새 합성 검증 자료 6쌍, 같은 Qwen | 두 응답 후 세 번째에서 메모리 보호 중단. 전체 검증 미완료 | 완료 응답 약 30~32초 |

인용문을 원문 그대로 복사하는 것과 의미를 올바르게 판단하는 것은 별개다. Qwen의 첫 6쌍 시험은 인용 형식·일치 검사를 통과했지만, 책 저자의 말까지 개인의 변화로 해석하거나 여러 관계를 모두 ‘수정’으로 판단했다. 앱은 발화 주체가 맞지 않는 결과를 검토 후보로 저장하지 않도록 검증한다. **근거 문장이 정확해도 해석 오류는 사용자 검토가 필요하다.**

실행 전 여유 RAM 3GiB, 실행 중 1.5GiB 하한을 유지했다. 다른 앱을 종료하거나 보호 기준을 낮추지 않았다. 매번 모델을 내리는 방식의 시간이며 상시 적재 시 속도를 측정한 값이 아니다. 전 시험의 프로세스 최대 메모리를 계측하지 못했으므로 그 값은 미측정으로 남겼다.

## 중단·재개 시험의 범위

합성 기록 2개와 메모리 안의 임시 DB를 사용했다. 실제 검색 모델 실행 중 취소하고, 시험 DB의 작업 임대를 만료시킨 뒤 새 작업기 호출로 재개했다. 실제 비교 모델이 응답한 후 검토 대기 후보 1개를 저장했다. 같은 완료를 재전송해도 후보는 1개, 작업 시도는 2회, 상태는 완료였다. 실제 서재 DB 쓰기는 0회였다.

이 시험의 의미 판정은 기대한 ‘유지’ 대신 ‘수정’으로 나왔다. **통과한 것은 작업 전달·중단 복구·중복 방지이며 AI 해석의 정확도가 아니다.** 실제 Windows 절전·재부팅, 인터넷 장애, Vercel·휴대폰 연결 시험은 아직 남아 있다.

## 다음 작업 순서

1. **기록의 성격 확인.** 가져온 기록에 내 감상과 책 인용이 섞여 있는지 확인한다. 사유의 지도 → 생각의 흐름 → 기록별 ‘날짜·발화 주체·주제 수정’에서 구분한다. 섞인 기록은 문장 단위로 검토하고 원본을 보존한다. 날짜 미상 기록에 가져온 날짜를 대신 붙이지 않는다.
2. **분류·검색 품질 확인.** 제안된 주제 30개를 실제 관심 주제로 정리한다. 같은 주제, 연결된 주제, 전체 미분류 자료의 세 경로가 필요한 구절을 찾는지 검수한다. 카테고리는 검색 범위를 좁히는 단서로 사용하되 다른 분야의 관련 근거를 막지 않는다.
3. **개인 기록의 평가 자료 작성.** 기존 로컬 검수 파일의 기록쌍 30개를 사람이 확인한다. 관련 없는 쌍도 그대로 평가 사례로 남긴다. 정답을 AI가 대신 만들지 않는다. 검색 관련성 평가와 입장 변화 평가를 나눠 기준선을 만든다.
4. **비교 방식을 다시 검증.** 필요한 짧은 근거만 모아 두 기록의 주장과 차이를 구조화하는 방식을 검토한다. 현재 시험한 모델을 그대로 자동 실행하지 않는다. 수정한 프롬프트나 다른 모델은 보지 않았던 자료와 개인 검수 자료로 다시 평가한다. 강화학습·LoRA·DPO는 실행하지 않았다.
5. **품질 확인 후 PC 자동 분석 연결.** 통과한 구성에 한해 실제 개인 후보 몇 건, 네트워크 중단·PC 재시작·휴대폰 조회 순으로 검증한다. 후보는 끝까지 사용자 확인 전 상태로 저장한다. 원격 배포와 상시 실행은 이 단계에서 따로 점검한다.

## 재현과 기록

개인 모델 설정·원문·실제 응답은 Git 제외 경로 `private-data/ai-trial/`에만 있다. 시험 결과를 공개 저장소에 올리지 않는다. 아래 명령은 개발 작업용이며 일반 사용자가 직접 실행할 필요는 없다.

- `npm run ai:benchmark -- --synthetic`: 초기 합성 6쌍.
- `npm run ai:benchmark -- --holdout`: 추가 검증 6쌍. 이번에 이미 사용했으므로 다음 변경의 독립 평가에는 새 자료가 필요하다.
- `npm run ai:verify-runtime`: 실제 모델을 사용하는 임시 DB 중단·재개 검증. 실제 서재 DB에 저장하지 않는다.
- `LIBRARY_AI_CONFIG`: 설치 digest를 고정한 로컬 설정 파일. 실제 운영 설정에는 아직 추가하지 않았다.

파생 모델의 digest는 검사하지만, 현재 설치된 원본 태그만으로 파생 관계를 증명할 수는 없다. 설정 생성기는 원본 digest와 생략한 구성 요소를 추정하지 않고 `unverified`로 남긴다. 재현 시 생성에 사용한 파일·가중치·템플릿도 별도로 확인해야 한다.

후속 검토에서 발견한 모델 HTTP 오류 후 계속 작업하는 문제, 파생 모델 출처 추정, 첫 중단 시험의 시간 제한 누락을 보완했다. 이번 회귀 검사 결과는 [구현·검토 결과](superpowers/reviews/2026-10-13-thought-evolution-result.md)에 기록한다.
