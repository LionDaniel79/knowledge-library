# 내 PC 분석 운영 안내

> **2026-10-14 운영 변경:** 사용자의 최신 결정에 따라 평소 기록·검색·수동 지도는 AI 없이 동작한다. 이전 자동 로컬 비교 작업은 비활성 상태이며, 명시적 GPT 요청만 PC의 새 작업기로 처리한다. [현재 사용 안내](gpt-assistance.md)와 [전체 검수 결과](human-owned-library-acceptance.md)가 아래 과거 시험·계획보다 우선한다.

**현재 상태(2026-10-13 후속 시험):** 모델 설치와 실제 실행은 확인했지만 생각 변화 판정의 품질·안정성이 부족하여 온라인 자동 분석은 활성화하지 않았습니다. 실제 모델을 사용하는 임시 DB의 중단·재개·중복 방지 시험은 통과했습니다. 상세 수치와 다음 순서는 [시험 결과와 다음 작업](local-ai-trial-and-next-steps.md)을 참고하세요. 아래 초기 차단·다운로드 기록은 당시 상태입니다.

자료는 주제 안·연결된 주제·전체 미분류 자료의 세 경로로 찾습니다. 분류는 검색을 돕는 우선순위이며, 사용자가 분야를 명시적으로 제한하지 않으면 다른 분야의 관련 근거도 찾습니다. 관련성과 입장 일치는 다릅니다.

AI가 내 기록 두 개에서 근거 문장을 제시하면 사용자가 유지·확장·수정·입장 전환을 확인합니다. 인용문은 저자의 주장으로, 작성일을 모르는 기록은 날짜 미상으로 취급합니다. 기록을 수정해도 생각 발생 시점이 새로 생기지 않습니다.

2026-10-13: 공식 portable Ollama v0.40.3 파일의 SHA256을 검증했습니다. 첫 실행 요청은 프로세스 생성 전 `blocked by policy`로 거절됐습니다. 자동 승인 검토가 원인이라는 이전 표현은 근거가 없어 정정했습니다. 세부 차단 이유는 제공되지 않았습니다. 사용자 요청으로 재시도한 18:54에는 권한 설정 변경 없이 서버 실행이 성공했습니다. 후속 다운로드·시험 상태는 아래 재시도 기록을 참고하세요. 코드 검사는 실제 모델 성능을 보장하지 않습니다.

설정은 `LIBRARY_AI_CONFIG`가 가리키는 로컬 JSON에 보관합니다. 검색 모델은 `qwen3-embedding:0.6b`, 시험 가능한 비교 모델은 `gemma4:e2b`, `knowledge-library-gemma4-text:e2b`, `qwen3.5:2b`이며 설치 digest를 고정합니다. 시험 허용은 품질 검증 완료를 의미하지 않습니다. 파생 모델의 계보는 설치 태그만으로 추정하지 않고 미확인으로 남깁니다. 로컬 주소만 허용하고 cloud 기능을 끄며 모델을 번갈아 적재합니다. 시작 전 여유 메모리 3GiB, 실행 중 1.5GiB 하한은 이 PC의 보수적인 운영 기준입니다.

검수 준비: `npm run ai:benchmark -- --prepare`. 소유자가 인증한 기존 기록 최대30쌍을 `private-data/ai-trial/personal-review.json`에 저장합니다. 기록 내용·발화 주체·시점과 기대 관계를 확인한 경우에만 `reviewed`를 true로 바꿉니다. 날짜 없는 기록에 임의의 날짜를 붙이지 않습니다. 기존 검수 파일은 덮어쓰지 않습니다.

합성 시험: `npm run ai:benchmark -- --synthetic`. 실제 검수 자료 시험: `npm run ai:benchmark`. 시험은 DB를 읽기만 하며 결과도 로컬에만 저장합니다. 모델 설정이 없으면 `not_run` 보고서를 남깁니다. 매번 모델을 내려 메모리를 확보하므로 현재 측정은 cold 호출이고 warm 속도를 추정하지 않습니다. 프로세스 메모리를 측정하지 못했으면 null로 남깁니다. 실제 검수 정답이 없으면 정확도도 null입니다.

추천 개선은 우선 별칭, 제외한 연결, 수정한 예시를 반영합니다. ‘입장이 다르지만 관련 있음’은 관련 없는 자료라는 학습값으로 바꾸지 않습니다. 충분한 검수 자료가 쌓인 뒤에만 독립 평가를 거친 작은 순위 모델을 사용할 수 있습니다. 생성 모델의 강화학습·LoRA·DPO·외부 업로드는 실행하지 않습니다.


## 분석기와 동기화

사유의 지도에서 ‘기존 태그로 주제 제안’을 누르면 빈도 상위30개 태그로 주제를 제안하며, 자료별 분류 제안은 최대3개입니다. 공식 도서관 분류를 변경하지 않습니다. 거절했던 제안은 다시 만들지 않습니다. 주제 수정·저장 또는 분류 선택으로 직접 확인할 수 있습니다.

설치된 두 모델을 확인한 뒤 `recordInstalledModels`로 로컬 모델 설정 파일을 생성하고 `LIBRARY_AI_CONFIG`에 그 경로를 설정합니다. `npm run ai:worker`가 작업기를 실행하며 Ctrl+C로 중지합니다. 자동 Windows 시작은 등록하지 않습니다. `npm run ai:analyze`는 한 기록을 로컬 시험 파일에만 분석하며 `--apply`를 붙인 경우에만 검토 후보를 온라인 저장합니다.

앱 DB 계정으로 소유자를 확인할 수 없거나 배포된 웹앱과 연결하려면 ‘분석할 PC 연결 관리 → PC 연결 키 만들기 → PC 연결 파일 저장’을 사용합니다. 다운로드한 `knowledge-library-worker.private.json`을 개인 폴더에 두고 `LIBRARY_WORKER_CONFIG`에 경로를 설정합니다. 키는 화면에 한 번만 표시되며 90일 후 만료합니다. 유출되거나 PC가 바뀌면 연결을 해제하고 새로 만듭니다. 연결 키로 책 수정이나 후보 확정을 할 수 없습니다.

작업기는 단일 작업, 120초 임대, 30초 연장으로 동작합니다. 유휴 대기는 5초에서15초, 이후60초까지 늘어납니다. 네트워크가 끊긴 작업은 원문 버전과 임대를 확인해 재시도합니다. 모델 불가·메모리 부족은 자동 반복하지 않고 확인을 기다립니다. 웹앱은 화면이 보이고 처리 중인 요청이 있을 때만 상태를 갱신합니다. 항상 켜두면 무료 DB의 컴퓨팅 한도를 소비할 수 있으며, 비용/속도 실측 전 무료 상시 운영을 보장하지 않습니다.

PDF 원본은 수정하지 않습니다. 이미 추출한 쪽에서 필요한 부분만 읽고 파일의 크기·수정 시각을 다시 확인합니다. 디스크가 없거나 원문이 바뀌면 새로운 PDF 근거는 제외하고 메모 비교를 계속합니다. 전체 PDF 의미 검색 색인은 이번 실행에서 자동으로 시작하지 않습니다.

피드백 순위 평가 입력은 `private-data/thought-ai/ranking-review.json`입니다. 학습100건·독립 평가30건 이상, 책/기록쌍/시점/검색질문 분리와 같은 검색자료에 대한 Precision@5·Recall@20·다른 분야 재현율을 확인합니다. 평가 결과는 검토용이며 검색기를 자동 교체하지 않습니다. `scripts/export-thought-training.ts --consent`는 사용자가 확정한 자기 기록 예시만 로컬로 내보냅니다. 실제 모델 강화학습 명령은 포함하지 않습니다.

실제 모델을 사용하는 임시 DB에서 분석 중단·재개·중복 완료 검증은 통과했습니다. 실제 PC 절전·재시작 실측, Vercel/휴대폰 원격 배포 검수는 미실행입니다. 프로그램 검사와 작업 전달 시험 결과를 실제 의미 판단 성능으로 해석하지 않습니다. 실제 모델 설치·초기 실행 시험 상태는 아래 재시도 기록에 구분했습니다.

## 2026-10-13 검토 후 보완

날짜는 한국 PC와 UTC 서버 모두 같은 달력 날짜로 저장·표시합니다. 원격 작업기는 메모, 주제와 도서/PDF 연결 정보를 페이지 단위로 받습니다. 자료 묶음 전체가 커도 각 응답은 512KiB 이내이며, 완료된 후보의 전체 원문을 매번 전송하지 않습니다. 현재는 매 작업마다 페이지 동기화하므로 대규모 운영 비용은 실측이 필요합니다.

내 생각끼리 비교할 자리는 따로 확보하고, 책의 설명과 PDF 인용은 맥락 자료로 보충합니다. 같은 책에서 나온 여러 메모는 분야 사이 연결의 독립된 근거 여러 개로 세지 않습니다. 메모가 짧아지거나 삭제되면 옛 검색 조각도 함께 정리됩니다. 원문이 달라진 확정 후보를 ‘다시 검토’하면 새 분석 요청이 생기며, 과거 판단과 완료 기록은 남습니다.

작업 요청과 PC의 모델·프롬프트·검색 방식 버전이 일치할 때만 분석을 시작합니다. 실제 응답의 모델 식별값도 검사합니다. 분류 제안의 일부가 유효하지 않더라도 정상 비교 결과는 저장할 수 있습니다.

검수: 단위·DB 검사75개, 화면 검사25개, 기존 Python 검사5개, 타입 검사·배포용 빌드 및 실제 Neon DB의 되돌리기 검사를 통과했습니다. 실제 화면은 1440px/390px에서 확인했습니다. 이 결과는 실제 AI 의미 판단의 정확도 검증과 구분합니다.

## 2026-10-13 저녁 다운로드 재시도

사용자 요청으로 다시 실행한 결과 서버와 두 모델 다운로드 모두 성공했습니다. 검색용 모델은 합성 문장 2개를 실제로 처리했고 1,024차원 검색 벡터를 반환했습니다(약 1.5~1.9초, 두 번의 cold 실행). 이 짧은 시험으로 방대한 서재의 검색 품질이나 전체 처리 속도를 판단하지 않습니다.

생각 비교용 모델은 적재 중 여유 메모리 1.5GiB 하한 보호에 걸려 두 번 중단됐습니다. 비교 답변·정확도는 미측정이며 자동 분석 작업기는 아직 켜지 않았습니다. 미사용 앱을 줄이거나 비교 모델의 메모리 사용량을 조정한 뒤 재시험해야 합니다. 모델은 이미 내려받았으므로 다시 다운로드할 필요가 없습니다.

설치 digest를 기록한 설정은 `private-data/ai-trial/local-models.json`입니다. 시험 결과는 같은 폴더의 `*runtime-smoke-report.json`에 보존했습니다. 서버는 이 PC의 `127.0.0.1`에서만 접속 가능하고 클라우드 AI 기능은 꺼져 있습니다. 마지막 확인에서 적재된 모델은 없었습니다. 자동 시작이나 보안 정책 변경은 하지 않았습니다. 상세 근거는 `docs/local-ai-block-diagnosis.md`에 있습니다.
