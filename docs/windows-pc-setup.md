# Windows PDF 서재 사용

이 문서에서 안내하던 PDF 전용 PC 웹서버·Tailscale 연결·설치기·트레이 소스는 제거되었습니다.
현재 PDF 검색·열람·OCR는 [Windows PDF 서재](../desktop/pdf-library/README.md)를 사용합니다.
웹앱은 소장 도서의 PDF 서지, 기존 메모·인용·쪽수와 독서 이력을 유지합니다.
기존 설치 경로, 예약 작업, 원본 PDF와 SQLite 색인은 이 변경에서 수정하지 않습니다.
로고스/서지 수집기의 암호화 설정 로딩은 desktop/windows/runtime-profile.mjs에서 계속 사용합니다.
