# 기존 서재에 새 Windows PC 연결

이 도구는 본인의 기존 온라인 서재를 새 Windows 10/11 x64 PC에서 사용하도록 구성합니다. 다른 사람의 서재 생성이나 새 DB·웹 배포는 만들지 않습니다. Codex·Git·Node·Python을 직접 설치하거나 명령을 입력하지 않아도 됩니다.

## 기존 PC에서 한 번

1. 설치 ZIP을 풀고 **KnowledgeLibrarySetup.exe**를 엽니다.
2. **기존 PC에서 연결 파일 만들기**에서 현재 PC의 보호 설정과 추가 환경 설정을 확인합니다. 기존 설치가 발견되면 자동으로 채웁니다.
3. 본인이 정한 **12자 이상 암호**로 **.klconnection** 파일을 저장합니다. 파일을 새 PC로 옮기고 암호를 기억합니다. 암호를 채팅에 적을 필요는 없습니다.

현재 구형 설치의 보호 설정은 외장하드 지식서재 작업/private-data/config/web-runtime.private.json입니다. 추가 설정은 기존 소스 폴더의 .env.local입니다. 새 설치에서 다시 내보낼 때는 프로그램 폴더의 connection.dpapi.json만 선택하면 됩니다.

연결 파일에는 기존 제한 권한 DB·Google 로그인 구성과 도서 서지 API 키만 포함됩니다. 도서·메모·PDF, 관리자 DB 계정, GPT·Zotero 키는 포함하지 않습니다. 잊은 연결 파일 암호는 복구할 수 없으므로 기존 PC에서 다시 만들면 됩니다.

책을 저장하면 서지 보완 요청도 함께 보관됩니다. PC 서버가 실행 중이면 별도 창 없이 예스24와 정보나루에서 같은 ISBN의 표지·목차·분류정보를 보완합니다. PC가 꺼져 있으면 다음 실행에 이어집니다. 조회 결과는 PC 자료 폴더에 캐시하며, 새 작업이 없을 때는 확인 간격을 늘립니다. 정보나루를 하루 500회 이상 조회할 새 PC는 해당 PC의 외부 IP 등록과 별도 호출 한도 설정이 필요합니다.

## 새 PC에서

1. 같은 ZIP을 풀고 **KnowledgeLibrarySetup.exe**를 실행합니다.
2. 프로그램·자료·PDF 폴더를 선택하고 연결 파일과 암호를 입력합니다. 프로그램은 NTFS/ReFS 형식의 상시 연결 PC 드라이브에 설치하고, 자료·캐시는 넉넉한 외장하드 폴더를 권합니다. 자료 폴더는 exFAT 외장하드도 사용할 수 있습니다. 기존 지식서재 작업 자료 폴더를 지정하면 그 안의 색인/pdf-library.sqlite를 재사용합니다.
3. Tailscale 설치·본인 로그인을 완료하고 **PC 주소 찾기**로 새 PC 주소를 채웁니다. **비공개 PDF 연결 설정**은 이 PC의 127.0.0.1:3001만 Tailscale 내부로 연결합니다. 다른 공유 설정이 있으면 보존하고 안내합니다.
4. **한국어·영어 OCR 설치**를 누르고 Windows 관리자 승인을 합니다. 이미 설치된 언어는 다시 설치하지 않습니다. 재시작 안내가 나오면 Windows를 다시 시작합니다.
5. **이 PC에 설치**를 누릅니다. Node·Python, PDF/OCR 도구, 소스·앱 빌드, 암호화 설정, 트레이·자동 실행을 준비합니다. 첫 준비에는 인터넷 다운로드와 빌드 시간이 필요합니다.
6. 새 비공개 주소를 기존 로그인 서비스의 허용 주소에 추가해야 할 수 있습니다. 본인 계정의 관리 화면에서 등록하고 Google 로그인합니다. 설치 도구는 계정 관리자 로그인이나 승인을 대신하지 않습니다.
7. **PDF 보관 폴더 설정 → 연결 검사 → 이 위치로 저장**으로 원본 경로를 확인합니다. 새 PC에서 드라이브 문자나 폴더 경로가 바뀌었다면 이 단계가 반드시 필요합니다. 설치에서 폴더를 선택해도 기존 자료의 경로를 자동으로 덮어쓰지는 않습니다. PDF 한 권을 열어 확인합니다.

Vercel 웹앱의 기본 PDF 연결은 기존 PC를 계속 가리킵니다. 새 PC를 기본 PDF 서버로 바꿀 때는 기존 웹 서버의 PC 주소 설정과 로그인 허용 주소를 함께 변경해야 합니다. 새 PC의 비공개 주소로 직접 접속하는 방법도 있습니다. 휴대폰에 PC마다 자료를 중복 등록할 필요는 없습니다.

## 자동으로 준비하는 항목

- 전용 폴더의 Node 24.22.0·Python 3.13.16 공식 ZIP을 검증하고 설치합니다. Windows 전체 PATH나 기존 Python을 변경하지 않습니다.
- 앱 의존성·PDF·Windows OCR 연결 도구를 설치합니다.
- PC 경로를 새로 구성하고 가져온 연결 정보를 해당 Windows 사용자만 해독할 수 있게 보관합니다.
- 트레이·바탕화면·로그인 자동 실행과 1분 간격 서버 복구를 등록합니다.
- 서버는 창을 만들지 않는 전용 실행기로 시작합니다. 트레이만 표시되며 실행 기록은 자료 폴더에 저장합니다.
- 다운로드·빌드 캐시와 큰 임시 작업을 선택한 자료 폴더에 둡니다.

원본 PDF·기존 색인·메모는 설치 과정에서 수정하지 않습니다. 전체 OCR·서지 수집은 자동 시작하지 않습니다. 설치 후 앱의 일괄 등록/OCR 기능으로 필요한 작업을 진행하세요. 서버 자동 실행과 OCR 작업 재개는 별개입니다.

## 오류와 검수

다른 설치의 서버 작업이나 포트 3001이 이미 있으면 기존 작업을 유지하고 설치를 중단합니다. 설치 기록의 마지막 단계를 확인해 재시도합니다. 정상 관리 중인 동일 설치는 소스·실행 도구·완료된 앱 빌드를 재사용합니다.

기존 Windows 환경에서 암호화·설정·압축 경로 방어·실행 도구와 런처·창 생성·포장 검사를 수행합니다. 실제 새 PC에서의 최초 설치, Google 로그인 허용 주소, UAC·재부팅은 해당 기기에서 마지막으로 확인해야 합니다. 설치 파일에 코드 서명이 없으므로 Windows의 실행 확인이 나타날 수 있습니다.

이전 PowerShell 방식으로 설치된 PC는 자동 실행 작업의 전환이 필요합니다. 이 설치 프로그램은 다른 방식의 기존 작업을 덮어쓰지 않습니다. 현재 사용 중인 PC는 별도로 전환했으며, 새 PC 설치본에는 창 없는 실행기가 포함됩니다.

개발용 생성: desktop/windows/package-setup.ps1 -OutputDirectory <새 출력 폴더>. 설치 ZIP은 커밋된 소스만 포함합니다.

공식 참고: [Python의 Windows 설치](https://docs.python.org/3.13/using/windows.html), [Windows OCR 기능 설치](https://learn.microsoft.com/en-us/powershell/module/dism/add-windowscapability), [Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve).
