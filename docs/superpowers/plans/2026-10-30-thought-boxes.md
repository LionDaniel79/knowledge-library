# 보드 상자 구현 계획

> **For agentic workers:** superpowers:executing-plans. 선택 필터는 독립 작업으로 분리하고 공용 파일 충돌을 피한다.

**Goal:** 두 보드의 상자·생각 묶음 목록·선택 보기를 같은 메모 참조로 작동시킨다.
**Architecture:** 기존 writing.chapters를 상자로 재사용한다. 소유자별 작은 상자 목록 API와 기기 조회를 추가하고, 상자별 메모 인스턴스/순서를 명시한다. 보드 외형은 유지한다.
**Tech Stack:** 기존 Next16/React19/TypeScript/Postgres/IndexedDB/Vitest/Playwright.
**Spec:** docs/superpowers/specs/2026-10-30-thought-boxes-design.md

## Global Constraints
- 원본 메모·연결·대기 동기화 명령 보존. 실제 자료 삭제/유료 호출 없이 검사.
- 전체 선택은 도서 제외 복수 필터에만 적용; 비선택은 전체 조회.
- 글감 생성/목록은 보드 아래, AI 설정은 도움 안쪽.

## Review Focus
- 여러 상자에서 같은 원본 메모를 표시할 때 별도 위치/순서 유지.
- 선택 보기와 검색 후에도 기존 상자 내용/좌표 보존.
- 다른 보드 상자 가져오기와 재클릭 중복 방지.
- 상세 편집의 구버전·타계정 거절과 오프라인 저장/동기화.
- 모바일/전체화면에서 상자/메모 번호 입력과 삭제 확인.
