# 도서정보 검토와 실제 사용 검수

> 실행: superpowers:executing-plans. 사용자가 승인한 남은 작업 순서에 따라 직접 진행한다.

## 목표와 제약

도서정보 정비 → 검색·인용 검수 → 사유의 지도 평가 → 휴대폰 원문 접근 순서로 진행한다. 사용자 소장 판본·생각의 변화·기기 연결은 추측하지 않고 필요한 확인만 별도 목록으로 제공한다. 기존 메모·독서 이력과 원본 PDF는 보존한다. 논문·간행물은 기본정보만 유지한다. 로컬 LLM과 유료 일괄 분석은 사용하지 않는다. 기존 feature branch를 계속 사용하며 관계없는 작업을 덮어쓰지 않는다.

## Task 1: 도서정보 정비

- [x] 저장된 서지와 조회 캐시를 대조해 보류 원인을 집계한다.
- [x] 공식 분류의 제목 대조를 보수적으로 개선한다. ISBN이 같고 저자·출판사도 일치하며 제목 차이가 부제/병렬제목뿐인 경우 분류를 채택한다. 권차·판·해설판 차이, 공저자 불일치, 사용자 수정·숨김은 보류한다. PDF의 ISBN 판본 확정 기준은 완화하지 않는다.
- [x] `tests/verified-metadata-match.test.ts`, `tests/verified-classification.test.ts`에서 RED→GREEN 및 원자료 보존·재실행 검사를 한다.
- [x] 실제 자료 미리보기 후 검증된 분류만 기존 트랜잭션으로 반영하고 기존 Zotero 연결의 분류만 갱신한다.
- [x] 원격 보류 77권을 중복·다른 판본·ISBN 누락으로 구분한다. 새 Zotero 항목은 추가하지 않는다.
- [x] 추가 조회가 필요한 자료를 기존 인증·사용량 기록·캐시 경로로 조사하고 사용자 확인 목록을 만든다.

## Task 2: 검색·인용 검수

- [x] 도서명·저자·주제와 실제 PDF 구절 표본으로 검색, 문서/쪽수/인용문 일치를 확인한다.
- [x] 발견된 결함은 재현 검사 후 최소 수정한다. OCR 정확도와 검색 성공 여부를 구분해 기록한다.

## Task 3: 사유의 지도 평가 준비

- [x] 사용 가능한 수동 기록·연결 흐름과 비활성 비교 기능의 경계를 확인한다.
- [x] 사용자 기록을 임의 해석해 정답으로 확정하지 않고 평가용 기록 선택/판단 요청을 최소화한다.

## Task 4: 모바일·운영 준비

- [x] 휴대폰 폭의 화면·오프라인/재접속 자동 검사를 실행한다.
- [x] PC 실행 프로그램의 재시작과 원문 비공개 접속 준비 상태를 점검한다. 본인 기기 연결과 별도 원본 백업 저장장치는 사용자 할 일로 구분한다.

## Task 5: 최종 검수

- [x] 새로운 변경의 독립 검토와 관련 검사, 실제 데이터 보존 지문 확인.
- [x] 현황 문서와 사용자가 해야 할 일만 담은 비공개 검토표를 제공한다.

## Review Focus

다른 판본/권차가 부제로 잘못 처리되는 경우, 번역자만 일치하는 경우, 오래된 출처 버전, 사용자 수정·숨김 보존, Zotero의 기존 수동 컬렉션 보존을 검토한다.
