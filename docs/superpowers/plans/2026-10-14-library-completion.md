# 지식서재 후속 단계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 승인된 연구 기반 설계의 남은 기능을 실제 자료와 연결하고 전체 흐름을 검수한다.
**Architecture:** 기존 서지·정비·주제·기록 저장 구조를 유지한다. 오래 걸리는 수집은 외장하드의 재개 가능한 작업으로 이어가고, 기능은 순차 구현한다. 각 단계의 구현 완료와 전체 자료 처리 완료를 별도로 집계한다.
**Tech Stack:** Next.js/React, TypeScript, PostgreSQL, 읽기 전용 SQLite PDF 색인, 기존 Python OCR.
**Spec:** `docs/knowledge-library-concept.md`, `docs/next-implementation-roadmap.md`, 사용자의 2026-10-14 전체 단계 지속 실행 지시.

## Global Constraints

- 원본 PDF·iReadItNow 원자료·사용자 문장·독서 기록은 보존한다. 수정 이력과 되돌릴 근거를 남긴다.
- 일반 도서 PDF만 상세 처리하고 논문·간행물·범위 미확인은 기본정보만 유지한다.
- AI는 요청한 기능에 한해 API로 사용한다. 키·예산 없는 유료 호출이나 로컬 모델 재설치는 하지 않는다.
- 대용량 자료와 실행 증빙은 `E:/지식서재 작업`에 둔다. 기존 OCR writer를 중복 실행하지 않는다.
- 출처는 접어서 보여 주며, 자동 후보를 사용자 판단으로 표시하지 않는다.
- 이미 승인된 구현을 단계마다 재확인하지 않는다. 실제 자격 증명이나 제공자 권한이 필요한 단계만 구체적인 외부 의존성으로 기록한다.

## 진행 순서와 완료 조건

### Task 1: 판본 수집·검수와 목차 기반 탐색

**Files:** `src/local/curation/pdf-outline.ts`, `src/local/curation/pdf-outline-store.ts`, `src/lib/pdf-outline.ts`, `src/components/pdf-outline.tsx`, `scripts/collect-pdf-outlines.ts`, `db/014_document_references.sql`, `scripts/migrate.ts`, `src/components/curation-details.tsx`, 관련 테스트.
**Interfaces:** `buildPdfOutline(document, rawOutline)`는 원본 식별자·signature·유효한 PDF 쪽수와 항목을 반환한다. `collectPdfOutline(db, owner, source, outline, verifySource)`는 기존 정비 자료와 동일하게 숨김·수정·이력을 지원하는 별도 자료를 원자적으로 저장한다.
- [x] 먼저 잘못된 페이지·중복·목차 없는 파일·논문 제외·오래된 버전·수동 수정 보존·다른 소유자 차단 테스트를 작성해 실패를 확인한다.
- [x] 문서 근거 종류를 추가하고 PDF 내장 목차를 온라인 보조 자료로 보관한다. 인쇄 쪽수로 추측하지 않는다. 목차 문장 검색과 원문 페이지 이동을 연결한다.
- [x] 실제 소량 PDF에 반영해 책·메모·독서 이력이 바뀌지 않는지 확인하고 전체 일반 도서에 확대한다.
- [x] 기존 ISBN 수집 완료를 확인하고 PDF 판본 후보 30건을 표본 검수한다. 검증된 판본만 대량 보완하고 나머지는 검토·미발견·OCR대기·오류로 남긴다.
- [x] 전체 테스트·타입 검사 후 커밋한다. 제공자 소개와 목차를 직접 쓴 메모와 구분해 표시한다.

### Task 2: 분류·주제·다른 표현으로 다시 찾기

**Files:** `src/server/library-search.ts`, `src/components/library-search-panel.tsx`, `src/app/api/library-search/route.ts`, `src/server/thought-topics.ts`, `tests/library-search.test.ts`.
**Interfaces:** `searchLibrary`에 선택 주제 범위(`exact`, `children`, `related`)와 별칭 확장 여부를 추가한다. 승인된 현재 버전의 주제·연결만 검색 확장에 사용한다.
- [x] 소유자 격리, 승인 전/거절 관계 제외, 분야 교차, 별칭과 원문 구분, 조건 변경 시 cursor 무효화 테스트 RED→GREEN.
- [x] 주제 선택·관련 주제 포함·왜 검색됐는지 설명을 화면에 제공한다. 기본 검색은 개인 기록을 우선하고 AI 없이 동작한다.
- [x] 실제 질문 표본으로 찾은 자료와 누락을 기록하고 전체 테스트·타입 검사 후 커밋한다.

### Task 3: 생각 변화의 실사용 흐름

**Files:** `src/components/thought-map/timeline.tsx`, `panel.tsx`, `src/server/thought-candidates.ts`, 관련 테스트.
- [x] 같은 주제의 두 기록을 과거→현재 순서로 비교하고 유지·확장·수정·입장 전환의 이유와 근거를 기록한다.
- [x] 내 생각/인용/확인 전, 날짜 불명, 원문 수정 후 오래된 판단을 구분한다. 판단 수정 이력과 원문 이동을 검증한다.
- [x] 개인 기록을 임의로 재분류하거나 AI 판단을 자동 확정하지 않는다. 관련 회귀 테스트와 UI 흐름을 검증하고 커밋한다.

### Task 4: 운영·중복·복구 검수

- [x] 7개 일반 PDF 오류와 37개 혼합 자료의 원인을 조사하고 원본 교체 필요·범위 검토·복구 가능을 구분한다.
- [x] 이미 계산한 해시로 동일 파일·같은 판본 후보를 보여 주고, 사용자가 연결/해제할 수 있도록 한다. 파일 자동 삭제 금지.
- [x] OCR·수집 진행률과 중단 사유를 관리 화면에 모으고, 동시 실행 방지·외장하드 분리·재개를 검증한다.
- [x] 복원 시험과 색인/원본 백업 범위를 갱신한다. 다른 물리 매체가 없으면 실제 독립 백업 완료로 표시하지 않는다.

### Task 5: 연구 자료와 Zotero

- [x] 설교·논문 자료 모음에 질문·주장·근거·반론을 배치하고 기록과 당시 서지를 보존한다.
- [x] Zotero 공식 문서를 확인해 우선 CSL JSON/RIS 등의 서지 교환과 식별자 연결을 구현·검증한다. 실제 계정/서재 키가 없으면 연결 준비와 실제 양방향 동기화 완료를 구분한다.

### Task 6: 외부 사용·선택형 AI·GPT 접근

- [ ] GitHub/Vercel의 기존 연결·권한을 확인하고 배포 가능한 코드를 검증한다. 본인만 접근할 수 있는 인증과 로그인 콜백을 검증한다.
- [ ] 원문이 없는 외부 환경의 기능 제한 표시와 인증된 PC 연결, PWA 설치·오프라인 기록·충돌 처리를 구현·검수한다.
- [ ] 기존 GPT 요청형 기능의 키/예산·전송 확인·실제 결과 검증을 진행한다. 읽기 전용 개인 MCP 접근을 준비한다.
- [x] 실제 계정 권한이나 비용 동의가 없는 기능은 누락 없이 외부 의존성으로 표시하고 독립 작업을 계속한다.

## Review Focus

다른 사용자의 자료, PDF 변경과 오래된 근거, 사용자 수정/숨김 보존, 승인 전 관계의 검색 확장, 네트워크·저장 실패 후 재실행을 각 소유 기능의 테스트에 포함한다. 마지막에 전체 변경을 새 검토자가 검토하고 중요한 문제를 수정·검증한다. 구현·운영·외부 의존성 상태를 구분하며 목표를 임의로 완료 처리하지 않는다.

## 2026-10-14 실행 상태 보충

Task 1의 30건 표본 검수·17건 반영과 내장 목차 1,115개 저장은 끝났다. 전체 PDF 온라인 판본 조사는 실행 중이며 완료 후 나머지 검증 후보를 같은 보호 조건으로 반영한다. OCR 전체 완료와 기능 구현 완료는 별도다.

Task 2~5의 구현·기술 검수는 완료했다. 실제 기록의 생각 주체·주제·변화와 검색 질문의 정답은 사용자 판단으로 남긴다. 확인된 주제가 없는 현재 자료에 임의의 확인 상태를 생성하지 않았다. 실제 서재에는 테스트 기록을 넣지 않았다.

Task 6의 코드·단위/통합 테스트·배포 빌드·개인 자료 제외 검수는 완료했다. 실제 배포 URL/Google 콜백, 휴대폰 설치, 비공개 PC 네트워크, GPT 키·예산, MCP 클라이언트 권한은 외부 의존성으로 남았다. 상세 절차는 docs/external-access.md. 그래서 실제 활성화까지 뜻하는 위 체크박스는 열린 상태다.
