# 내 기록 통합과 사고 보조 AI 구현
Spec: docs/superpowers/specs/2026-10-25-unified-notes-assist-design.md

1. 달력 세부정보와 상단 버튼 표시 범위를 검수하고 수정한다. 자료 질의에 기록 종류·태그·도서를 추가해 서버/기기 전체 필터 일치를 검수한다. 내 기록에 기존 태그/휴지통/새 기록을 옮기고 독립 메뉴와 이전 진입을 정리한다. 표시 개수는 페이지 표시 오른쪽으로 배치한다.
2. 종합 AI 작업/근거/모델 등록과 모델별 비용/추론/출력 한도를 구현한다. 기존 호출과 작업·결과 호환, 원문/주제 현재성, 임의 출처·연결 거절, 선택 모델 일치, 비용 예약/정산, 안전한 채택을 고립 검사로 증명한다.
3. 현재 조건 기반 대표 기록 선택·전송 미리보기·간결한 요청 목록·펼침 상세·채택·삭제를 연결한다. 숨겨진 모델 설정과 기기별 선택을 구현하고 삭제 재등장 회귀를 고립 모의 검사로 확인한다. 사용법/11월 1일 목록을 갱신한다.
4. 관련 단위·고립 DB·모의 PC/휴대폰 검사와 타입 검사를 통과시킨 후 한 번의 신선한 전체 검토를 받는다. 중요 결함을 재현→수정 검증하고 GitHub/공개 웹에 반영한다. 실제 기기/개인 DB 동기화 검수와 원본 PDF/PC 서버/OCR 변경은 하지 않는다.

Review focus: 전체 필터의 서버/로컬 일치, 이전 notes 진입·태그/휴지통 호환, 조건과 실제 AI 자료 범위 일치, 근거 문장/참조/주제 소속/버전/소유권 검증, 사람 확인만으로 확정, 재시도 중복/부분 채택/자동 재과금 방지, 모델별 비용 상한과 기존 요청 호환, 삭제 후 오래된 기기 목록이 되살아나지 않음, 휴대폰 필터/요청 목록의 밀도와 키보드 안정성.
