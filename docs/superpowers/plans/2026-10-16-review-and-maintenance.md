# 도서 후보 검토와 후속 정비

> 직접 순차 구현: superpowers:executing-plans. 사용자가 4개 후속 기능의 구현을 승인했다.

**목표:** 수집 결과를 앱에서 확인·채택하고, 소개 작성·PDF 재연결·대량 기록 조회까지 실제 사용 흐름으로 완성한다.

**공통 기준:** 종이책/전자책/일반 도서 PDF만 상세 정비한다. 논문·간행물과 손상 PDF 7개 정비·원본 백업은 제외한다. 원본 PDF·개인 메모·독서 이력은 수집으로 바꾸지 않는다. 사람의 판본 판단 없이 후보 ISBN을 확정하지 않는다. API 키·로컬 경로는 공개 응답에 넣지 않는다. AI는 요청한 경우만 사용하며 기존 비용 상한을 유지한다. 이미 승인된 실행을 재확인하지 않고 판본 등 실질 판단만 사용자에게 남긴다.

## 1. 도서정보 후보 검토

- 기존 예스24 결과를 소유자/도서 버전/상세 정비 범위 확인 후 온라인 검토함에 멱등 가져오기한다. 수집 중 생기는 새 후보도 이어서 등록한다.
- `library_catalog_reviews`: 도서·원본 버전·문서 식별 상태·제공자 후보·검토 버전·대기/보류/거절/적용/만료 상태를 보관한다. 백업/복원에도 포함한다.
- `/api/catalog-review`: 소유자 인증, 페이지 조회·검색·필터, 상세 비교, Origin 검증된 결정을 제공한다. 도서 목록에서 진입한다.
- 적용은 동일 판본 확인과 선택 필드 미리보기를 거친다. 원래 값은 기본 보존하고 빈 필드만 기본 선택한다. ISBN 불일치는 묵시적으로 통과시키지 않는다. 같은 책의 다른 후보는 이력을 남겨 만료한다.
- 기존 editBook 트랜잭션/수정 이력·서지 수집 보관 모듈을 재사용한다. 후보 재수입은 사람 결정을 덮지 않는다. 오래된 책/문서는 적용을 거절한다.
- 실패→성공 검사: 다른 소유자/논문 제외, 재수입/재요청 중복 없음, 거절/보류 무변경, 적용 선택 필드·이력·출처, 버전/문서 변경 충돌, 휴지통/원본 메모 보존, 백업 복원. 브라우저에서 비교·필터·확인·충돌을 검사한다.

## 2. 여러 출처를 참고한 소개

- 보관된 제공자 소개와 사용자가 확인해 입력한 리뷰 발췌·출처를 함께 보고 별도의 도서 소개를 작성·수정한다. 사용자 서평과 제공자 소개를 구분하고 자료가 없으면 만들지 않는다.
- 보조 소개는 원래 메모/서평을 덮지 않는다. 검토한 출처와 버전·수정 이력을 보관한다. 원문 페이지를 읽은 전체 요약으로 표시하지 않는다.
- 제공자가 제공하지 않는 리뷰 전문의 무단 대량 수집은 추가하지 않는다. 실제 리뷰 근거가 없는 책은 이 사실을 유지한다.
- 검사: 출처 범위·유효 URL·버전 충돌·원문 무변경·수정 이력·백업/복원.

## 3. PDF 폴더 재연결

- 로컬 PDF 화면에서 새 폴더 입력 → 기존 문서와 연결 검사 → 경로 설정 적용. 클라우드에서는 PC 연결에서 여는 경로를 제공한다.
- 파일을 이동/삭제하거나 식별자를 바꾸지 않는다. 루트 밖 경로·다른 파일·논문 상세 분석을 허용하지 않는다. 기존 인용은 동일 원본임이 확인될 때만 유지한다.
- 검사: 루트 변경, 경로 이탈/다른 파일 거부, 미연결 상태, 동일 원본 인용 유지, 실패 시 기존 설정 보존.

## 4. 대량 기록 조회

- 메모 본문과 독서 이력의 페이지 조회/검색을 추가하고 처음 화면에 불필요한 전체 본문을 보내지 않는다. 통계·달력은 전체 집계 정확도를 유지한다.
- 기록 편집·AI 선택·책별 기록·휴지통·오프라인 초안은 전체 원문을 확인한 뒤 동작하도록 한다. 잘린 미리보기를 원문으로 저장하지 않는다.
- 검사: 페이지 밖 검색/편집, 필터/정렬/날짜, 지연 응답, 통계/달력 동일, 원문 유실 방지.

## 실행·검수

기존 D: 분리 작업공간과 설치된 의존성을 사용한다. 실행 중인 PC 서버의 `.next`는 빌드하지 않고, 검수용 소스 사본에서 최종 빌드한다. 각 기능의 실패→성공 검사·타입 검사 후 커밋하고 전체 검사·별도 최종 검토·웹 배포·실제 계정 화면 검증을 수행한다. 예스24 503은 저장 지점부터 재개하며 인증/권한/사용량 제한은 우회하지 않는다. 실제 기록이 아직 없는 생각 변화 AI 품질 검수와 사용자 실기기 검수는 완료로 표시하지 않는다.
