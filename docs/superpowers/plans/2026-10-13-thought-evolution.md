# Thought Evolution Implementation Plan

> **2026-10-13 후속 계획:** 이 문서는 이전 구현과 검증의 기록으로 보존한다. 앞으로의 작업은 [직접 작성 중심 지식서재 계획](2026-10-13-human-owned-library.md)을 따른다. 개발 중 자료 정비와 운영 중 명시적 GPT 보조를 분리하며, 메모 저장·작업기 시작의 자동 생성 분석과 소형 로컬 모델 상시 비교를 기본 동작에서 제외한다.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 분야 안과 분야 사이에서 관련 자료를 찾고, 근거를 확인하며 내 생각의 변화를 정리하는 개인 서재를 만든다.

**Architecture:** 기존 Next/Neon의 인증·메모·수정 이력을 유지한다. PC에서 분야·주제·어휘·벡터 검색을 조합하고 작은 모델로 두 기록을 비교한다. 사용자 판단을 보존하며 원문·벡터·모델은 로컬에 두고 후보·확정 결과를 온라인에 동기화한다.

**Tech Stack:** 현재 잠금된 Next 16/React 19/Node 24+/TypeScript/pg/Zod/Vitest/PGlite/Playwright, Node SQLite, 로컬 Ollama. GPU 학습 프레임워크는 기본 의존성에 추가하지 않는다.

**Spec:** `docs/superpowers/specs/2026-10-13-thought-evolution-design.md`

## Global Constraints

- 같은 주제의 기록을 시간순으로 놓고 AI가 유지·확장·수정·입장 전환 후보와 근거 문장을 제시한다.
- 책의 주장과 독자의 입장을 구분한다. 사용자가 확인한 변화만 확정한다.
- AI는 내 PC에서 실행하고 결과를 온라인 개인 서재에 동기화한다. PC가 꺼져 있으면 새 분석은 대기한다.
- 초기 입력은 메모 2–6개, 최대 약 4천 토큰, 결과는 짧은 구조화 데이터로 제한한다.
- 동시에 분석 1건만 실행한다. 검색 모델과 비교 모델을 동시에 메모리에 올리는 것을 기본으로 하지 않는다.
- 근거는 실제 저장된 기록의 부분 문자열과 일치해야 한다. 정확한 인용과 해석의 타당성은 따로 검수한다.
- 원본 PDF와 synced sources는 수정하지 않는다. 실제 개인 표본·모델·벡터·성능 로그·토큰은 Git에 넣지 않는다.
- 공식 KDC, 자동 분야 제안, 개인 주제, 책장은 구분한다. 미분류와 다른 분야의 관련 자료도 찾는다.
- 새 모델 학습이나 외부 AI 전송, 유료 서비스 전환, 배포는 이 계획의 자동 실행 범위가 아니다.

## Review Focus

1. 가져온 메모의 생성일이 실제 작성일로 오인되는 경우: 날짜 불명 처리. B1/B4.
2. 종교 분야의 자료가 압도적으로 많은 경우: 미분류·상담·문학의 관련 반론도 검색. B3.
3. 한 문서의 작은 수정이 새로운 생각 변화로 생기는 경우: 독립된 사건을 만들지 않음. B1/C1.
4. 사용자 거절이 반대 의견 전체를 배제하는 경우: 관련성·의견 차이 구별. B4/B5.
5. PC 절전 후 이전 작업과 새 작업이 같은 후보를 저장하는 경우: 임대 토큰·원문 버전·멱등 검증. C1/C2.

## 사용자에게 보이는 변화

`사유의 지도` 안에 `주제별 자료 / 생각의 흐름 / 검토할 후보`를 둔다. 주제를 열면 대표 구절과 관련 자료가 보이고, 후보마다 `같은 주제에서 발견 / 다른 분야에서 발견`을 표시한다. 수정·거절 이유가 다음 탐색에 반영된다. AI가 아직 준비되지 않아도 주제 정리와 수동 타임라인은 쓸 수 있다.

## 검수와 운영 기준

- AI 없이 되는 주제·타임라인 기능은 추론 모델 성능과 분리해 출시한다.
- 실제 메모 평가 30쌍 이상에 사용자가 판정한 정답을 받는다. 별도의 관련 자료 검색 평가도 만든다. 정답이 없으면 결과를 `미검수`로 표시하고 정확도 숫자를 만들지 않는다.
- 변경 후보의 인용 일치율 100%, 다른 소유자 노출 0, 승인 없는 확정 0은 필수다. 개인화 검색은 고정된 평가에서 기존 검색보다 나빠지면 활성화하지 않는다.
- 속도·메모리는 실측하고 ‘즉시 응답’은 약속하지 않는다. 모델 상시 메모리 적재, 자동 시작은 별도 설정으로 명시한다.
- 단위/DB/화면/실제 DB 롤백 검사를 수행하고 마지막에 한 번 독립 리뷰한다. 현재 통과한 기존 검사는 기준선으로 유지한다.
