# PDF 재개와 Zotero 분야 정리

사용자가 2026-10-16 승인한 순서대로 직접 순차 구현한다.

1. OCR의 WinError 1450과 오래된 running 상태를 재현 검사한다. 경로 해석을 작업마다 반복하지 않고, 상태 기록 실패가 원래 예외를 덮지 않게 한다. 실행기를 주기적으로 교체하고 단일 OCR 작업으로 저장 지점에서 재개한다. 기존 PDF와 native text는 보존한다.
2. Zotero의 기존 연결 항목만 지식서재 분야 컬렉션에 배치한다. 미확정은 분류 검토, 기존 컬렉션·태그·서지·개인 메모를 보존한다. 버전 조건과 재실행 안전성, 원격 검증 및 연결 기준 갱신을 검사한다.
3. ISBN/제목 검색·서지·표지·목차 후속 수집기를 재개하고 최종 보존 검사 결과를 확인한다.
4. 사유의 지도 검수·배포 준비·독립 백업에서 지금 실행 가능한 일을 수행한다. 사용자 판단이나 계정 연결이 필요한 실제 조건은 대체하거나 완료로 표시하지 않는다.
5. 관련 검사와 독립 최종 검토, 현황 문서 갱신.

운영 기록과 원격 쓰기 전후 자료는 E:의 비공개 작업 폴더에 저장한다. 기존 feature branch의 작업을 유지하고 관계없는 변경은 되돌리지 않는다. 유료 AI 호출, 새로운 도서 전송, 원본 삭제는 이 작업에 필요하지 않다.
