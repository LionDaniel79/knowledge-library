# 기록 삭제와 선택적 AI 정리

사용자 요청에 따라 직접 순서대로 구현한다. 기존 원문과 수정 이력을 보존한다.

1. 기록 삭제는 휴지통 이동으로 구현한다. 목록·검색·새 AI 요청·새 연결에서는 제외하고 복원할 수 있게 한다. 기존 연구에 담긴 인용 스냅샷과 이력은 유지한다. 소유자·버전·중복 요청을 검증하고 백업에도 휴지통 상태를 담는다.
2. AI 도움과 비용·PC 설정은 짧은 상태와 조작 항목만 표시한다. 상세 안내는 ‘사용법’에서 펼쳐 본다.
3. 명시적 요청에만 실행되는 ‘AI 정리’를 추가한다. 선택한 기록 한 개에서 태그·주제 후보와 정확한 근거를 제시한다. 개별 채택 시 검색용 보조 정보에 저장하며 원문은 수정하지 않는다. 기존 API 한도와 요청 전 미리보기를 그대로 적용한다.
4. ‘개발 중 AI 정리’는 과거 정비의 출처임을 분명히 고친다.
5. GPT 작업자 상태, Zotero 인증/실제 항목 수, 미완료 항목을 확인한다. Zotero 대량 전송과 신규 웹 배포는 이번 수정과 구분해 실제 상태를 보고한다.
6. 삭제/복원/백업/원문 변경 방지/AI 근거/동작 화면을 검증하고 실제 앱에 적용한다.
