# 기록 접근·통합 검색 회귀 수정 계획
Spec: docs/superpowers/specs/2026-10-25-reading-shortcuts-search-design.md
Use superpowers:executing-plans (prior direct sequential execution preference).
1. 모의 PC/휴대폰에서 모든 화면의 새 기록, 태그 검색·삭제, 실시간 책표지+미리 받지 않은 메모 결과, 지도 새로고침 제거를 재현한다. 예상: 현재 코드에서 실패.
2. 상단 CSS/버튼, 기존 태그 선택기 검색 옵션 및 공용 삭제, 직접 검색 컴포넌트/카드 렌더러/독립 페이지와 갱신을 최소 수정한다. 기존 메모 종류·태그·독서 상태는 유지한다. 대상 화면 검사·기존 검색/단위·타입 검사 통과.
3. 신선한 전체 검토1회, 중요한 결함 재현→수정, GitHub/Vercel 반영 및 정적 빌드 확인. 개인 DB/실기 동기화는 검수 목록에 기록하고 실행하지 않는다.
Review focus: 휴대폰 모든 화면의 실제 기록 모달, 태그 삭제의 전체기록 반영/검색 유지/선택 초기화, 초기 페이지 밖 메모·독립 메모/독립 페이지와 늦은 응답, 책 카드 상세/메모 편집 연결, 지도 오류 재시도 보존.
