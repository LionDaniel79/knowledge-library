# PDF 판본 식별과 연구 기반 지식서재 적용

승인 근거: 사용자의 2026-10-14 지시 “순서대로 작업을 진행”, 앞·뒤 ISBN 및 제목 활용, 연구 자료 조사와 구현 반영. 기존 직접 실행 방식과 사람 중심 서재 설계를 이어간다.

## 목적과 범위

기존 서지 수집 흐름을 보완한다. 일반 도서 PDF의 앞 12쪽·뒤 8쪽에 이미 추출된 문자와 OCR 결과를 사용해 ISBN 후보를 찾고, 번호 검산·도서관 응답·제목·권차를 비교한다. 제목 검색은 후보를 만드는 용도이며 제목 일치만으로 판본을 확정하지 않는다. 논문·간행물·범위 확인 대기는 제외한다. 기존 OCR과 API 수집은 중복 실행하지 않는다.

고신뢰 자동 보완은 명시적 ISBN이 있는 원래 텍스트, 동일 ISBN의 도서관 결과, 정확한 제목 일치, 복수 ISBN 모호성 없음, 기존 사용자 편집 없음, 파일·책 버전 일치를 모두 요구한다. OCR만 있는 ISBN·복수 판형·제목만 일치한 결과는 검토 대상으로 저장한다. 빈 ISBN·저자·출판사만 보완하고 원래 값·원문 PDF·메모는 보존한다. 모든 반영에는 전후 수정 이력과 페이지 근거를 남긴다.

## Task 1: 근거 기반 식별 규칙

- `src/local/curation/pdf-identity.ts`: 앞·뒤 범위, ISBN-10/13 검산, 근거 페이지·원문 방법·해시, 제목 변형 정리, 확정/검토/미발견 판정.
- `tests/pdf-identity.test.ts`: 뒤쪽 ISBN, 잘못된 검산, Unicode 하이픈, ISBN-10, 짧은 책 범위 중복, 광고/참고문헌, OCR만 발견, 복수 ISBN, 제목·권차 충돌, 제외 자료를 검증.
- RED→GREEN: `npx vitest run tests/pdf-identity.test.ts`.

## Task 2: 안전한 보완과 검색

- `src/local/curation/pdf-identity-store.ts`: 소유자·문서·버전·사용자 편집을 잠근 트랜잭션에서 확인, 빈 필드 보완, 전후 이력 기록. 재실행 중복 방지.
- `src/server/catalog-provider.ts`: 공식 `srchBooks` 제목 검색, 검색 조건 필수, 오류를 빈 결과와 구분, 같은 호출 기록 사용. 후보 ISBN이 있어도 제목 검색만으로 확정 금지.
- 통합 검사: 다른 소유자, 오래된 버전, 수동 수정, 논문 제외, 후보만 있는 경우 원본 불변, 승인 가능한 판본의 필드 보완과 수정 이력.

## Task 3: 전체 대상 실행

- `scripts/identify-pdfs.ts`: 기본은 읽기 전용 조사. `--online`과 `--apply` 명시 시 조회와 고신뢰 보완. 캐시·검토 보고서는 외장하드에 저장, 전체 대상마다 상태를 남김. 개별 파일 변경·손상은 기록, 인증·한도 오류는 중단. 앞·뒤 OCR 미완료는 별도 집계.
- 기존 서지 수집 캐시를 재사용하고 모호한 결과는 자동 확정하지 않는다. 새 검색 결과는 전용 캐시로 남긴다.
- 전체 오프라인 조사 → 소량 실제 온라인 검수 → 순차 백그라운드 실행. 원문 파일 변경 없음, 메모·독서 기록 변경 없음 확인.
- 전체 온라인 실행은 먼저 후보 수집으로 진행한다. 연구 문서의 판본 검수 목표에 따라 고신뢰 후보 30건을 검토한 다음 대량 `--apply`로 확대한다. 실제 5권 검수 중 앞뒤 OCR 대기 2권과 개정판 제목 불일치 1권은 검토로 남겼다. 표본 2권만 실제 보완을 유지했다.

## Task 4: 연구 기반 전체 개념과 다음 구현 기준

- 논문·도서·표준의 직접 출처를 확인하고 `docs/knowledge-library-concept.md`에 근거와 설계 판단을 구분한다.
- 도서/판본/소장본, 원문/내 생각, 공식 분류/주제/태그, 다시 찾기, 시간에 따른 변화, 근거·수정 이력, 단계적 정보 표시를 정리한다.
- 현재 구현/이번 반영/후속 작업을 구분하고 기존 로드맵을 갱신한다. 표지 이미지 이용 조건에 따라 URL 표시와 이미지 파일 보관을 구분한다.
- 전체 관련 테스트·타입 검사 및 별도 최종 검토. 키·개인 원문은 커밋하지 않는다.

## Review Focus

여러 권차·양장/문고 ISBN, 참고문헌에 나온 번호, OCR 오독, 수동 편집과 동시 수집, 오래된 PDF 페이지, 실제 표지 제공자의 이용 조건. 제목 검색만으로 잘못된 판본을 붙이지 않는지가 최우선이다.
