# ISBN 우선 OCR과 순차 서지 수집

승인 근거: 사용자가 전체 OCR을 기다리지 말고 PDF 앞뒤 ISBN 페이지를 먼저 처리하고, 확인된 책부터 정보나루 조회 및 제목·저자 보완 검색을 진행하도록 명시했다. 기존 실행 계획을 확장하는 범위 안에서 직접 순차 구현한다.

1. 단일 OCR 작업기의 선택 순서를 모든 일반 도서의 앞 12쪽·뒤 8쪽 → 나머지 본문으로 변경하는 선택지를 추가한다. 완료 페이지·원문은 보존하고 논문·간행물은 제외한다.
2. 앞뒤 완료 여부만으로 조회 준비를 판단한다. ISBN 검산·원문과 판본 확인·수동 편집 보호 기준은 유지한다. 제목+저자 AND 검색을 먼저 하고 제목 검색으로 보완한다. 검색 결과만으로 ISBN이나 판본을 자동 확정하지 않는다.
3. 기존 전체-OCR 대기 감독 작업을 교체한다. 앞뒤 OCR과 정보나루 수집을 동시에 진행하되 SQLite OCR 쓰기는 한 작업기만 담당한다. 수집기는 하나만 실행하고 캐시·공통 호출 한도를 유지한다. 초기 조회 이후 OCR 진행분이 생기면 순차 배치를 반복하고, 완료 뒤 기존 분류·목차·보존 검수를 수행한다.
4. 우선순위·재개·중복 방지·본문 OCR 중 조회 가능·저자 검색 전달을 검증한 다음 실제 작업을 재개하고 별도 최종 검토를 받는다.

Ruling: 기존 감독 파일의 전체 OCR 대기는 이번 사용자 지시로 대체한다. 기존 OCR은 중단 요청으로 현재 페이지 저장을 마친 뒤 새 순서로 재개한다. 추가 OCR 작업기를 병렬로 만들지 않는다.

진행: 우선순위 선택·앞뒤 준비 판단·제목/저자 조회·순차 감독 구현. 재현 테스트 RED→GREEN: Python OCR 전체 16개 통과, TS 서지·판본·한도 관련 35개 통과, 타입 검사 통과. 실제 작업 전환과 독립 최종 검토 진행 중.

최종 독립 검토 및 수정: 검토자가 발견한 세 가지 중요 문제를 재현한 뒤 수정했다. (1) 조회 도중 완료된 마지막 앞뒤 페이지를 놓치지 않도록 조회 전 진행값과 비교한다. (2) 동일 버전의 사용자 수정 보호·출판사 충돌 결과를 반복 시도하지 않아 뒤의 책까지 진행한다. (3) 각 다음 단계 전에 OCR 중단·실패·프로세스 소실을 확인한다. PowerShell 실제 감독 스크립트를 가짜 OCR/수집기로 실행하는 재현 테스트 3개 RED→GREEN, TS 보호 결과 재개 테스트 RED→GREEN. 관련 TS 36개, Python OCR 16개·감독 3개 통과. 타입 검사 통과. 추가 검토의 중요 지적은 모두 반영했으며 보류한 경미 지적은 없다.

Ruling: 원문 ISBN을 대조하는 기존 자동 확정 조건을 유지한다. OCR 숫자나 제목·저자 검색은 조회·검토 후보 수집에 사용한다 — 다른 판본의 표지가 잘못 붙는 것을 막기 위함 — 일부 정확한 OCR 결과도 수동 확인이 필요하다.
