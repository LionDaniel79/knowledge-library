# 사유의 지도 사용법과 남은 유지보수

사용자 요청: 사유의 지도에 ‘사용법’ 버튼을 만들고 실제 사용 흐름을 정리한다. 남은 작업을 확인해 구현한다.

## 이번 구현 범위

1. 모든 사유 지도 하위 화면에서 여는 사용법. 빠른 시작과 펼침 안내 6개(기록, 분류, 연결, 변화, 재사용, AI 범위). 현재 구현에 맞는 정확한 버튼 이름과 가상 예시를 사용한다. 작성 중 입력·선택을 유지하고 도움말 열기로 API를 호출하지 않는다.
2. 오프라인 초안 50개 상태에서도 충돌을 해결해 교체한다. 원본 저장 실패·다른 창 변경·계정 경계를 보호하고 새 요청 ID를 사용한다.
3. 제공자 소개의 HTML 문자를 읽을 수 있게 표시한다. 기존 자동 자료는 표시·편집 시작에서만 정리하고 사용자가 확인한 문장과 원래 근거는 유지한다.
4. 앞뒤 ISBN 조사 직후 새로 서지를 반영한 도서만 공식 분류 검사한다. 제목·저자 보완도 동일하게 처리하고 마지막 전체 검사는 유지한다. 진행 중 OCR은 그대로 둔다.
5. 기록의 태그도 공통 표현 연결 후보에 사용한다. 제안 상태만 만들며 사용자 기록·확정 판단·거절 이력은 변경하지 않는다.

## 검수와 결과

- 사용법: 새 버튼 부재 RED → 구현 → PC/360px 표시·입력 유지·추가 요청 0회 GREEN. 닫기 후 초점 복귀 문제 RED → 닫기 전 native dialog.close() → GREEN.
- 임시 기록: 50개 교체 RED → 용량 계산에서 교체 원본 제외, 새 사본 저장 후 원본 제거 → GREEN. 저장 실패·오래된 초안·계정 경계 검사.
- 소개: 제공자 HTML 문자 처리 RED → 공통 텍스트 변환 → GREEN. 기존 소개 편집 화면 RED → 자동 소개만 동일 변환 → GREEN. 사용자 확인 문장과 숨겨진 원근거 보존.
- 수집: 가짜 실행기의 전체 분류 반복 RED → 새 도서 ID 전달 → GREEN. 실제 SQL의 계정별·선택 ID 범위 검사 GREEN.
- 태그: 태그만 공유한 내 기록 연결 후보 0건 RED → 조회와 후보 입력에 태그 포함 → GREEN.
- 초기 전체 검사 66개 파일 223개 통과. 태그 보완 후 전체 최종 검사는 아래 운영 문서에 기록.
- Task 1–5: complete. 최종 66개 파일 225개 검사, 브라우저 14개, 실행기 4개, 타입 검사·변경 내용 검사 통과. 최종 타입 검사에서 시험 데이터의 구조를 명시하도록 조정했고 해당 회귀 검사도 다시 통과했다. 배포·전체 OCR 완료는 이 결과에 포함하지 않는다.

## 독립 최종 검토

중요 문제 1개: 수집 시 정리한 제공자 소개를 표시·편집에서 재정리해 `&lt;주의&gt;` 같은 원래 표기를 잃을 수 있었다.

Final: fixed 중복 문자 변환 — 실제 제공자 파싱 → DB 저장 → 화면·편집, 공식 분류 반영 시 재보관 회귀 검사가 RED→GREEN. 새 소개에는 `plain-text-v1` 형식을 저장하고 재보관 때 유지한다. 기존 소개는 이미 HTML을 제거한 상태이므로 문자 참조만 한 번 해석한다. 사용자 확인 문장은 변환하지 않는다.

형식 표시를 추가하기 전 이번 세션에 저장된 소개도 읽기 전용으로 확인했다. 남은 문자 참조가 있는 4개 행은 전날 수집 캐시와 원문자열이 같았다. 따라서 기존 형식으로 해석하는 것이 맞으며 자료 수정은 하지 않았다.

검토 범위 밖인 배포·유료 GPT 실자료 평가·기존 OCR 내부 구현은 이번 완료로 주장하지 않는다. 실제 작업·자료 정비 현황은 운영 문서와 외장하드 로그를 유지한다.

## 운영 전환

기존 수집 스케줄러를 종료했다. 그 자식 분류 검사도 150개 처리 상태에서 종료되어, 마지막으로 새 서지를 반영한 1권을 대상으로 재실행했다. 해당 1권 공식 분류 반영을 확인했다. 기존 DB 거래는 책 단위이며 원본 파일·메모·독서 이력 삭제는 없다.

개선된 수집기는 별도 로그 디렉터리 `E:/지식서재 작업/검수/priority-isbn-20261015/catalog-incremental`로 이어서 실행한다. 기존 로그는 보존한다. OCR은 동일 프로세스에서 계속 실행하며 새 스캔 결과가 생길 때 수집한다. PC 재부팅 후 자동 실행하는 서비스는 아니다.
