# 지식서재 후속 구현 — 승인 범위

사용자가 남은 작업의 순차 실행을 승인했다. PDF 원본 백업·손상 PDF 7개 정비는 범위에서 제외한다. 물리 기기 확인은 사용자가 담당한다. 기존 개인 기록과 자료 출처·수정 이력을 보존하며, AI는 명시적으로 요청한 범위에서만 사용한다. 기존 API 키 재사용 및 월 $5 / 요청당 $0.01 승인을 유지한다.

## 순서와 완료 기준

1. 예스24 5,749권 보완 작업을 2,000권/10분 대기로 계속한다. 판본 미확정은 자동 채택하지 않고 검토 대상으로 보관한다. 완료 전에 전체 완료로 보고하지 않는다.
2. 손상 7개를 건드리지 않고 기존 정상 PDF의 OCR·검색·인용과 목차 상태를 감사한다. 인식 오류를 원문인 것처럼 확정하거나 내용·페이지를 추정하지 않는다.
3. 사유의 지도 비교 검증을 보완한다. 사용자의 비교 기록이 아직 없으므로 합성 검증과 개인 기록 평가를 구분한다. 실제 평가 없이 품질 통과라고 기록하지 않는다.
4. 기존 읽기 전용 MCP에 원격 HTTPS와 본인 Google 로그인/명시적 동의·PKCE 인증을 추가한다. 책·메모·목록 검색만 제공하며 PDF 파일·관리자 SQL·쓰기 도구는 노출하지 않는다. ChatGPT 계정의 연결 동의는 본인이 수행한다.
5. 기존 GPT 요청·비용 예약·작업 임대·원문 검증을 재사용해 서버 실행을 추가한다. PC가 없어도 이미 요청한 작업을 처리하고, 중복 외부 호출은 막는다. 송신 후 불확실한 요청을 자동 재호출하지 않는다. API 키는 Vercel의 서버 비밀 설정에만 넣는다.
6. 관련 검사·전체 단위 검사·빌드·최종 독립 검토 후 검수된 배포 경로에 반영한다. 개인 기기 확인 목록은 별도 전달한다.

## 구현 결정

Ruling: 기존에 승인한 지식서재 구현의 후속으로 직접 순차 진행한다. 승인 질문을 되풀이하지 않는다. 기능 인터페이스/외부 자료 전송 범위는 기존 읽기 전용 MCP와 사용자가 선택하는 GPT 기록으로 제한한다.

Ruling: 정보 수집은 장시간 작업이므로 진행 확인 후 다음 코드 작업을 이어간다. 전체 수집이 끝나기 전 대기 시간 동안 다른 단계 개발이 가능하다.

Ruling: 실제 사용자 기록이 없는 비교 품질 평가는 완료로 표시하지 않는다. 평가 준비와 수동 비교 흐름은 구현하고, 결과는 사용자 확정 전까지 후보로 유지한다.

## 진행 기록

- 시작: 예스24 366/5,749권, 241권 보완, 판본 검토 74권, 작업 PID 5976 정상.
- 기존 소스 feat/library-mvp의 작업 상태와 운영 배포 사본을 유지한다. 다른 작업과 `sources/`는 변경하지 않는다.
- 정상 PDF 검색 인용 20건 재확인 및 스캔 원본 표본 대조 완료. 각주·만화 OCR 오류는 확인 전 표시를 유지한다.
- 원격 MCP와 서버 GPT 실행 구현 완료. 사용자 기록 부족으로 실제 생각 변화 비교 품질 평가는 대기한다.
- 최종 검토의 토큰 연결 해제 경쟁/서버 대기열 지속성 문제를 재현 후 수정. 실제 Google 로그인 복귀 경로도 추가 검사했다.
- 270개 단위/통합 검사, 12개 관련 브라우저 검사, 타입 검사·격리 배포 빌드 통과. 운영 배포 및 연결 시험을 진행한다.
