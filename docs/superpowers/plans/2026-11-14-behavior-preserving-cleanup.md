# 기능 보존 코드 정리·최적화 계획

**목표:** 화면, API 응답, 데이터와 동기화 의미를 유지하며 확인된 미사용 코드와 중복 탐색만 정리한다.

**범위:** GitHub main의 전체 추적 파일 목록, 웹·서버·기기 복제본·CLI·Windows 진입점 및 테스트 참조를 조사한다. DB 마이그레이션, 운영 자료 수정, 수집기 재시작은 하지 않는다.

1. 변경 전 전체 단위 검사와 정적 의존 그래프를 기록한다. Next proxy 자동 진입점, 테스트 저장소, 수동 유지보수 API와 설치·운영 스크립트는 고아 판정에서 제외한다.
2. `src/components/memo-box/topic-editor.tsx`, `src/components/research-placement-editor.tsx`, `src/server/reocr.ts`의 전체 참조를 재확인한다. 활성 호출이 없는 코드와 해당 구현만 시험하는 옛 검사만 삭제한다. 현재 주제 편집·Windows OCR의 별도 구현은 유지한다.
3. `src/lib/memo-box.ts`의 메모·연결 색인과 그룹별 탐색, 책장 표시의 반복 조회를 최적화한다. 출력 항목·순서·제목·연결 계층을 바꾸지 않는다. 변경 전 함수와 생성 자료를 대조하고 반복 탐색량을 측정한다.
4. 변경 코드의 단위·화면 검사, 전체 단위 검사, 타입 검사 및 프로덕션 빌드로 확인한다. 기존부터 실패하던 시험은 별도로 기록한다. 필수 경로가 불확실하면 삭제하지 않는다.
5. 조사 범위, 삭제 이유, 측정, 통과·실패·미검증 결과를 `docs/operations/code-cleanup-2026-11-14.md`에 기록한다. 검증된 변경만 커밋·운영 반영한다.
