# 내장 목차가 없는 PDF의 인쇄 목차 보완

기존 승인 범위: 전체 개념 문서의 목차·소개 단계, 내장 목차 없는 자료의 인쇄 목차 검수, 전체 단계 지속 실행 지시. 기존 목차·보조 자료 저장과 표시 흐름을 확장한다. 자동으로 생성한 목차를 확정하거나 PDF/인쇄 페이지를 환산하지 않는다.

## 구조

- 일반 도서만 조사하며 기존에 쓸 수 있는 내장 목차가 있으면 그 경로를 우선한다.
- 이미 저장된 앞 40쪽과 뒤 10쪽에서 독립된 ‘목차·차례·Table of Contents·Contents’ 제목과 여러 항목형 행이 함께 있는 쪽을 찾는다. 단순 단어 등장·본문·참고문헌은 목차로 삼지 않는다. 원문 또는 OCR 추출문 모두 확인 전 후보다.
- 최대 4개 원문 쪽·합계 8,000자까지 발췌하여 원문 그대로 보관한다. 초과·조사 범위·OCR 대기를 표시한다. 분할된 행을 추측해 합치거나 장 시작 쪽을 계산하지 않는다.
- `toc` 보조 자료 안의 별도 `printed_toc_excerpt` 형식: documentId, signature, pageCount, pages(page, method, textHash), text, truncated, optional editedText. 원문 쪽·hash·text는 수정 불가, 사용자는 별도 editedText를 수정할 수 있다. 수정·숨김·복원 이력을 기존 구조로 보존한다.
- 검색은 editedText 또는 원문 text를 사용하며 문자열화한 기술 필드를 검색 결과에 노출하지 않는다. 파일 교체·기본정보 전용 변경 시 현재 검색에서 제외하고 이전 링크를 중지한다.
- 개발용 재개 가능한 수집기는 E:에 조사 결과와 상태를 저장한다. 파일·책 버전·소유자·처리 범위를 재검증한다. 기존 서지/분류/내장 목차 작업이 끝난 뒤에만 실제 반영한다.

- [x] 저장 테스트: 소유자·책 버전·파일 변경, 수정·숨김 보존, 재실행, 원자적 원본 근거 저장, 수정 시 source 불변.
- [x] 읽기·검색·UI: 원문 쪽과 인쇄 쪽 구분, 접힌 자료, 확인 전 표시, 원문/수정문 구분, 오래된 원문 링크 중지.

- [x] 기존 순차 수집기 종료 뒤 반영하고 메모·독서 이력 보존을 다시 확인한다. 전체 회귀·타입·빌드 검수.

사용자가 이미 목차 수집·수정·출처 보존·전체 단계 실행을 승인했으므로 반복 승인을 요청하지 않는다. 외부 계정/배포 권한 질문은 기존 질문을 유지하며 이 작업과 독립적으로 처리한다.
