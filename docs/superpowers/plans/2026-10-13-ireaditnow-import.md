# iReadItNow HD 자료와 Google 로그인 구현 계획

> 실행: 이 대화에서 직접 구현한다. 사용자가 실제 소장 자료의 사용과 Google 로그인 전환을 요청했다.

**목적:** 복구한 소장 도서·메모·서평을 기존 개인 서재에서 검색하고 편집하며, 원본 독서 이력을 책별로 보존한다.

**구조:** 읽기 전용 SQLite 변환기 → 개인정보를 제외한 JSON 묶음 → 소유자 인증과 원본 ID 중복 검사를 거친 PostgreSQL 저장. 기존 앱·DB·인증 제공자를 유지한다.

## 제약과 검수

- 사용자가 1,685건 모두 소장 목록이라고 확인했다. 원본의 ownership 숫자값으로 소장 여부를 다시 추정하지 않는다.
- 전자책은 PDF와 구분한다. 형식 누락은 unknown으로 보존한다.
- 상태 코드의 의미는 미확정이다. 독서 세션·페이지 이력을 원본 기록으로 표시하고 완독 통계에 임의로 합산하지 않는다.
- Core Data 날짜는 2001-01-01 기준 초로 해석하고 한국 날짜를 사용한다. 0/누락값을 오늘 날짜로 채우지 않는다.
- 원본 SQLite·계정 DB·쿠키·암호·개인 JSON은 Git 및 공개 preview에 넣지 않는다.
- 원본 라이브러리/엔터티/ID로 재실행 중복을 막고 사용자 편집을 덮어쓰지 않는다. ISBN 중복은 후보로만 보고한다.
- 저장은 한 트랜잭션이며 가져오기 이력·원본 자료를 내보내기에 포함한다.
- Google 로그인도 기존 소유자 이메일 확인을 유지한다. OAuth 콜백은 설치된 Neon SDK가 처리한다.
