# Memo Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for inline execution. One fresh whole-branch review at the end.

**Goal:** 독서 기록 → 주제 분류 → 연결 검토 → 관련 새 기록 → 목차와 글감 내보내기를 완성한다.
**Architecture:** 메모/주제/연결/연구 저장을 재사용한다. 메모의 주제·관계 변경은 한 명령으로 저장하고 새 메모 상자는 기존 snapshot과 전체 기록 편집기를 사용한다.
**Tech Stack:** Next.js/React/TypeScript, PostgreSQL/PGlite, IndexedDB, Vitest, Playwright.
**Spec:** docs/superpowers/specs/2026-10-25-memo-box-design.md

## Global Constraints

- 실제 DB/기기 동기화 검사는 11/1 보류. 스키마 변경 없이 기존 표·JSON 계약 재사용.
- 원문·개인 기록·이력 보존, 유료/자동 AI 호출 없음. PDF/OCR 작업 중지 금지.
- E 단일 코드 폴더에서 별도 브랜치 사용. 기존 직접 구현/배포 승인 적용.

## Review Focus

- 메모와 주제/관계 저장이 부분 성공하지 않으며 요청 재시도가 중복을 만들지 않는다.
- 선택하지 않은 주제·타인의 자료·원문 인용의 내용이 바뀌지 않는다.
- 직접 주제 거절·삭제·휴지통·페이지/필터/전체 정렬을 존중한다.
- 연결된 주제는 실제 근거와 시각적 연결을 구분한다. 과거 판단은 남긴다.
- 목차/배치 저장은 버전 충돌을 지키고 스냅샷·출처가 내보내기에 유지된다.
