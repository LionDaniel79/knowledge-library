# Shared Thought Originals Implementation Plan

> **For agentic workers:** superpowers:executing-plans; 독립적인 글감 목록/연결 제목 UI는 dispatching-parallel-agents로 분리한다.

**Goal:** 같은 생각묶음 원본을 두 보드에서 참조하고 글감별 번호만 별도로 관리한다.
**Architecture:** 기존 library_memo_bundles와 버전 있는 보드 저장을 재사용한다. sourceBox가 있는 기존 사본은 원본 ID 참조로 정리하며 저장 이력을 보존한다. 연결 제목은 기존 연결의 선택 필드로 추가한다.
**Tech Stack:** Next16/React19/TypeScript/Postgres/IndexedDB/Vitest/Playwright.
**Spec:** docs/superpowers/specs/2026-10-30-shared-thought-originals.md

## Global Constraints
- 원본 글감·메모 유지, 오프라인 명령 큐/버전 검사 유지, 실제 자료 시험 쓰기·유료 AI 호출 없음.
- 선택보기 원본 생성 금지, 일반 화이트보드 가리기와 글감의 메모 제외를 분리.

## Review Focus
- sourceBox 여러 단계/삭제된 출발 보드/중복 참조와 기존 메모 번호의 보존.
- 원본 수정이 다른 보드에서도 반영되며 번호·배치는 바뀌지 않음.
- 글감 합치기 중 소스 변경·다른 계정·재시도·오프라인 실행에서 무손실 처리.
- 모바일/전체화면의 메모 순서 입력이 실제로 보이고 눌림.
- 원본 묶음 삭제/오래된 명령이 숨겨진 사본을 다시 만들지 않음.

- 순환 sourceBox, 느린 저장 중 추가 입력, 새 원본 버전 편집, 번호 변경의 원본 순서 독립성, 원본 편집 되돌리기, 일반 가리기와 글감 제외의 독립성을 회귀 검사했다.
