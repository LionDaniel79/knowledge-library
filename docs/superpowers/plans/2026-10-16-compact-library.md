# 지식서재 화면 정리와 입력 기능

사용자 요청 11개 항목을 실행 명세로 삼는다. 기존 흐름을 수정하며 재승인 없이 순서대로 구현한다. 기존 소장본·메모·독서 이력과 Zotero에 이미 보낸 원격 도서는 삭제하지 않는다. Zotero 연동 실행 코드·화면·설정은 제거하고 과거 백업 호환에 필요한 중립적인 외부 연결 보관만 유지한다.

1. 통계/달력 단위 ‘권’, 기존앱 독서량 카드 제거. 날짜와 메뉴 제목을 한 줄로, 설명 제거, 카드/필터 높이 축소. 독서 완료/진행/대기 표시를 색과 접근성 이름으로 제공한다.
2. AI 도움의 실제 서버 오류를 읽기 전용으로 재현해 원인을 수정한다. 유료 호출 없이 상태/미리보기 검증, 기존 비용 상한 유지.
3. 메모 태그 목록/일괄 삭제: 본인 자료만, 휴지통 포함, 검토한 버전이 변했으면 충돌, 요청 재실행 중복 방지, 각 메모 수정 이력 보관. 새 메모 태그는 목록에 자동 반영.
4. 책 표지 파일/URL 선택: 소유자 인증, 이미지 형식/크기 검증 및 메타데이터 제거, 온라인 비공개 저장, 백업 포함. 책 상세는 목록 데이터를 즉시 보여주고 최신 상세를 보완한다.
5. 책 추가 검색/바코드: 제목/ISBN 조회 후보 선택 후 저장, 카메라 권한 실패/미지원 시 이미지·번호 입력 대안. 공개 서지 검색과 설정된 공식 도서관/서점 API 사용. 미설정 서점 키를 가정하지 않는다.
6. Zotero 화면/API/실행 스크립트/테스트/환경 설정 제거. 연구용 표준 서지 내보내기는 연동 없이 유지. 기존 원격 자료는 건드리지 않음.
7. 단위/통합/모바일 브라우저 검사, 독립 검토 1회, 실제 DB 제한 역할과 마이그레이션/백업 검증 후 기존 GitHub/Vercel 배포 경로로 반영.

검증은 태그 동시 수정·타인 자료 보호, 이미지 검증·백업, AI 제한 계정 재현, 검색 실패/후보 선택, 390px/데스크톱 가독성과 카드 크기를 중심으로 한다. 숫자 집계는 유지하고 표시 단위만 바꾼다.
