# 사유의 지도 구현·검토 결과

사용자가 승인한 직접 순차 구현과 카테고리 기반 검색·피드백 개인화를 반영했다. 기존 지식서재 개발 브랜치를 보존하며 원격 게시·배포는 하지 않았다.

## 사용 가능한 기능

- 기존 태그로 주제와 자료 분류 제안, 주제 계층·별칭 편집, 여러 주제 지정, 도서관 분야와 개인 주제 구분.
- 개인 기록의 실제 시점·발화 주체 확인, 시간순 탐색, 직접 연결, 근거를 확인한 후보 승인·거절·재검토 및 수정 이력.
- 같은 주제·이웃 주제·전체 검색, 다른 분야의 관련 자료 확보, 로컬 검색 조각·벡터 캐시와 원문 버전 검증.
- PC 작업 대기열·임대·중단 복구·기기 연결, 원격 자료 페이지 동기화 및 결과 검증 코드.
- 관련성 피드백과 수정 예시 반영, 독립 평가용 소형 추천 순위 모델 도구. 실제 학습 모델은 활성화하지 않았다.

## 한 차례 독립 검토와 수정

검토 범위 `df1b96c..f1697cf`. 심각한 보안·자료 소실 결함은 발견되지 않았다. 주요 지적8개와 작은 지적1개를 실제 코드 경로로 확인하고 한 차례 보완했다.

| 지적 | 수정·검증 |
|---|---|
| SQL 날짜의 UTC 변환으로 하루 이동 | 웹·PC 풀에서 DATE를 문자열로 보존, DTO 방어 처리. 서울/UTC 별도 프로세스 왕복 검사. |
| 원격 전체 자료가 512KiB 초과 | 메모·서지·분류·피드백 등을 크기 제한과 커서로 나눔. 작업 관련 후보의 ID·상태만 전달. 합계 512KiB 초과 자료도 각 페이지 한도 안에서 복원하는 검사. |
| 같은 책의 메모를 독립 근거로 계산 | 메모의 책 ID를 공통 근거 ID로 전달. 선택적인 주제 연결 오류는 별도 저장 지점에서 제외해 정상 비교 보존. |
| 오래된 확정 후보 재검토가 재실행 안 됨 | 재검토 피드백 ID를 작업 버전에 포함하고 두 기록에 새 작업 등록. 완료 이력 유지 검사. |
| 메모 수정 후 옛 검색 조각 잔존 | 최신 메모 조각 집합으로 로컬 색인을 원자적으로 교체. 줄어든 기록·삭제 기록 정리. |
| 책 설명이 개인 기록 비교 자리를 차지 | 비교 가능한 내 기록과 맥락 자료를 별도로 검색. 관련 서지 자료30개가 있어도 개인 기록 비교가 실행되는 검사. |
| 새 원격 PC에 PDF 연결 정보 없음 | 서지 및 PDF ID를 원격 페이지에 포함하고 매 작업 갱신. 빈 로컬 색인에서 실제 임시 PDF 인용 맥락에 도달하는 검사. |
| 실제 모델과 저장된 모델 이력 불일치 | 모델·프롬프트·검색 버전 일치 작업만 수령, 실제 모델 응답 식별값 검사, 전체 구성 변경을 재수집에 반영. |
| 첫 완료 후 화면 미갱신 | 최초 결과 없음→완료 시에도 후보 화면 새로고침. 브라우저 재현 검사. |

검토자가 판단을 보류한 영역: 실제 한국어 해석·검색 정확도, 추론 속도·메모리, 물리 PC 절전·재시작과 유휴 DB 비용, 배포된 휴대폰 접속, 학습 모델의 실제 개선 효과. 모두 미검증으로 남겼다.

## 최종 검사

2026-10-13: Vitest75/75, Playwright25/25, Python5/5, 타입 검사, 빌드 통과. 실제 Neon 마이그레이션007–009 적용 후 실제 DB에서 메모·분류·작업 수령/연장/완료·페이지 전달을 검사하고 시험 자료 전부 되돌림. 실제 서재에서 태그 기반 주제30개를 제안 상태로 만들고 데스크톱1440px/휴대폰390px 표시를 확인했다.

실제 개인 기록30쌍은 로컬 검수 파일에 준비했지만 정답을 임의로 붙이지 않았다. 이 검토 시점에는 실제 모델 실행·다운로드 명령이 프로세스 생성 전 `blocked by policy`로 거절됐고 상세 이유는 제공되지 않았다. 자동 승인 검토 때문이라는 이전 표현은 근거가 없어 정정했다. 우회하지 않았다. 이 검토 시점의 속도·정확도·메모리는 `not_run`/null이며, 무료 상시 운영이나 실시간 결과를 보장하지 않는다. 이후 사용자 요청에 따른 재시도 결과는 `docs/local-ai-block-diagnosis.md`와 `docs/local-ai-operations.md`에 기록한다.

## 구현 결정 기록

1. 실행 중인 기존 전용 개발 작업을 재사용했다. 새 작업 복사는 실행 중 변경을 누락할 수 있다.
2. Windows에서 사용할 수 없는 스킬 보조 셸 대신 같은 범위의 원장·검수 문서를 직접 유지했다.
3. 전역 설치 대신 공식 휴대형 실행 파일의 해시를 확인했다. 실행 차단 뒤에는 다른 경로로 우회하지 않았다.
4. 실제 모델 시험을 미실행으로 남기고 분류·수동 검토·검색 및 동기화 코드의 독립 작업을 진행했다.
5. 개인 평가 자료 준비 전에 공통 날짜·발화 주체 해석기를 구현해 가져온 날짜를 현재 날짜로 오해하지 않게 했다.
6. 작업 재수집은 소유자별 한 트랜잭션에서 일괄 처리했다. 현재 메모 규모보다 훨씬 커지면 잠금·처리 비용을 다시 측정한다.
7. 추천 평가에는 기록쌍·책·시점에 더해 검색 질문 구분을 포함했다. 이전 평가 파일에는 질문 ID가 필요하다.
8. 초기 분류 제안은 기존 태그만 사용한다. 태그에는 폴더명·관리용 표기가 섞일 수 있어 자동 확정하지 않는다.
9. 16GB PC에서 검사 작업은 두 개까지 병렬 실행했다. 다른 사용자 앱은 중지하지 않았다.
10. 원격 전달은 우선 크기가 제한된 전체 페이지 동기화를 사용한다. 증분 동기화 및 장기 비용 최적화는 실측을 거쳐 진행한다.
11. 재검토 이력으로 작업 버전을 변경해 기존 완료 작업을 덮어쓰지 않는다. 이력이 커지면 집계 조회 최적화가 필요하다.
12. 승인된 계획대로 기존 개발 브랜치·개인 자료·진행 원장을 보존한다. 실제 모델 시험이 남아 있어 원장을 완료 처리하거나 삭제하지 않는다.

## 다음 검수 관문

로컬 AI 실행이 가능한 환경에서 두 모델의 설치 식별값을 기록하고, 준비된 개인 비교 자료의 정답을 사용자가 확인한 뒤 속도·메모리·근거 정확도를 측정해야 한다. 충분한 관련성 평가가 쌓인 뒤에만 추천 순위 모델을 검토한다. 생성 모델의 강화학습·LoRA·DPO, 외부 개인 기록 업로드는 이번 작업에서 실행하지 않았다.

## 2026-10-13 후속 실행과 검토

위 초기 검토 이후 설치와 실제 추론을 수행했다. 다운로드 차단은 재현되지 않았다. Gemma 텍스트 전용 구성과 Qwen3.5 2B를 시험했지만 합성 기록 6쌍의 유효한 정답은 각각 2개·1개였고, 반복 시험에서는 메모리 보호 중단도 발생했다. 추가 추론 모드는 한 쌍에서 180초 시간 초과였다. 개인 자료의 정확도는 여전히 미검수다. 현재 자동 분석 작업기는 활성화하지 않았다. 자세한 기록은 [시험 결과와 다음 작업](../../local-ai-trial-and-next-steps.md)에 있다.

실제 검색·비교 모델과 임시 DB를 사용한 중단·재개 검증은 통과했다. 중단된 작업을 두 번째 시도로 완료하고 검토 대기 후보 1개만 저장했다. 같은 완료를 재전송해도 중복되지 않았다. 이 후보의 의미 판정은 기대와 달랐다. 실제 PC 절전·재부팅 및 원격 배포 검증으로 간주하지 않는다.

후속 변경에 대한 독립 검토 1회를 진행했다. Critical 0건, Important 1건, Minor 2건을 확인하고 모두 수정했다.

| 지적 | 수정·확인 |
|---|---|
| 모델의 HTTP 500이 일반 추론 오류로 분류되어 다음 작업도 계속 실행 | 전용 모델 불가 오류로 구분하고 전체 작업기 중단. 실제 어댑터→작업기 경로의 HTTP 500 회귀 검사 RED→GREEN. |
| 현재 원본 태그로 파생 모델의 원본 digest를 추정 | 계보를 미검증으로 표시하고 digest·생략 구성 추정을 제거. 원본이 갱신되거나 없어도 거짓 계보를 저장하지 않는 검사 RED→GREEN. |
| 첫 추론이 너무 빨리 끝나면 중단 시험이 계속 대기 | 30초 제한과 완료/실패 중지 경로 추가. 중단을 확인하지 못하면 명확히 실패. 실제 실행에서 추론 중 취소·재개 확인. |

후속 최종 검사: **Vitest 83/83, Playwright 25/25, Python 5/5**, 타입 검사·빌드·서식 검사 통과. 코드 외 문서에 현재 한계와 후속 순서를 기록했다. 이번 변경에는 마이그레이션이 없으며 실제 Neon DB 쓰기는 수행하지 않았다. 앞선 실제 DB 롤백 검수와 이번 임시 DB의 실제 추론 시험을 구분한다.

다음은 기록 157개의 발화 주체·시점 확인, 주제별 검색 관련성 평가, 사용자가 검수한 개인 기록쌍 30개 기준으로 비교 방식 재평가다. 모델 학습이나 온라인 자동 후보 생성을 시작하지 않았다. 승인된 단계 A의 실사용 품질 관문과 C의 실제 PC·원격 운영 관문은 남아 있으므로 전체 계획은 완료 처리하지 않는다.
