# 보드의 상자와 생각 묶음

사용자의 2026-10-30 최종 10개 요청 및 글감 목록 위치 정정을 구현한다. 앞선 독립적인 생각 묶음 관리 화면을 대신해, 보드에서 메모를 담은 상자 한 개를 생각 묶음으로 사용한다.

- 화이트보드·내 기록·글감엮기의 복수 선택 필터에 실제 전체 선택을 추가한다. 도서 선택 및 단일 정렬/개수 선택은 유지한다. 비선택은 기존처럼 무제한 조회다.
- 연결된 메모의 생각 묶음 저장 버튼과 묶음 연결 탭을 제거한다.
- 두 보드 모두 상자 추가, 제목/정리 작성, 메모·연결된 메모 담기, 확인 후 상자만 삭제를 지원한다. 기존 보드의 writing.chapters 형식을 재사용한다. 한 원본 메모가 여러 상자에 참여할 수 있다.
- 생각 묶음 탭은 모든 소유 보드 상자의 간략 목록을 왼쪽에 표시한다. 클릭해 상세 원문과 정리를 확인하고 원래 상자를 수정한다. 원본 메모는 공통 참조한다. 다른 글감으로 가져온 상자는 메모 참조를 보존한 별도 배치/목차 사본이다.
- 연결 관리에는 연결된 메모와 생각 묶음(상자)의 목록·선택 칸을 둔다. 배지는 각각 원 안의 메/생이다. 미사용 묶음 카운터와 묶음 연결 탭은 없앤다. 선택 보기/전체 보기는 기존 상자와 내용·위치를 유지하며 선택 자료를 겹치지 않는 곳에 추가한다.
- 글감엮기의 목차 상자/넣을 목차/연결된 자료/목차에 넣기/목차 안 정렬 도구 모음을 제거한다. 상자 추가는 보드 동작 줄, TXT/MD 내보내기는 같은 줄에 둔다. 상자 번호와 각 메모의 순서를 직접 입력하고 번호순으로 출력한다. 자료 순서 토글은 제거한다.
- 상자 제목 칸은 기존 가용 너비의 약80%로 줄인다. 기존 자료 순서 잘림은 목록 토글 제거로 해결한다. AI 방향·대상 목차는 AI 도움을 펼친 안쪽에 둔다.
- 사용자의 최종 정정: 글감 목록 제목/검색 칸을 제거하고 그 자리에 글감 생성 칸을 둔다. 생성 칸 바로 아래에 짧은 기존 글감 선택 목록을 둔다. 모두 보드 아래에 남는다.

기존 보드/글감/메모/연결과 미전송 명령은 보존한다. 앞서 생성한 독립 묶음 데이터·복제 코드는 구버전 자료/대기 명령 호환용으로 유지하되 새 관리 UI를 노출하지 않는다. 새 DB나 유료 AI 호출 없이 기존 기기 저장·변경 동기화를 사용한다.
