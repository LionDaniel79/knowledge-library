# 생각묶음 원본과 글감별 구성

사용자의 2026-10-30 9개 정정 요청을 구현한다. 기존의 상자 복사 방식은 사용자가 요구한 원본 연동과 다르므로, 이미 있는 library_memo_bundles를 원본으로 사용하고 보드 상자는 그 ID를 참조한다. 제목·내용·담긴 원본 메모는 공유하고, 배치·상자 번호·메모 번호는 각 글감에서 저장한다.

- 선택보기는 원본을 생성하지 않는다. 같은 ID의 보드 참조도 중복 추가하지 않는다. 기존 sourceBox 사본 연결을 따라 원본으로 모으고 이전 보드 내용은 수정 이력에 보존한다.
- 메모 상자 생각묶음 목록은 제목으로 선택하고 원본 제목·내용·메모를 편집/확인한다. 번호 입력은 글감엮기에서만 표시한다.
- 글감엮기는 상자 밖 메모를 현재 글감에서 빼기 지원, 별도 가려진 메모 UI 제거. 일반 화이트보드의 보이기/가리기는 글감과 독립이다.
- 정렬은 상자 내부 메모를 번호순으로 모으고 상자 크기·위치도 맞추되 원문과 원본 관계는 보존한다.
- 메모 연결에 선택적인 제목을 저장한다. 제목이 있으면 보드 연결 목록·메모 상자 연결 목록/상세에서 표시한다.
- 글감 목록에 선택 칸·선택 글감 합치기·제목 수정. 합치기는 새 글감을 생성하며 원본 글감/메모/원본 생각묶음은 보존한다.
- 기존 기기 저장·동기화·버전 충돌 검사와 사용 중인 PDF/OCR/서지 수집 작업을 유지한다. 실제 사용자 자료 삭제나 AI 유료 호출로 시험하지 않는다.

구현 판단: 별도 원본 테이블을 또 만들기보다 이미 동기화되는 묶음 원본 테이블을 재사용한다. 글감 사이에 사본을 전파하는 방법은 중복/불일치 원인이어서 사용하지 않는다. 저장 자료를 처음 정리할 때 명확한 sourceBox 참조만 같은 원본으로 인식한다.
