# 화이트보드 연결선에서 해제하기

사용자 선택: **연결선을 누른 뒤 ‘끊기’ 버튼 누르기**. 메모는 유지하고 실제 메모 관계를 해제하며 기존 되돌리기를 제공한다. 기존 연결 관리 목록도 유지한다.

## Approaches
- 선택한 선의 ‘끊기’: PC 클릭·휴대폰 터치에 공통 적용 가능. 사용자가 이 방식을 선택했다.
- 선 끝을 끌어 떼기: 연결점 조작이 추가로 필요하며 작은 화면에서 이동·확대 동작과 구분하기 어렵다.

## 조작과 저장
- 선택한 선을 강조하고 보드 위의 작고 안정적인 도구 상자에 메모 쌍과 ‘끊기’를 표시한다. 도구 상자는 확대·축소의 영향을 받지 않는다.
- 선의 터치 영역은 화면상 최소 44px 폭으로 만든다. 선 위에서 끌면 기존 보드 이동을 유지하며 클릭·터치만으로 해제하지 않는다. Enter/Space로 선택, Escape·빈 곳 선택으로 닫는다.
- 연결 해제는 기존 editConnection 명령과 버전 검사를 재사용한다. 성공 시 실제 메모 관계와 선을 해제하며 되돌리기로 복원한다. 오류가 나면 선과 선택을 유지한다.
- 여러 메모 관계가 접힌 묶음 사이의 한 선으로 합쳐진 경우 각 메모 쌍을 따로 표시한다. 선택하지 않은 관계를 함께 삭제하지 않는다.
- 묶음 연결 해제는 해당 두 묶음 사이의 선만 제거한다. 메모·묶음 구성·배치는 유지하고 되돌리기를 제공한다.
- 저장소·API·DB 스키마는 추가하지 않는다. 기존 기기 저장·명령 큐를 그대로 사용한다. 실제 DB/기기 동기화 검수는 11/1 기록에 추가한다.

## 구현 범위와 확인
작은 UI 개선이다. E의 단일 코드 저장소에서 별도 브랜치로 작업하며 새 개발 사본을 만들지 않는다. 순수 로직 검사와 모의 API를 사용하는 PC·터치 브라우저 검사로 해제, 되돌리기, 오류 보존, 묶음·겹친 선을 확인한다. 실제 사용자 자료를 시험용으로 변경하지 않는다.
