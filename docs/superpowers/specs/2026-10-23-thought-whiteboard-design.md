# 사유의 지도 화이트보드

사용자가 지정한 9개 항목을 구현 범위로 삼는다. 기존 서재의 메모를 자유롭게 배치하고 묶고 연결하는 화면이며, 메모를 복사하거나 AI가 관계를 판정하지 않는다.

- 사유의 지도에 화이트보드 탭. 위에는 주제·태그·분야·도서의 검색 가능한 복수 선택과 제목/본문 단어 입력, 검색 버튼. 항목 안에서는 OR, 항목 사이는 AND. 검색 버튼을 누르기 전에는 판의 검색 결과를 바꾸지 않는다.
- 주제 전체는 확인한 주제별 묶음과 미분류 묶음. 여러 주제에 속한 메모는 각 묶음에 표시하되 원본 ID는 같다. 다른 조건은 주제 묶음 안의 메모에도 적용한다.
- 포스트잇 이동, 배경 이동, 확대/축소, 전체 보기. 가까이에 놓으면 관련 연결, 겹쳐 놓으면 연결과 수동 묶음. 놓기 직전에 대상 표시. 클릭만 하거나 이동을 취소하면 연결하지 않는다.
- 메모 연결은 기존 library_connections의 사용자 확인 related 연결이다. 이미 있는 연결의 관계·이유는 덮어쓰지 않는다. 같은 원본을 자기 자신과 연결하거나 반대 방향의 중복 연결을 만들지 않는다. 연결 해제는 기존 연결을 rejected로 바꾸고 이력 유지.
- 묶음 접기/펼치기·이름·이동·해제, 묶음 사이 연결. 묶음 연결은 보드의 명시적인 그룹 간 관계로 보관하고 모든 메모의 조합을 무작정 연결하지 않는다. 주제 묶음도 같은 방법으로 연결한다.
- 배치와 묶음은 새 library_whiteboards에 저장. 메모 본문은 넣지 않고 ID·좌표·묶음·그룹 연결만 보관. 기존 기기 저장소와 변경 대기에 연결한다. 오프라인에서는 기기 거래 후 즉시 반응. 계정별 보드이며 삭제/휴지통 메모는 표시하지 않는다. 검색에서 사라져도 배치와 연결을 지우지 않는다.
- 마우스·터치와 키보드 연결 버튼을 함께 지원. 제목/본문/책/태그를 읽을 수 있는 카드, 좁은 화면에서는 도구 줄 안에서 가로 스크롤. 메모 열기는 기존 편집창 사용.

구현 선택: 별도 유료 서비스나 그래프 의존성 없이 React·SVG·Pointer Events를 사용한다. 화면 배치만 기기에 두는 방식은 새 PC에서 잃으므로 제외하고, 배치와 실제 연결을 분리하여 기존 메모 연결을 재사용한다. 고정 좌표/노드 상한·검증으로 비정상 입력을 제한한다.

사용자 지시: 온라인 동기화 검사는 기존 보류 항목과 함께 2026-11-01에 일괄 수행한다. 그 전에는 실제 Neon 조회·마이그레이션·동기화·전체 자료 재다운로드를 실행하지 않는다. 화면·보드 규칙·격리 저장 검사는 진행한다. 새 DB 구조 적용 및 기기 왕복 검사는 완료로 표시하지 않는다.
