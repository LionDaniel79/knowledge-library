# 생각 묶음과 묶음 연결

2026-10-29 사용자가 제안 전체와 한 메모의 여러 묶음 참여를 승인하고 구현을 요청했다.

분류용 주제와 독립적인 생각 묶음을 만든다. 생각 묶음은 고유 ID, 이름, 정리 내용, 순서 있는 메모 참조를 갖는다. 원본 메모를 복사하지 않으며 한 메모가 여러 묶음에 참여한다. 메모 연결은 메모 연결이고 묶음 연결은 별도의 관계·이유를 갖는다. 어느 쪽의 연결 해제도 다른 쪽을 변경하지 않는다.

접근법: 기존 연결의 연결요소를 자동 묶음으로 삼는 방법은 연결 변경마다 정체성이 바뀌므로 채택하지 않는다. 기존 보드 JSON만 사용하는 방법은 글감 보드 사이에서 내용이 갈라지므로 채택하지 않는다. 승인된 독립 저장 방식을 사용한다. 두 개의 소유자별 버전 테이블(묶음, 묶음 연결)에 저장하고 현재 기기 저장·변경 동기화·충돌·백업 경로에 포함한다.

메모 상자에 생각 묶음 탭을 두고 만들기·이름/정리 수정·메모 검색/복수 선택·묶음 보관해제를 제공한다. 연결된 메모에서 선택한 기존 연결 묶음을 새 생각 묶음으로 저장할 수 있다. 기존 연결된 주제 탭은 묶음 연결로 교체한다. 연결과 이유를 수정하고 끊을 수 있다. 분류용 주제에 근거한 자동 연결 노출은 중단하되 기존 주제/주제 연결 데이터와 메모 연결은 보존한다.

화이트보드는 생각 묶음을 별도 상자로 보여주고 접기·펼치기·이동·연결·해제를 지원한다. 상자끼리 연결해도 구성 메모를 전부 서로 연결하지 않는다. 메모 선택 후 기존 생각 묶음에 추가하거나 새로 만든다. 글감엮기도 같은 생각 묶음을 참조하고 목차로 넣을 수 있다. 글감의 배치는 보드별로 유지한다.

기존 수동 보드 묶음은 보존하고 명시적인 '생각 묶음으로 저장'으로 전환한다. 기존 자동 연결 묶음도 명시적으로 저장한다. 분류 주제끼리의 연결을 생각 묶음 연결로 임의 변환하지 않는다. 보관해제는 원본 메모/내부 연결을 삭제하지 않으며 이력을 남긴다. 휴지통 메모는 활성 목록에서 숨겨도 묶음 참조는 유지한다.

유료 AI 호출·새 의존성 없이 구현한다. 실제 사용자 자료는 검수에서 삭제하지 않는다. OCR/도서수집 작업을 유지하며 웹과 PC 서버에 반영한다.
