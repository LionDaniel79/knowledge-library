# PDF 폴더 일괄 등록

사용자가 승인한 범위: PDF 보관 폴더 설정 안에 연결 검사·PDF 일괄 등록 버튼을 나란히 두고, 빈 서재의 최초 등록과 이후 추가분 등록을 같은 기능으로 제공한다. 독립 설치당 기존 소유자 한 명의 권한을 유지한다.

## 흐름

1. 폴더와 하위 폴더를 읽기 전용으로 조사한다. 신규 후보·기존·변경·논문/간행물 제외·분류 보류 건수를 미리 표시한다.
2. 등록 시작 후 신규 파일을 SHA-256으로 대조한다. 파일명이 다른 동일 파일도 중복으로 처리한다. 기존 제외 이력은 되살리지 않는다. 기존 파일의 내용이 바뀐 경우 자동 교체하지 않고 보류한다.
3. 기본 도서 정보를 먼저 등록한다. 원본은 복사·이동·삭제하지 않는다. 페이지 색인과 앞뒤 ISBN 확인, 제공자 서지·표지·목차 보완은 이어서 처리한다.
4. 원문 ISBN과 정확한 제목으로 판본이 확인된 경우에만 보완한다. 제목 검색·OCR 결과는 검토 후보로 보존하며 사용자가 확인할 수 있다. 개인 수정 사항은 자동으로 덮어쓰지 않는다.
5. PC 작업 상태와 파일별 체크포인트는 색인 옆 SQLite에 저장한다. 창을 닫아도 실행하고, 일시 중지·재개·오류 재시도를 지원한다. PC 재시작 뒤에는 재개를 누른다. 인증키가 없어도 기본 등록·문자형 PDF 색인은 가능하다.

## 제약

- 외장하드 원본과 온라인 인증 비밀정보를 기기 동기화에 추가하지 않는다. 새 도서 정보는 기존 변경분 동기화를 이용한다.
- 논문·간행물은 등록하지 않는다. 분류가 모호하거나 기존 원본이 변경된 자료는 보류한다.
- 유료 AI 호출 없음. 기존 서지 API의 호출 예약·한도 및 안전한 표지 다운로드를 재사용한다.
- 기존 전체 OCR 작업을 새 등록 작업이 임의로 재시작하지 않는다. 스캔 본문은 OCR 대기로 명확히 표시한다.
- 폴더 입력은 로컬 PC 서버에서만 사용한다. 클라우드에서는 기존 검증된 PC 연결로 이동한다.

## 검수

빈 서재·동일 폴더 재실행·이름이 다른 중복·기존 제외·파일 변경·경로 이탈/링크·오류 후 재개·동시 시작·타 소유자·교차 출처 요청을 검증한다. 휴대폰 폭에서 버튼·상태·검토 목록이 넘치지 않아야 한다.
