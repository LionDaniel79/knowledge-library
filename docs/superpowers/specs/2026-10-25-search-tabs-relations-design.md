# 검색 탭과 소장본 연결 개선

사용자의 구체적인 화면/동작 지시를 그대로 구현한다. 기존 Next/React/로컬 질의를 확장하고, 새 DB 구조와 서비스는 추가하지 않는다. 기존에 승인한 순차 구현·공개 웹 반영 흐름을 유지한다. 개인 DB/기기 실동기화 검수는11/1까지 보류하고 가짜 브라우저/고립 DB로 확인한다. 안정 PC/OCR과 원본 PDF는 건드리지 않는다.

- 통합검색 메뉴에 도서 검색/메모 검색/통합 검색 탭을 두고 기본은 도서 검색, 이후 계정·기기별 마지막 탭을 기억한다. 기존 상세 검색은 모달이 아닌 탭 본문이다. 옛 자료검색어/검색대상 및 상단 전역 검색은 제거한다. 통합 검색 탭에는 책·저자·내 생각의 단일 검색을 둔다.
- 메모 검색은 종류→분야→주제→태그→제목→메모 내용 순서다. 주제/태그는 검색 가능한 목록이다. 도서 제목은 입력 시 소장 도서를 바로 제안하고 특정 도서를 선택할 수 있다. 사용자가 답변한 대로 제목은 연결된 책 제목만 검색하고 메모 제목 입력칸은 두지 않는다.
- 소장도서는 분야/책장 다음에 기본정보 검색을 둔다. 검색 중에도 소장도서 화면/필터/정렬/페이지 구조를 유지한다. 책 상세 제목은 본문과 함께 스크롤되게 해 가리지 않는다.
- 소장본 연결은 현재 책을 선택 결과에서 제외하고 첫 유효한 결과를 선택한다. 검색 결과 개수/페이지는 접지 않고 표시한다. 직접 찾기는 선택 후 관계/근거를 확인해 ‘연결’하며, 실제 서버 관계·버전 검증/해제를 유지한다. 다른 책을 열면 이전 선택·결과 상태를 재사용하지 않는다.

구현 선택: 기존 검색 API를 탭에 재사용하는 한 경로로 구성한다. 별도 검색 시스템이나 복제 화면은 만들지 않는다. 연결 검색용 제외 조건을 서버·기기 질의 양쪽에 추가해 전체 개수와 페이지를 일치시킨다. 원본 메모 편집의 빈 책 선택은 유지한다.
