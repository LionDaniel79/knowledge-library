# 주제별 자료 필터·배치 개선

사용자 요청 일곱 항목을 기존 주제별 자료 화면에 반영한다. 기존 직접 순차 구현 지시에 따라 추가 승인 없이 진행한다.

## 선택과 구조

- 자료 목록과 필터를 먼저 표시하고, ‘나의 주제’를 마지막의 접는 관리 영역으로 이동한다. 큰 왼쪽 사이드바를 제거한다.
- 자료 종류 / 도서 분야 / 주제 / 정렬 / 표시 개수 순서. PC는 한 줄, 휴대폰은 두 열로 배치하며 모든 선택 칸 높이를 44px로 맞춘다.
- 주제 순서는 관리 영역의 위·아래 버튼으로 변경한다. 기기별 표시 설정으로 본인 계정에 구분해 저장하며 메모·주제의 업무 데이터나 서버 스키마를 변경하지 않는다.
- 내 기록은 메모·하이라이트, 책은 소장 목록, 책과 내 기록은 두 종류를 한 목록에 표시한다. 기본은 내 기록이다.
- 분야는 기록에 연결된 책의 분야를 사용한다. 연결할 책이 없는 기록은 분야 미분류에 포함한다. 세부 분류번호도 KDC 큰 분류로 맞춘다.
- 주제는 직접 분류와 연결된 책의 주제를 함께 참고한다. 기록에서 같은 주제를 명시적으로 거절했다면 책의 주제로 다시 포함하지 않는다. 자동으로 실제 주제 배정을 추가하지 않는다. 제안·삭제한 주제의 기존 처리 기준을 지킨다.
- 최신순·오래된 순은 작성일/등록일, 분야별은 KDC, 주제별은 주제명, 책별은 연결된 책 제목으로 정렬한다. 같은 키에서는 날짜와 종류/ID로 안정적인 순서를 유지한다. 전체 필터와 정렬을 마친 뒤 페이지를 나눈다.

## 접근

서버에서 전체 자료를 내려받아 정렬하는 방식은 트래픽을 낭비하므로 SQL의 필터·정렬·분할 조회를 사용한다. 기기에 이미 저장된 자료는 같은 기준의 순수 조회 함수로 처리한다. 작은 미리보기 화면도 같은 모델을 쓴다. 기존 다른 메뉴가 사용하는 기본 정렬은 유지한다.

## 검증과 범위

실제 사용자 DB·기기 동기화 검사는 11/1까지 보류한다. 고립된 시험 DB, 순수 함수, 모의 브라우저로 분야·종류·주제 교차 필터, 페이지 경계, 정렬, 빈 제목·미분류, 거절/삭제 주제, 주제 순서의 재열기 보존, 모바일 높이·폭을 검사한다. OCR·PDF 서버를 중지하거나 변경하지 않는다.
