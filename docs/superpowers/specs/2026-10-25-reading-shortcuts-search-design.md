# 기록 접근과 기존 통합 검색 복원

사용자가 지적한 기존 동작을 복원한다. 모든 화면의 상단에 새 기록을 제공하며 휴대폰에서도 글자와 버튼을 보인다. 상단 검색은 다시 만들지 않는다. 메모 검색의 태그 선택은 검색을 유지하고 기존 지문/확인/일괄 삭제 기능을 재사용한다. 통합 검색 탭은 과거 상단 검색과 같은 책/메모 직접 질의, 입력 중 검색, 책 표지 카드와 메모 카드, 독립 페이지를 사용한다. 다른 검색 자료 인덱스로 대체하지 않는다. 사유의 지도 탭 옆 새로고침과 중복 지도 새로고침을 제거하며 오류의 재시도는 유지한다.

기존 카드 렌더러를 부모에서 전달해 책 상세/기록 편집과 표시를 그대로 보존한다. 서버와 기기는 기존 /api/books?q 및 /api/notes?q를 사용하고 전체 자료가 메모리에 있을 때만 기존 직접 필터를 사용한다. 태그 삭제는 기존 명령으로 기록의 태그만 제거한다. 새 DB/유료 API·실제 개인 자료 변경·PC/OCR 변경은 없다. 실제 동기화 검수는11/1 유지.
