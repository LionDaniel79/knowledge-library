# 내 기록 통합과 사고 보조 AI

사용자의 상세 지시와 기존 직접 순차 구현 선호에 따라 추가 승인 대기 없이 구현한다. 기존 개인 기록·이력·월 5달러 상한·외장 PDF와 PC/OCR 실행은 보존한다. 실제 DB/기기 동기화 검수는 11/1까지 보류하며 고립 DB/모의 화면/공급자 응답 검수만 한다. 기존에 연결한 OpenAI 키를 재사용하고 키를 읽거나 변경하지 않는다.

## 화면
- 독서 달력의 완독 행에 날짜 수정 오른쪽 세부정보를 두고 실제 bookId로 기존 상세 창을 연다.
- 상단 책 추가는 나의 서재/소장 도서에만 표시한다.
- 기록과 생각의 독립 메뉴를 없애고 사유의 지도 첫 탭을 내 기록으로 통합한다. 이전 notes 진입은 새 탭으로 안내한다.
- 필터는 종류(미분류 포함), 도서분야, 검색 가능한 도서명, 주제, 기존 태그 관리/선택, 정렬, 본문 검색이다. 전체 자료 기준으로 함께 적용하고 바뀌면 첫 페이지로 돌아간다. 표시 개수는 아래 페이지 표시 오른쪽으로 옮겨 기기별 저장을 유지한다.
- 기록 편집/새 기록/태그 관리/휴지통·복원·비우기를 새 화면에 연결한다. 책 자체의 분야 검색은 소장도서/통합 검색을 사용한다.

## AI
별도 자동 분석 대신 명시적으로 요청한 자료의 사고 보조를 강화한다. 기본은 현재 필터에 맞는 기록을 사용한다(선택 질문의 답변이 오면 반영). 대표 기록을 제한된 수로 고르고 자료 수·발췌 범위를 확인 후 전송한다. 전체 자료를 분석했다고 과장하지 않는다.
- 한 번의 종합 검토에서 메모 간 연결, 주제 간 연결, 새 주제, 글감/목차 방향을 제안한다. 사용자는 원하는 제안만 확정한다.
- 모든 제안에 실제 전송한 메모의 정확한 근거 문장과 식별자를 붙인다. 주제 연결은 실제 기존 주제와 근거 메모의 소속도 검증한다. 저자의 인용과 사용자의 입장을 구분하고 공통 단어만으로 관계를 단정하지 않는다.
- 연결 확정은 실제 관계를 저장한다. 새 주제는 주제/해당 기록의 분류를 저장한다. 글감 제안 확정은 기존 집필 구조와 원문 스냅샷을 사용한다. 원문 메모를 AI 문장으로 고치지 않는다.
- 모델 설정은 접어서 두고 기기/계정별 선택을 기억한다. GPT-6 Luna(중간 추론)를 기본, GPT-6.1 Sol(중간 추론)을 선택지로 제공한다. 공식 모델·가격·Responses/구조화 출력 지원을 확인했으며 자료 범위를 제한한다. 계정 접근 가능 여부는 실행 결과로 알리고 임의로 다른 모델에 재과금하지 않는다.
- 기존 예산·예약·unknown 비용·중복 방지/재전송 금지 구조를 유지한다. 선택 모델의 실제 요금으로 예약/정산하고 결과 모델이 선택과 맞는지 검증한다. 사용·비용·PC 설정 UI는 제거하되 서버 제한은 없애지 않는다.
- 요청 목록은 종류·시각·상태 한 줄과 펼침 상세, 우측 삭제/취소로 간결하게 한다. 완료 요청 삭제 후 기기 자료가 아직 갱신되지 않아 목록이 되살아나는 문제를 직접 서버 조회와 즉시 화면 반영으로 해결한다. 처리 중/비용 미확인 요청은 안전한 상태 제한을 유지한다.

## 접근 선택
중복 화면을 남기는 방식은 사용자의 통합 요구에 어긋나므로 기존 자료 질의를 확장해 하나로 만든다. 새로운 AI 작업 시스템을 만들기보다 현재의 명시적 요청/비용 예약/결과 보관 구조에 종합 검토를 추가한다. 기존 요청은 계속 읽고 기존 코드 호출은 호환한다. 새 DB 테이블 없이 기존 JSON 작업/결과와 주제·연결·연구 자료를 사용한다.
