# 지식서재 확장

사용자는 기존 기획대로 개발을 계속하라고 명시했다. 이번에는 실제 자료를 일상적으로 찾고 읽고 연결할 수 있는 흐름을 완성한다. 추가 승인 절차 없이 기존 승인된 로컬 우선·무료 우선 구조를 따른다.

## 화면과 통계

- 실제 표지는 장식 배경·책등·여백 없이 표시한다. 가져오기 출처 문구는 메모 카드에서 제거하되 원본 출처 데이터는 보존한다.
- 본문 16px, 주요 제목 18px 이상, 보조 텍스트 14px 중심으로 개선하고 밝은 회색 글자를 어둡게 한다. 모바일 가로 넘침을 막는다.
- 사용자 확인: 전체 완독 415, 현재 읽는 4권(정서와 작업하기, 인간 본성의 4중 상태, 개성의 탄생, 넥서스). 원본 session 상태 2의 완료 415회 및 book 상태 4/session 상태 0의 4권을 정식 회차로 변환한다. 원본 ID 기반 중복 방지·수정 보존·이력 저장.
- 원본 날짜상 2026년 완독은 27회이나 원본 앱의 연간 수치는 사용자가 확인한 25.5권이다. 서로 다른 측정값으로 보존하고 원본 날짜나 회차를 수치에 맞추어 바꾸지 않는다. 통계 화면에서 연간 독서량과 날짜별 완독 횟수를 구분한다.

## PDF와 지식 연결

- 범위는 사용자가 지정한 E:\전자도서관 하나. 조사 당시 9,309개 약 337GB. 원본 변경/복사/업로드 없이 파일 목록을 등록한다.
- 대용량 본문은 PC의 SQLite 색인으로 보관한다. 온라인 DB에는 목록·메모·링크·수정 이력을 저장한다. 외장하드가 분리되어도 목록과 색인 검색을 유지하고 원문 열기는 불가 이유를 알려준다.
- 파일 ID, 경로, 크기, 수정시각을 추적한다. 전체 해시가 검증된 경우만 동일 파일로 표시한다. 파일명/제목의 유사성은 병합 제안이며 자동 병합하지 않는다.
- 재개 가능한 로컬 작업으로 PDF 메타데이터/목차/페이지 텍스트를 수집한다. 이미지뿐인 페이지·암호·손상 파일을 구분한다. 전체 OCR 완료를 가장하지 않는다.
- 검색 결과에는 파일명·PDF 페이지 번호·정확한 발췌와 원문 링크를 표시한다. 인쇄된 쪽수와 PDF 순번을 혼동하지 않는다. 검색 근거를 메모/하이라이트에 저장할 수 있다.
- 무료 기본 동작은 제목·주제·본문 검색과 근거 발췌. 모델이 없는 상태에서 생성형 AI 답변을 가장하지 않는다. 향후 로컬/외부 모델을 넣을 경계를 명시한다.
- 자동 연결 후보는 공통 주제/단어 등 설명 가능한 근거로 제안한다. 사용자가 승인·거절·관계 유형/설명을 수정한다. 주장·근거·반론·생각 변화의 연결과 설교/논문 연구 묶음을 제공한다.
- DB/파일/검색 API는 소유자 세션을 검증한다. 파일은 등록 ID로만 열며 경로를 입력받아 임의 파일을 노출하지 않는다. 설정·키는 Git/응답에 노출하지 않는다.

## 검수

통계 실제 건수 대조, 재실행 시 신규 0, 파일 누락/중복/변경 검증, 페이지 인용 일치, SQL/경로 입력 공격·타 사용자 접근 차단, 원본 불변, 모바일/PC 가독성, 타입·빌드·회귀 검사. 중간 처리 상태와 한계는 앱에서 확인할 수 있어야 한다.
