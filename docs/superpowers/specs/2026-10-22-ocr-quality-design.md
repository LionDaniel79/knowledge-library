# OCR 품질 개선과 일괄 재인식

사용자 요청: 본문·각주는 유지하고 반복 머리말·쪽번호·장식·광고를 제거한다. 기존 OCR을 일괄 다시 수행할 수 있어야 한다. 외장하드는 내일 연결하므로 실제 책 품질 개선을 지금 확정하거나 전체 재인식을 실행하지 않는다.

## 품질 처리

기존 Windows.Media.Ocr를 유지한다. 별도의 로컬 LLM이나 대형 모델을 설치하지 않으며 유료 API를 자동 호출하지 않는다. 기존 전체 페이지 2500px 축소 대신 300dpi 렌더링과 겹침이 있는 작은 영역별 인식으로 작은 글자를 보존한다. 가벼운 대비·기울기 보정과 인식 좌표를 사용한다. 인식 영역은 두 단/펼친 책의 읽기 순서를 유지한다.

반복 머리말은 같은 책의 여러 페이지에서 위치와 문구가 반복될 때만 제외한다. 쪽번호는 페이지 가장자리의 단독 숫자에 한정한다. 각주·인용·한 번 나오는 장 제목은 유지한다. 광고·비본문 판별이 애매하거나 새 결과가 과도하게 줄면 검토 대상으로 남긴다. 표지·목차·판권/ISBN 정보는 본문과 별도로 보관하며 추정만으로 삭제하지 않는다.

## 비파괴 재인식

원본 PDF와 원래 문자형 PDF 추출문은 변경하지 않는다. 기존 OCR/빈 쪽/오류 쪽만 대상으로 선택한다. 논문·간행물·분류 보류·손상/암호/변경 파일은 기존 범위 정책대로 제외한다.

새 일괄 작업은 기존 로컬 색인 SQLite의 reocr_* 테이블에 페이지별 이전/새 결과·소스 서명·처리 버전·검토 이유를 보존한다. 같은 파일에 두어 검색문·인식 근거·반영 체크포인트가 원자적으로 커밋된다. 중단 후 이어서 실행하며 기존 OCR 작업과 같은 디스크 잠금을 사용한다. 결과를 확인한 뒤 반영할 때에도 현재 원본·페이지 내용·OCR 실행 식별자를 다시 대조한다. 결과 반영/복원 이력을 유지하고, 오류나 불확실한 쪽은 기존 검색 결과를 보존한다.

## Neon과 저장

OCR 본문과 후보·이력은 PC의 로컬 색인 저장장치에만 쓴다. 이 처리기와 진행률 API는 업무 DB 쿼리를 수행하지 않는다. 웹 API는 기존 소유자 인증을 유지하므로 로그인 서버 장애 시 이용이 제한될 수 있지만, Windows 계정에서 실행하는 CLI 작업은 Neon 없이 동작한다. 인증 우회는 하지 않는다.

현재 확인된 Neon public network 전송량은 5,389,210,312바이트, 무료 요금제, reset 2026-11-01T00:00:00Z이다. 계정 요금제 변경·DB 이전·대규모 내보내기는 하지 않는다. 기존 기기 자료를 유지하고 한도 복구 후 변경분을 동기화하는 것을 우선 권한다. 표지 base64 및 전체 이력이 동기화 대상인 점은 트래픽의 후보 원인이며 실제 기여율은 미측정이다.

## 검증

합성 페이지에서 고해상도 타일 범위·겹침 중복 제거·2단 읽기 순서·반복 머리말 제거·각주 보존·기울기 보정·불확실 페이지 보류를 검사한다. SQLite에서는 기존 결과 보존, 원문/사용자 수정 경쟁, 재개, 동시 실행, 반영/복원 및 타 소유자 차단을 검사한다. 외장하드 연결 후 실제 표본에서 문자 오류율과 누락을 비교한 뒤 전체 처리 여부를 결정한다. 향상을 측정하기 전 ‘정확도 개선 검증 완료’라고 표시하지 않는다.
