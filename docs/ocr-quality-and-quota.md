# OCR 품질과 일괄 재인식

PDF 원문 검색 → PDF 보관 폴더 설정 → **OCR 품질·다시 인식**에서 사용합니다.

1. **표본 5쪽 비교**로 기존 결과와 새 결과를 확인합니다. 미리보기는 쪽별 최대 6,000자입니다.
2. 원본과 비교해 누락·오인식이 줄었다면 **전체 OCR 다시하기**로 기존 OCR 쪽을 다시 처리합니다.
3. 새 결과는 후보로 보관합니다. **검토 후 전체 반영**은 일반 후보만 검색 색인에 반영하며, 광고/목차 의심·인식량 감소 등 ‘확인 필요’ 쪽은 **이 쪽 반영**으로 직접 선택합니다.
4. **이전 결과로 복원**으로 반영 전 상태를 돌릴 수 있습니다. 이후 원본이나 다른 OCR 작업이 내용을 바꾼 쪽은 덮어쓰지 않고 보류합니다.

‘확인 필요’는 자동 검수에서 보류한 후보이며, 모든 쪽을 사용자가 확인해야 한다는 뜻은 아닙니다. 개발·정비 과정에서 원문을 먼저 검수합니다. 새 인식문이 비어 있으면 자동으로 미반영하고 기존 결과를 유지합니다. ‘두 차례’, ‘차례대로’ 같은 본문 표현을 목차로 분류하지 않습니다. 판단이 어려운 후보는 보류 상태로 기존 결과를 유지하며, 사용자 판단이 꼭 필요한 자료만 따로 안내합니다.

광고·표지·목차·판권으로 직접 확인한 쪽은 **본문에서 제외**를 선택합니다. 본문 검색에서 빠지지만 ISBN·목차 수집용 문자와 이전 결과는 별도로 남아 복원할 수 있습니다.

일시 중지·이어서 진행·오류 재시도를 지원합니다. PC가 꺼지면 멈추며 다음 실행에서 이어갈 수 있습니다. 기존 OCR/해시 작업이 디스크를 사용 중이면 동시에 실행하지 않습니다. 후보 생성과 반영·복원은 창을 닫아도 PC에서 계속합니다.

## 달라진 처리

- 보통 크기 페이지를 300dpi로 읽고 영역을 겹쳐 나눠 인식합니다. 기존의 전체 긴 쪽 2,500픽셀 축소로 작은 글자까지 줄이던 처리와 구분됩니다.
- 대비·기울기를 보정하고 중복 인식 문장을 좌표로 정리합니다.
- 반복 머리말은 여러 표본에서 같은 문구·여백 위치가 반복될 때만 제거합니다. 각주와 한 번 나오는 장 제목은 유지합니다.
- 표지·목차·판권·광고가 의심되거나 결과가 급격히 줄면 검토 대상으로 보관합니다. 추정만으로 페이지 전체를 지우지 않습니다.
- 매우 넓은 스캔은 축소/읽기 순서 검토가 필요할 수 있습니다. 저해상도·훼손·특수 언어 원본의 정보 자체를 복구하거나 정확도를 보장하지 않습니다.

원본 PDF, 원래 문자형 PDF의 추출문, 독서 메모는 변경하지 않습니다. 별도 로컬 LLM을 설치하거나 유료 OCR/GPT API를 자동 호출하지 않습니다. 실제 소장본의 정확도 개선은 원본 연결 후 표본으로 확인해야 합니다.

2026-10-22 실제 소장본 검수에서는 개선과 새 오인식이 함께 나왔습니다. 반복 쪽번호·머리말의 결합, 각주 참고문헌 공백의 잘못된 2단 분리, 로마숫자 절 제목 누락을 보완했습니다. 머리말은 책 전체와 가까운 32쪽 구간의 반복 근거를 함께 사용합니다. 검증되지 않은 머리말이나 광고는 보존·검토합니다.

처음에는 한국어 OCR만 설치되어 있었고, 이후 사용자가 영어 OCR을 설치해 두 언어를 확인했습니다. 설치된 Windows OCR만 사용하며, 한글 등 다른 언어가 감지되지 않는 영문 쪽은 영어로 읽습니다. 혼합 쪽에서는 영문 전용 인용 줄만 따로 확대해 인식합니다. 한글과 영문이 함께 있는 줄은 그대로 보존하며, 영문 줄의 변경은 확인이 필요한 후보로 표시합니다. 영어 실행기가 실패하거나 재인식 좌표가 불확실하면 성공한 한국어 결과를 유지합니다. 메모리 부족은 숨기지 않고 작업을 중단·보존합니다. 별도 LLM이나 유료 API는 사용하지 않습니다.

300dpi·400dpi·배경 보정 중 어느 하나가 모든 한국어 표본에 우세하지 않았으므로, 전체 결과를 자동으로 덮어쓰지 않습니다. 영어 표본의 개선을 서재 전체의 정확도 수치로 해석해서는 안 됩니다.

2026-10-22 연결한 색인에는 정상 도서 PDF 4,057개가 있습니다. 이번 일괄 재인식 대상은 기존 Windows OCR 330,604쪽과 빈 OCR 15,389쪽, 총 **345,993쪽**입니다. 문자형 PDF의 기존 추출문, 논문·간행물, 손상 PDF 7개는 대상에서 제외합니다. 실제 4권·8쪽의 반복 검수에서 영문 인용과 반복 여백 제거의 개선을 확인했지만, 한국어 오인식·각주·절 제목의 누락도 남아 있습니다. 일괄 작업은 후보 생성까지 진행하고 자동 전체 반영은 하지 않습니다.

영어 OCR을 추가하려면 Windows 설정 → 시간 및 언어 → 언어 및 지역 → English (United States)에서 광학 문자 인식 기능을 설치합니다. 표시 언어를 바꿀 필요는 없습니다. 명령으로 설치할 경우 관리자 PowerShell에서 `Add-WindowsCapability -Online -Name Language.OCR~~~en-US~0.0.1.0`을 사용합니다. [언어 기능 안내](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/features-on-demand-language-fod?view=windows-11), [설치 명령 안내](https://learn.microsoft.com/en-us/powershell/module/dism/add-windowscapability)

## Neon 한도를 소진했을 때

OCR 본문과 후보·이력은 **PC의 로컬 SQLite 색인**에 저장됩니다. OCR 처리기는 Neon에 접속하지 않습니다. 따라서 OCR 때문에 웹 업로드 한도를 기다릴 필요는 없습니다. 웹 동기화·로그인·현재 PDF 검색 API의 도서 소유권 조회는 별개로 Neon 가용성에 영향을 받습니다.

2026-10-22 관리 API 확인 기준 지식서재 프로젝트는 Free 요금제이며 전송량 5,389,210,312바이트, 다음 초기화는 **2026-11-01 오전 9시(한국시간)**입니다. Free 요금제의 네트워크 전송 한도는 프로젝트당 월 5GB이며 초과하면 다음 주기 또는 업그레이드까지 compute가 중지됩니다. 데이터가 삭제되는 것은 아닙니다. [공식 한도 안내](https://neon.com/docs/introduction/plans)

비용을 추가하지 않는 우선 방안은 PC에서 OCR을 계속 보관하고, 이미 기기에 저장된 서재와 기록을 사용한 뒤 한도 복구 후 변경분을 동기화하는 것입니다. 급하게 온라인 기능을 복구해야 한다면 유료 요금제를 검토할 수 있으나 이 작업에서 요금제를 변경하지 않았습니다.

트래픽에는 DB에서 외부로 읽어 간 데이터가 포함됩니다. 표지 이미지(base64), 전체 수정 이력과 기기별 최초 전체 다운로드가 현재 동기화 대상이므로 반복 전체 저장/재구축은 점검할 후보입니다. 실제 원인별 비율은 아직 측정하지 않았습니다. [공식 트래픽 안내](https://neon.com/docs/introduction/network-transfer)

로그인이 막혀 웹 설정창을 사용할 수 없는 경우에도, 본인 Windows 계정의 PC 작업자는 직접 실행할 수 있습니다. 기존 PC 연결 파일에 소유자 ID가 있으면 자동으로 사용합니다. 인증을 우회하는 웹 접속 방식은 추가하지 않았습니다.

```powershell
# Python/색인 경로는 본인 PC 설정에 맞춥니다.
$ocrPython = 'OCR Python 실행 파일의 전체 경로'
$ocrIndex = 'PDF 색인 SQLite의 전체 경로'
'{"action":"create","scope":"all","sample":true}' | & $ocrPython scripts/pdf_reocr.py control --index $ocrIndex
# 위 결과의 job.id로 실행합니다. 우선 표본만 검수하세요.
& $ocrPython scripts/pdf_reocr.py work --index $ocrIndex --job '반환된 작업 ID'
```

설치 의존성은 `scripts/requirements-pdf.txt`와 Windows의 `scripts/requirements-ocr.txt`입니다. 큰 색인과 OCR 이력은 외장하드의 기존 색인 위치에 보관합니다.
