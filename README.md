# 문장과 사유 · 개인 지식 서재

종이책·로고스·전자책·PDF의 소장 목록, 독서 회차, 메모와 독립적인 생각을 한곳에서 관리하는 한국어 개인용 웹앱입니다.

최신 화면·등록 기능과 Zotero 제거 내용은 [2026-10-16 변경 안내](docs/compact-library-2026-10-16.md)를 따릅니다.

## 지금 사용할 수 있는 기능

- 소장 도서 추가·수정: 제목, 저자, 출판사, ISBN, 종이책/로고스/전자책/PDF/형식 확인 필요, 전체 쪽수, 보관 위치, 분야, 주제, 표지 파일/URL. 제목·ISBN 검색과 바코드 등록을 지원합니다. 수정 전후 내용을 보존합니다.
- 왼쪽에서 열리는 메뉴, 분야·책장별 소장 목록, 최근/오래전 등록·제목·저자 정렬.
- 여러 책장에 같은 책을 넣거나 새 책장을 만듭니다. 기본 책장은 ‘책 대기열’, ‘내 인생 최고의 책들’입니다.
- 제목/ISBN이 같은 기존 책을 입력 화면에서 알려 줍니다. 자동 병합하거나 서지 정보를 검증했다고 표시하지 않습니다.
- 읽기 시작, 진행 쪽수, 완독, 재독, 완독 날짜 변경. 재독은 새 회차로 남습니다.
- 좌우 끝에서 멈추는 읽기 카드, 터치·드래그·방향키·화살표 조작.
- 완독 달력, 월별/연간 통계, 완독 회차와 서로 다른 책 수의 구분.
- 책 메모, 원문 쪽수를 기록한 하이라이트, 책과 무관한 생각, 수정 이력.
- 책·저자·보관 위치·주제·기록 본문·태그 검색. 기록은 태그·종류·연결 도서·날짜로 좁혀 봅니다.
- Google 로그인과 확인된 소유자 이메일만 접근하는 온라인 PostgreSQL 저장.
- iReadItNow HD 백업 변환·가져오기: 도서/메모/서평과 원본 독서 이력 보존, 재실행 중복 방지.
- 소장 목록·독서 회차·메모·수정 이력을 JSON으로 내려받기.

예시 서재는 `/preview`에서 열립니다. 모든 예시 제목·저자·메모는 가상이며 실제 계정으로 복사되지 않습니다. 실제 저장은 `/`에 로그인해서 사용합니다.

## 실행

Node.js 24 이상과 npm을 사용합니다.

1. `npm ci`
2. `.env.example`을 `.env.local`로 복사하고 본인 환경 값을 설정합니다.
3. `npm run db:migrate`
4. `npm run dev -- --hostname 127.0.0.1`
5. http://127.0.0.1:3000

‘Google 계정으로 시작하기’를 누르고 `LIBRARY_OWNER_EMAIL`에 지정한 Google 계정을 선택합니다. 별도 비밀번호나 이메일 인증번호를 입력하지 않습니다. Neon 대시보드 계정과 앱 계정은 별개입니다. Neon 브랜치에 Google 제공자와 앱 origin의 trusted domain이 필요합니다. 로컬 개발용 공유 Google 설정과 운영용 OAuth 설정을 구분합니다.

로그인 화면은 `/auth/sign-in`, 인증 완료 후 돌아오는 주소는 `/`입니다. Neon SDK는 로그인 경로에서 인증 처리를 건너뛰므로 이 두 경로를 같게 설정하지 않습니다. SDK 미들웨어가 인증 코드를 교환하고 쿠키를 저장한 뒤 `/`로 이동합니다. 데이터 API는 별도로 소유자 신원을 검사합니다.

| 설정 | 용도 |
| --- | --- |
| DATABASE_URL | 앱 전용 최소 권한 역할의 pooled 연결 |
| DATABASE_URL_UNPOOLED | 스키마 소유 역할의 직접 연결, 로컬 마이그레이션 전용 |
| LIBRARY_APP_ROLE | 마이그레이션에서 권한을 부여할 앱 역할, 선택 |
| NEON_AUTH_BASE_URL | 해당 Neon 브랜치의 Managed Auth URL |
| NEON_AUTH_COOKIE_SECRET | 32자 이상의 임의 비밀 문자열 |
| LIBRARY_OWNER_EMAIL | 이용을 허용한 소유자 이메일 |
| APP_ORIGIN | 정확한 웹앱 origin, 로컬은 http://127.0.0.1:3000 |
| LIBRARY_IMPORT_ASSET_DIR | 변환된 표지 이미지가 있는 로컬 assets 폴더, 선택 |
| DATA4LIBRARY_KEY | ISBN·제목 일치 도서의 공식 서지정보·KDC 조회용 인증키, 선택 |

운영 환경에 `DATABASE_URL_UNPOOLED`를 올리지 않습니다. 비밀 값은 Git에 포함하지 않습니다. Vercel 배포 시 앱 origin과 Neon Auth의 trusted domain을 배포 주소로 맞춰야 합니다. 실제 개발 접속 역할에는 상위 관리 권한이 있으므로 그대로 배포하지 않습니다. [전용 런타임 계정 절차](db/operations/README.md)를 적용하고 별도 새 접속으로 실효 권한을 확인합니다.

## 데이터 구조와 보존

- `library_books`: 서지 정보와 소장 형태. PDF 원본 파일은 저장하지 않습니다.
- `library_cycles`: 한 번 읽기 시작해서 완독하기까지의 회차. 현재 쪽수와 시작일/완독일을 보관합니다.
- `library_notes`: 책 연결이 선택적인 메모/생각. 하이라이트에는 책과 원문 쪽수가 필수입니다.
- `library_shelves`: 사용자가 만든 책장. 도서는 여러 책장에 속할 수 있으며 실물 보관 위치와 별개입니다.
- `library_revisions`: 바꾸기 전/후 내용의 기록.
- `library_operations`: 요청 ID와 결과. 네트워크 재시도에서 중복 저장을 막습니다.
- `library_imports`: 원본 라이브러리 ID·DB 해시·허용된 원본 도서 관련 테이블과 가져오기 요약. 도서/기록의 `source_key`, `source_data`가 원본과 연결합니다.

각 변경은 데이터와 이력을 한 트랜잭션으로 저장합니다. 수정은 버전 번호로 충돌을 탐지합니다. 날짜는 PostgreSQL `date`와 YYYY-MM-DD를 사용해 시간대에 따른 날짜 이동을 방지합니다.

DB 비밀키는 서버에서만 사용합니다. 모든 업무 API에서 이메일 인증·소유자 확인을 거치며, 모든 조회와 변경에 세션의 사용자 ID를 적용합니다. DB의 RLS/Data API를 사용하지 않으므로 브라우저나 외부 MCP에 SQL 연결을 노출해서는 안 됩니다. 직접 DB 접근 권한이 있는 운영자는 모든 자료를 볼 수 있습니다. 종단 간 암호화는 이 버전에 포함되지 않았습니다.

‘전체 기록 내려받기’는 열람·다른 앱 활용용이며, ‘백업과 복원’은 별도의 복원용 JSON을 제공합니다. 복원 전 파일을 검사하고 빈 서재에만 복원하며, 기존 자료에 덮어쓰거나 병합하지 않습니다. 로그인 비밀키와 기기 토큰은 제외합니다. PDF 원본·본문 색인·표지 이미지 파일은 별도로 보관해야 합니다. [백업 범위와 실제 복원 검수](docs/backup-restore.md)를 확인하세요.

## 검증

- `npm test`: 날짜·통계·권한 및 PGlite 기반 실제 PostgreSQL 문법/트랜잭션 검사.
- `npm run typecheck`
- `npm run build`
- `npm run test:e2e`: Chromium UI 검사. 편집 오류/지연 응답 검사는 배포되지 않는 테스트 전용 진입점과 가상 API 응답으로 재현합니다.
- `npm run verify:live`: 실제 Neon에서 저장·재독·이력·권한을 검증하고 모든 검증 자료를 트랜잭션 롤백으로 제거합니다.

Neon Auth SDK는 현재 설치 버전이 beta입니다. 패키지 잠금 파일을 유지하고 SDK를 올릴 때 Google 인증 시작·콜백·새로고침·로그아웃·소유자 접근 제한을 다시 확인해야 합니다.

## PDF 도서와 Windows PDF 서재

웹앱은 PDF를 소장 도서 형식으로 관리합니다. 제목·저자·ISBN·출판사·표지, 추가·수정·삭제·목록 조회와 도서 추천용 서지 조회를 유지합니다. 기존 메모·인용·하이라이트의 내용과 쪽수, 독서 이력·책장·태그·사유의 지도 연결도 보존합니다.

웹앱의 PDF 원문 검색, 파일/페이지 뷰어, 원문 발췌, 페이지 이동·목차 탐색, PC/Tailscale 원문 접근 API와 링크는 제거했습니다. 통합 검색은 도서 서지와 저장된 기록을 검색하며 PDF 본문 색인을 조회하지 않습니다.

PDF 전체 본문 검색·파일 열기·OCR·색인 관리는 별도의 [Windows PDF 서재](desktop/pdf-library/README.md)에서 수행합니다. 웹앱 사용을 위한 상시 PC 웹서버나 Tailscale 연결은 필요하지 않습니다. 원본 PDF와 로컬 SQLite 색인은 이 코드 정리 과정에서 변경하거나 삭제하지 않습니다.

로컬 서지 수집·파일 중복 검증 등 공유 도구는 남아 있습니다. 해당 도구에서만 사용하는 `LIBRARY_PDF_ROOT`, `LIBRARY_PDF_INDEX`, `LIBRARY_PYTHON`은 로컬 환경에 설정하며 웹 배포에 필수인 설정은 아닙니다. 과거 PDF 웹 사용법 문서는 역사적 기록이며 현재 사용 절차는 Windows 프로그램 문서를 따릅니다.

## 최신 기능

- 나의 서재: 책 대기열, 최근30일 완독 도서, 현재 읽는 책, 최근 기록과 AI 소장 도서 추천. 독서 달력과 통계는 별도 메뉴에서 유지합니다.
- 서재별 보기: 기존 책장 선택과 페이지 단위 도서 조회.
- 사유의 지도: 메모상자, 화이트보드, 생각묶음·글감묶음 및 요청형 AI 도움.
- 새 형식 로고스와 일반 전자책의 독립적인 검색·통계·백업·동기화.

## AI 소장 도서 추천

대시보드의 ‘AI가 추천하는 나의 책’에서 ‘추천받기’ 또는 ‘새로고침’을 누를 때만 GPT-6 Luna로 추천을 만듭니다. 종이책·PDF·로고스에서 각각 최대50권의 후보를 서버가 추출하며, 메모 원문이나 PDF 본문은 전송하지 않습니다. 각 형식에서 최대3권을 추천하고 기존 도서 상세정보를 엽니다. 완독·현재 읽는 책은 후보에서 제외합니다.

이미 저장한 추천은 다시 열거나 탭을 바꿀 때 재사용하며, 새 생성에 실패하면 마지막 성공 결과를 유지합니다. 기존 AI 허용 여부와 요청당·월간 비용 한도를 적용합니다. 송신 결과를 알 수 없는 요청의 비용 예약은 유지하고 자동으로 같은 유료 요청을 재전송하지 않습니다. 설명은 서지·독서 이력에 근거하며 책 본문을 검증했다는 의미가 아닙니다.
